# React Native Resources

## Knowledge

- [React Native Official Docs](https://reactnative.dev/docs/getting-started)
  The authoritative source for React Native API, components, and guides. Use for: any API reference, component props, official patterns.
- [Expo Docs](https://docs.expo.dev/)
  The recommended workflow for beginners. Use for: project setup, Expo SDK APIs, managed workflow guides.
- [React Navigation Docs](https://reactnavigation.org/docs/getting-started)
  The standard navigation library. Use for: stack, tab, drawer navigation setup and deep linking.
- [Redux Toolkit Docs](https://redux-toolkit.js.org/introduction/getting-started)
  Modern Redux patterns. Use for: global state management, slices, RTK Query.
- [React Native Reanimated Docs](https://docs.swmansion.com/react-native-reanimated/)
  The animation library for performant UI. Use for: gesture-driven animations, layout animations, shared element transitions.
- [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/)
  TypeScript fundamentals. Use for: type safety patterns in React Native.
- [Hermes Engine](https://hermesengine.dev/)
  Facebook's JS engine for RN. Use for: understanding RN performance characteristics.

## Wisdom (Communities)

- [r/reactnative](https://reddit.com/r/reactnative)
  Large, active subreddit. Use for: career advice, debugging help, library recommendations.
- [React Native Discord](https://discord.gg/reactiflux)
  Real-time help from experienced RN developers. Use for: quick questions, code review feedback.
- [Stack Overflow — react-native tag](https://stackoverflow.com/questions/tagged/react-native)
  Q&A archive. Use for: specific error solutions, implementation patterns.
