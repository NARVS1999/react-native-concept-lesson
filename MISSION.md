# Mission: React Native Developer

## Why
I want to get a job as a React Native developer. Learning React Native from complete beginner to job-ready will allow me to build cross-platform mobile apps and enter the mobile development workforce.

## Success looks like
- Can build a complete React Native app from scratch (navigation, state management, API integration)
- Can explain React Native architecture and performance optimization in interviews
- Can deploy an app to both App Store and Play Store
- Can write clean, production-quality React Native code that passes code review
- Can debug, test, and optimize React Native apps

## Constraints
- Starting from zero React Native experience
- Learning full-time or alongside other commitments
- Budget: free/low-cost resources preferred

## Out of scope
- React for web (separate workspace)
- Backend/Node.js deep dive (focus on frontend mobile)
- Native iOS (Swift) or native Android (Kotlin) development — React Native only
