Lesson 38: Zustand

Phase 5 — Architectural Concepts

Lesson GoalLearn Zustand — a minimal, fast state management library that requires no providers, supports middleware like persistence and devtools, and uses selectors for optimal re-renders.

What is Zustand?

Zustand (German for "state") is a small, fast, and scalable state management solution. Unlike Redux, it requires no providers, no boilerplate, and no context. You create a store and use it directly in any component.

Why Zustand over Redux?

  • No Provider needed — Just import and use the store hook
  • Minimal API — One function to create the store
  • Bundle size — Under 2KB gzipped
  • No boilerplate — No action types, action creators, or reducer switch statements

Installation

npm install zustand

Creating a Store

A Zustand store is created with the create function. It takes a function that returns the initial state and any actions you want.

// store/useCounterStore.js
import { create } from 'zustand';

const useCounterStore = create((set) => ({
  count: 0,
  increment: () => set((state) => ({ count: state.count + 1 })),
  decrement: () => set((state) => ({ count: state.count - 1 })),
  reset: () => set({ count: 0 }),
}));

export default useCounterStore;

Using the Store in Components

// screens/HomeScreen.js
import { View, Text, Button, StyleSheet } from 'react-native';
import useCounterStore from '../store/useCounterStore';

export default function HomeScreen() {
  const count = useCounterStore((state) => state.count);
  const increment = useCounterStore((state) => state.increment);
  const decrement = useCounterStore((state) => state.decrement);
  const reset = useCounterStore((state) => state.reset);

  return (
    <View style={styles.container}>
      <Text style={styles.count}>Count: {count}</Text>
      <Button title="Increment" onPress={increment} />
      <Button title="Decrement" onPress={decrement} />
      <Button title="Reset" onPress={reset} />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', alignItems: 'center', gap: 10 },
  count: { fontSize: 32, fontWeight: 'bold' },
});

Selectors for Performance

Zustand uses selectors to prevent unnecessary re-renders. Only the selected state triggers a re-render, not the entire store.

// Bad: Re-renders on any store change
const store = useCounterStore();

// Good: Only re-renders when count changes
const count = useCounterStore((state) => state.count);

// Good: Only re-renders when increment function reference changes
const increment = useCounterStore((state) => state.increment);

Multiple Selectors

// You can select multiple values at once
const count = useCounterStore((state) => state.count);
const name = useCounterStore((state) => state.name);

// Or use shallow comparison for objects
import { shallow } from 'zustand/shallow';

const { count, name } = useCounterStore(
  (state) => ({ count: state.count, name: state.name }),
  shallow
);

Middleware: Persistence and DevTools

Zustand supports middleware that can persist state to storage or connect to Redux DevTools.

Persist Middleware

// store/useTodoStore.js
import { create } from 'zustand';
import { persist, createJSONStorage } from 'zustand/middleware';
import AsyncStorage from '@react-native-async-storage/async-storage';

const useTodoStore = create(
  persist(
    (set) => ({
      todos: [],
      addTodo: (text) => set((state) => ({
        todos: [...state.todos, { id: Date.now(), text, done: false }],
      })),
      toggleTodo: (id) => set((state) => ({
        todos: state.todos.map((t) =>
          t.id === id ? { ...t, done: !t.done } : t
        ),
      })),
      removeTodo: (id) => set((state) => ({
        todos: state.todos.filter((t) => t.id !== id),
      })),
    }),
    {
      name: 'todo-storage',
      storage: createJSONStorage(() => AsyncStorage),
    }
  )
);

export default useTodoStore;

DevTools Middleware

// store/useCounterStore.js
import { create } from 'zustand';
import { devtools } from 'zustand/middleware';

const useCounterStore = create(
  devtools((set) => ({
    count: 0,
    increment: () => set((state) => ({ count: state.count + 1 }), false, 'increment'),
    decrement: () => set((state) => ({ count: state.count - 1 }), false, 'decrement'),
  }))
);

export default useCounterStore;

Building a Todo App

// screens/TodoScreen.js
import { useState } from 'react';
import { View, Text, TextInput, Button, FlatList, TouchableOpacity, StyleSheet } from 'react-native';
import useTodoStore from '../store/useTodoStore';

export default function TodoScreen() {
  const [text, setText] = useState('');
  const todos = useTodoStore((state) => state.todos);
  const addTodo = useTodoStore((state) => state.addTodo);
  const toggleTodo = useTodoStore((state) => state.toggleTodo);
  const removeTodo = useTodoStore((state) => state.removeTodo);

  const handleAdd = () => {
    if (text.trim()) {
      addTodo(text.trim());
      setText('');
    }
  };

  return (
    <View style={styles.container}>
      <TextInput
        style={styles.input}
        value={text}
        onChangeText={setText}
        placeholder="Add a todo..."
      />
      <Button title="Add" onPress={handleAdd} />
      <FlatList
        data={todos}
        keyExtractor={(item) => item.id.toString()}
        renderItem={({ item }) => (
          <TouchableOpacity onPress={() => toggleTodo(item.id)}>
            <View style={styles.todoItem}>
              <Text style={item.done ? styles.done : styles.pending}>
                {item.done ? '✓ ' : '○ '}{item.text}
              </Text>
              <Button title="X" onPress={() => removeTodo(item.id)} />
            </View>
          </TouchableOpacity>
        )}
      />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 20, marginTop: 50 },
  input: { borderWidth: 1, borderColor: '#ccc', padding: 10, marginBottom: 10, borderRadius: 5 },
  todoItem: { flexDirection: 'row', justifyContent: 'space-between', alignItems: 'center', padding: 10, borderBottomWidth: 1 },
  done: { textDecorationLine: 'line-through', color: 'gray' },
  pending: { color: 'black' },
});

Summary

  • Zustand is a minimal state management library with no providers needed
  • Use selectors to prevent unnecessary re-renders
  • Persist middleware saves state to AsyncStorage or other storage
  • DevTools middleware enables time-travel debugging
  • Zustand is ideal for small to medium apps that need simple state management
  • Combine with React Query for server state, Zustand for client state
