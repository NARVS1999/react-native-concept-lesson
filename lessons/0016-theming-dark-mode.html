Lesson 0016: Theming and Dark Mode

Phase 6 — Design Concepts

Lesson Goal Build a theming system with design tokens and implement dark mode that respects user preferences.

Design Tokens

Design tokens are the primitive values (colors, spacing, typography) that define your visual system. Centralize them in one place:

// theme.js
export const lightColors = {
  background: '#ffffff',
  surface: '#f5f5f5',
  text: '#1e1e2e',
  textSecondary: '#6c757d',
  primary: '#4263eb',
  error: '#c92a2a',
};

export const darkColors = {
  background: '#11111b',
  surface: '#1e1e2e',
  text: '#cdd6f4',
  textSecondary: '#a6adc8',
  primary: '#89b4fa',
  error: '#f38ba8',
};

export const spacing = {
  xs: 4, sm: 8, md: 16, lg: 24, xl: 32,
};

export const typography = {
  body: { fontSize: 16, lineHeight: 24 },
  h1: { fontSize: 24, fontWeight: 'bold', lineHeight: 32 },
  caption: { fontSize: 12, lineHeight: 16 },
};

Theme Context

Use Context API to provide the current theme to all components:

import { createContext, useContext, useState } from 'react';
import { useColorScheme } from 'react-native';
import { lightColors, darkColors } from './theme';

const ThemeContext = createContext();

export function ThemeProvider({ children }) {
  const systemScheme = useColorScheme();
  const [isDark, setIsDark] = useState(systemScheme === 'dark');

  const colors = isDark ? darkColors : lightColors;

  return (
    <ThemeContext.Provider value={{ isDark, colors, toggleTheme: () => setIsDark(!isDark) }}>
      {children}
    </ThemeContext.Provider>
  );
}

export const useTheme = () => useContext(ThemeContext);

Applying the Theme

Use the theme in your components with a custom hook:

function Card({ title, children }) {
  const { colors, spacing } = useTheme();

  return (
    <View style={{ backgroundColor: colors.surface, padding: spacing.md, borderRadius: 8 }}>
      <Text style={{ color: colors.text, fontSize: 18, fontWeight: 'bold' }}>{title}</Text>
      <Text style={{ color: colors.textSecondary, marginTop: spacing.sm }}>{children}</Text>
    </View>
  );
}
Best Practice Store the user's theme preference in AsyncStorage/MMKV so it persists across app restarts.
