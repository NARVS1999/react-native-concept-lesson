Lesson 15: useState

Phase 2 — Core Concepts

Lesson Goal By the end of this lesson, you will be able to manage local component state using useState, handle state updates correctly with functional updates, and follow immutability rules for React Native state management.

What is useState?

useState is a React hook that lets you add state to functional components. State is data that changes over time and triggers a re-render when updated.

import React, { useState } from 'react';
import { View, Text, Button, StyleSheet } from 'react-native';

export default function Counter() {
  const [count, setCount] = useState(0);

  return (
    <View style={styles.container}>
      <Text style={styles.count}>Count: {count}</Text>
      <Button title="Increment" onPress={() => setCount(count + 1)} />
      <Button title="Decrement" onPress={() => setCount(count - 1)} />
      <Button title="Reset" onPress={() => setCount(0)} />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', alignItems: 'center', gap: 12 },
  count: { fontSize: 32, fontWeight: 'bold' },
});

useState(0) returns an array with two elements: the current state value and a function to update it.

Array Destructuring

The useState return value is destructured using array destructuring. You can name the variables whatever you want:

// Basic destructuring
const [count, setCount] = useState(0);
const [name, setName] = useState('John');
const [isVisible, setIsVisible] = useState(true);
const [items, setItems] = useState([]);

// You can also name them differently
const [counterValue, updateCounter] = useState(0);

The naming convention is [value, setValue] — use the state name prefixed with "set".

Lazy Initialization

If your initial state requires an expensive computation, you can pass a function to useState instead of a value:

import React, { useState } from 'react';

// Expensive computation - only runs once
const [data, setData] = useState(() => {
  console.log('This runs only once!');
  return computeExpensiveInitialData();
});

// Without lazy initialization - runs every render
const [data2, setData2] = useState(computeExpensiveInitialData());
// This would recalculate on every render even though the result is ignored

Functional Updates

When your new state depends on the previous state, use a function to ensure you always have the latest value:

import React, { useState } from 'react';
import { View, Text, Button, StyleSheet } from 'react-native';

export default function Counter() {
  const [count, setCount] = useState(0);

  // BAD - may use stale count value
  const incrementBad = () => {
    setCount(count + 1);
    setCount(count + 1); // Only adds 1, not 2!
  };

  // GOOD - always uses latest count
  const incrementGood = () => {
    setCount(prev => prev + 1);
    setCount(prev => prev + 1); // Adds 2 correctly!
  };

  return (
    <View style={styles.container}>
      <Text style={styles.count}>Count: {count}</Text>
      <Button title="Bad Increment" onPress={incrementBad} />
      <Button title="Good Increment" onPress={incrementGood} />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', alignItems: 'center', gap: 12 },
  count: { fontSize: 32, fontWeight: 'bold' },
});

State Batching

React batches multiple state updates into a single re-render for performance:

import React, { useState } from 'react';

export default function Form() {
  const [name, setName] = useState('');
  const [email, setEmail] = useState('');
  const [age, setAge] = useState(0);

  // These three updates will cause only ONE re-render
  const handleSubmit = () => {
    setName('John');
    setEmail('john@example.com');
    setAge(25);
  };

  return ( /* ... form JSX */ );
}

State Immutability Rules

You must never mutate state directly. Always create a new value when updating:

import React, { useState } from 'react';
import { View, Text, Button, StyleSheet } from 'react-native';

export default function TodoList() {
  const [todos, setTodos] = useState(['Learn React Native']);

  // BAD - mutating state directly
  const addTodoBad = (text) => {
    todos.push(text);  // Mutation! React may not detect the change
    setTodos(todos);   // This might not trigger a re-render
  };

  // GOOD - creating new array
  const addTodoGood = (text) => {
    setTodos([...todos, text]);  // New array, triggers re-render
  };

  // GOOD - updating objects immutably
  const [user, setUser] = useState({ name: 'John', age: 25 });
  const updateAge = () => {
    setUser({ ...user, age: 26 });  // Spread existing, override age
  };

  // GOOD - removing items immutably
  const removeTodo = (index) => {
    setTodos(todos.filter((_, i) => i !== index));
  };

  return (
    <View style={styles.container}>
      {todos.map((todo, index) => (
        <Text key={index}>{todo}</Text>
      ))}
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', padding: 20 },
});

Object State

When working with object state, spread the previous object and override only the properties you want to change:

import React, { useState } from 'react';
import { View, Text, TextInput, StyleSheet } from 'react-native';

export default function UserProfile() {
  const [profile, setProfile] = useState({
    name: 'John Doe',
    email: 'john@example.com',
    avatar: null,
  });

  const updateName = (newName) => {
    setProfile(prev => ({ ...prev, name: newName }));
  };

  return (
    <View style={styles.container}>
      <Text>Name: {profile.name}</Text>
      <TextInput
        style={styles.input}
        value={profile.name}
        onChangeText={updateName}
      />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', padding: 20 },
  input: { borderWidth: 1, borderColor: '#ccc', padding: 10, marginTop: 10 },
});

Mini-Project: Build a Multi-Step Form with useState

Create a multi-step form that tracks progress and form data:

import React, { useState } from 'react';
import { View, Text, TextInput, Pressable, StyleSheet } from 'react-native';

export default function MultiStepForm() {
  const [step, setStep] = useState(1);
  const [formData, setFormData] = useState({
    name: '',
    email: '',
    phone: '',
    address: '',
    city: '',
  });

  const updateField = (field, value) => {
    setFormData(prev => ({ ...prev, [field]: value }));
  };

  const nextStep = () => {
    if (step < 3) setStep(step + 1);
  };

  const prevStep = () => {
    if (step > 1) setStep(step - 1);
  };

  const renderStep = () => {
    switch (step) {
      case 1:
        return (
          <View style={styles.stepContainer}>
            <Text style={styles.stepTitle}>Step 1: Personal Info</Text>
            <TextInput
              style={styles.input}
              placeholder="Full Name"
              value={formData.name}
              onChangeText={(v) => updateField('name', v)}
            />
            <TextInput
              style={styles.input}
              placeholder="Email"
              value={formData.email}
              onChangeText={(v) => updateField('email', v)}
            />
            <TextInput
              style={styles.input}
              placeholder="Phone"
              value={formData.phone}
              onChangeText={(v) => updateField('phone', v)}
            />
          </View>
        );
      case 2:
        return (
          <View style={styles.stepContainer}>
            <Text style={styles.stepTitle}>Step 2: Address</Text>
            <TextInput
              style={styles.input}
              placeholder="Street Address"
              value={formData.address}
              onChangeText={(v) => updateField('address', v)}
            />
            <TextInput
              style={styles.input}
              placeholder="City"
              value={formData.city}
              onChangeText={(v) => updateField('city', v)}
            />
          </View>
        );
      case 3:
        return (
          <View style={styles.stepContainer}>
            <Text style={styles.stepTitle}>Step 3: Review</Text>
            <Text style={styles.reviewItem}>Name: {formData.name}</Text>
            <Text style={styles.reviewItem}>Email: {formData.email}</Text>
            <Text style={styles.reviewItem}>Phone: {formData.phone}</Text>
            <Text style={styles.reviewItem}>Address: {formData.address}</Text>
            <Text style={styles.reviewItem}>City: {formData.city}</Text>
          </View>
        );
    }
  };

  return (
    <View style={styles.container}>
      <Text style={styles.progress}>Step {step} of 3</Text>
      {renderStep()}
      <View style={styles.buttons}>
        {step > 1 && (
          <Pressable style={styles.button} onPress={prevStep}>
            <Text style={styles.buttonText}>Previous</Text>
          </Pressable>
        )}
        {step < 3 ? (
          <Pressable style={styles.button} onPress={nextStep}>
            <Text style={styles.buttonText}>Next</Text>
          </Pressable>
        ) : (
          <Pressable
            style={[styles.button, styles.submitButton]}
            onPress={() => alert('Form submitted!')}
          >
            <Text style={styles.buttonText}>Submit</Text>
          </Pressable>
        )}
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 20, justifyContent: 'center' },
  progress: { textAlign: 'center', fontSize: 16, color: '#7f8c8d', marginBottom: 20 },
  stepContainer: { marginBottom: 20 },
  stepTitle: { fontSize: 18, fontWeight: 'bold', marginBottom: 16 },
  input: {
    borderWidth: 1, borderColor: '#ddd', borderRadius: 8,
    padding: 12, marginBottom: 12, fontSize: 16,
  },
  reviewItem: { fontSize: 16, marginBottom: 8, color: '#333' },
  buttons: { flexDirection: 'row', justifyContent: 'space-between', gap: 12 },
  button: {
    flex: 1, backgroundColor: '#3498db', padding: 14,
    borderRadius: 8, alignItems: 'center',
  },
  submitButton: { backgroundColor: '#27ae60' },
  buttonText: { color: '#fff', fontSize: 16, fontWeight: '600' },
});

This creates a multi-step form that uses useState to track the current step and form data.

Summary

  • useState returns an array with the current state value and an update function
  • Use functional updates (prev => newValue) when new state depends on previous state
  • React batches multiple state updates into a single re-render
  • Never mutate state directly — always create new arrays or objects
  • Use the spread operator ... to copy existing state when updating
  • Lazy initialization with a function avoids expensive computations on every render
  • State updates trigger re-renders, which update the UI
