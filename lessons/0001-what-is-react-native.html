Lesson 0001: What is React Native?

Phase 1 — Foundational Concepts

Lesson Goal Understand what React Native is, how it differs from native development, and set up your first development environment.

Why React Native?

React Native is a cross-platform mobile framework created by Meta (Facebook). It lets you write one codebase in JavaScript or TypeScript and deploy to both iOS and Android.

Before React Native, building for both platforms required two separate teams writing in Swift (iOS) and Kotlin (Android). React Native changed that — you write once, run everywhere.

Key Insight React Native is NOT a web view. It renders real native components using a bridge between JavaScript and the platform's native UI layer.

Expo vs React Native CLI

There are two ways to start a React Native project:

FeatureExpoReact Native CLI
SetupOne command, zero configRequires Xcode/Android Studio
Native code accessLimited (managed workflow)Full access
Best forBeginners, most appsApps needing custom native modules
EAS BuildCloud builds, no Mac neededLocal builds only
EjectingCan eject to bare workflowAlready bare
Recommendation Start with Expo. It handles 90% of use cases and lets you focus on learning React Native, not build tooling.

JavaScript vs TypeScript

React Native supports both JavaScript and TypeScript. TypeScript adds static type checking — catching errors before your code runs.

// JavaScript — no type safety
function greet(name) {
  return "Hello, " + name;
}

// TypeScript — catches errors at compile time
function greet(name: string): string {
  return "Hello, " + name;
}

Industry standard: most professional React Native projects use TypeScript. Learning it early gives you an advantage in job interviews.

Your First Setup

Install the tools you need to start building:

1

Install Node.js (version 18+) from nodejs.org

2

Install Expo CLI: npx create-expo-app@latest my-app

3

Start the dev server: cd my-app && npx expo start

4

Scan the QR code with Expo Go app on your phone

Mini-Project: Create Your First App

Run the following commands in your terminal:

npx create-expo-app@latest HelloReactNative
cd HelloReactNative
npx expo start

Open the app in Expo Go on your phone. You should see the default splash screen. If it works, your environment is ready.

Summary

  • React Native renders real native components, not web views
  • Start with Expo — it handles build tooling so you can focus on code
  • Use TypeScript for type safety and job market competitiveness
  • You need Node.js and Expo Go to start developing
