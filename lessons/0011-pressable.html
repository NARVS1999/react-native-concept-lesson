Lesson 11: Pressable

Phase 2 — Core Concepts

Lesson Goal By the end of this lesson, you will be able to handle touch interactions using Pressable, create custom buttons with visual feedback, and implement accessible press handlers in React Native.

What is Pressable?

Pressable is a core component for handling touch interactions in React Native. It is the recommended way to make any part of your UI respond to taps and long presses. Pressable wraps its children and provides callbacks for various touch states.

import React from 'react';
import { Pressable, Text, Alert } from 'react-native';

export default function App() {
  return (
    <Pressable onPress={() => Alert.alert('Pressed!')}>
      <Text>Tap Me</Text>
    </Pressable>
  );
}

onPress Handler

The onPress callback is called when the user taps the component. This is the most commonly used event handler.

import React from 'react';
import { Pressable, Text, Alert, StyleSheet } from 'react-native';

export default function App() {
  return (
    <Pressable
      style={styles.button}
      onPress={() => Alert.alert('Button Pressed!')}
    >
      <Text style={styles.buttonText}>Click Me</Text>
    </Pressable>
  );
}

const styles = StyleSheet.create({
  button: {
    backgroundColor: '#3498db',
    padding: 15,
    borderRadius: 8,
    alignItems: 'center',
  },
  buttonText: {
    color: '#ffffff',
    fontSize: 16,
    fontWeight: 'bold',
  },
});

onLongPress Handler

The onLongPress callback is called when the user holds down on the component. You can set a duration threshold with delayLongPress (default 500ms).

import React from 'react';
import { Pressable, Text, Alert, StyleSheet } from 'react-native';

export default function App() {
  return (
    <Pressable
      style={styles.button}
      onPress={() => Alert.alert('Short press')}
      onLongPress={() => Alert.alert('Long press detected!')}
      delayLongPress={750}
    >
      <Text style={styles.buttonText}>Hold Me</Text>
    </Pressable>
  );
}

const styles = StyleSheet.create({
  button: {
    backgroundColor: '#e74c3c',
    padding: 15,
    borderRadius: 8,
    alignItems: 'center',
  },
  buttonText: {
    color: '#ffffff',
    fontSize: 16,
    fontWeight: 'bold',
  },
});

onPressIn and onPressOut

These callbacks let you respond to the exact moment a press starts and ends, which is useful for creating visual feedback:

import React, { useState } from 'react';
import { Pressable, Text, StyleSheet } from 'react-native';

export default function App() {
  const [isPressed, setIsPressed] = useState(false);

  return (
    <Pressable
      style={[styles.button, isPressed && styles.pressed]}
      onPressIn={() => setIsPressed(true)}
      onPressOut={() => setIsPressed(false)}
      onPress={() => console.log('Released!')}
    >
      <Text style={styles.buttonText}>
        {isPressed ? 'Pressed!' : 'Press Me'}
      </Text>
    </Pressable>
  );
}

const styles = StyleSheet.create({
  button: {
    backgroundColor: '#27ae60',
    padding: 15,
    borderRadius: 8,
    alignItems: 'center',
  },
  pressed: {
    backgroundColor: '#2ecc71',
    transform: [{ scale: 0.98 }],
  },
  buttonText: {
    color: '#ffffff',
    fontSize: 16,
    fontWeight: 'bold',
  },
});

Style Function with Pressed State

Pressable supports a function as the style prop, which receives the pressed state as an argument. This is the cleanest way to apply press-based styling:

import React from 'react';
import { Pressable, Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <Pressable
      style={({ pressed }) => [
        styles.button,
        pressed && styles.pressed,
      ]}
      onPress={() => console.log('Pressed!')}
    >
      {({ pressed }) => (
        <Text style={[styles.text, pressed && styles.textPressed]}>
          {pressed ? 'Loading...' : 'Submit'}
        </Text>
      )}
    </Pressable>
  );
}

const styles = StyleSheet.create({
  button: {
    backgroundColor: '#8e44ad',
    paddingVertical: 12,
    paddingHorizontal: 24,
    borderRadius: 8,
    alignItems: 'center',
  },
  pressed: {
    backgroundColor: '#9b59b6',
    opacity: 0.8,
  },
  text: {
    color: '#ffffff',
    fontSize: 16,
  },
  textPressed: {
    color: '#f1c40f',
  },
});

Note that Pressable also supports a function as children, giving you access to the pressed state for rendering.

Accessibility Props

Pressable includes built-in accessibility support. Add these props to make your buttons accessible to screen readers:

import React from 'react';
import { Pressable, Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <Pressable
      style={styles.button}
      onPress={() => console.log('Deleted!')}
      accessibilityLabel="Delete item"
      accessibilityRole="button"
      accessibilityHint="Permanently removes the selected item"
    >
      <Text style={styles.buttonText}>Delete</Text>
    </Pressable>
  );
}

const styles = StyleSheet.create({
  button: {
    backgroundColor: '#e74c3c',
    padding: 15,
    borderRadius: 8,
    alignItems: 'center',
  },
  buttonText: {
    color: '#ffffff',
    fontSize: 16,
  },
});

Disabled State

You can disable a Pressable to prevent interactions:

import React from 'react';
import { Pressable, Text, StyleSheet } from 'react-native';

export default function App() {
  const isDisabled = true;

  return (
    <Pressable
      style={[styles.button, isDisabled && styles.disabled]}
      onPress={() => console.log('Pressed!')}
      disabled={isDisabled}
    >
      <Text style={styles.buttonText}>Disabled Button</Text>
    </Pressable>
  );
}

const styles = StyleSheet.create({
  button: {
    backgroundColor: '#3498db',
    padding: 15,
    borderRadius: 8,
    alignItems: 'center',
  },
  disabled: {
    backgroundColor: '#bdc3c7',
    opacity: 0.6,
  },
  buttonText: {
    color: '#ffffff',
    fontSize: 16,
  },
});

Pressable vs TouchableOpacity vs TouchableHighlight

React Native has older touchable components, but Pressable is the recommended replacement:

  • Pressable — Modern, flexible, recommended for new apps
  • TouchableOpacity — Fades opacity on press (legacy)
  • TouchableHighlight — Darkens background on press (legacy)
  • TouchableWithoutFeedback — No visual feedback (legacy, avoid)

Use Pressable for all new code. It provides the same functionality with a more flexible API.

Mini-Project: Build a Custom Button with Press States

Create a reusable button component with multiple press states:

import React from 'react';
import { Pressable, Text, StyleSheet, View } from 'react-native';

export default function CustomButton({ title, onPress, variant = 'primary' }) {
  const getButtonStyle = ({ pressed }) => {
    const base = [styles.button, styles[variant]];
    if (pressed) base.push(styles.pressed);
    return base;
  };

  const getTextStyle = ({ pressed }) => {
    const base = [styles.buttonText, styles[variant + 'Text']];
    if (pressed) base.push(styles.textPressed);
    return base;
  };

  return (
    <Pressable
      style={getButtonStyle}
      onPress={onPress}
      accessibilityRole="button"
      accessibilityLabel={title}
    >
      {({ pressed }) => (
        <Text style={getTextStyle({ pressed })}>{title}</Text>
      )}
    </Pressable>
  );
}

// Usage
export default function App() {
  return (
    <View style={styles.container}>
      <CustomButton
        title="Primary Button"
        variant="primary"
        onPress={() => console.log('Primary pressed')}
      />
      <CustomButton
        title="Danger Button"
        variant="danger"
        onPress={() => console.log('Danger pressed')}
      />
      <CustomButton
        title="Success Button"
        variant="success"
        onPress={() => console.log('Success pressed')}
      />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    justifyContent: 'center',
    padding: 20,
    gap: 12,
  },
  button: {
    paddingVertical: 14,
    paddingHorizontal: 24,
    borderRadius: 8,
    alignItems: 'center',
    justifyContent: 'center',
  },
  pressed: {
    opacity: 0.8,
    transform: [{ scale: 0.97 }],
  },
  primary: { backgroundColor: '#3498db' },
  danger: { backgroundColor: '#e74c3c' },
  success: { backgroundColor: '#27ae60' },
  buttonText: {
    fontSize: 16,
    fontWeight: '600',
    color: '#ffffff',
  },
  primaryText: { color: '#ffffff' },
  dangerText: { color: '#ffffff' },
  successText: { color: '#ffffff' },
  textPressed: {
    opacity: 0.9,
  },
});

This creates a reusable button component that supports multiple variants with press feedback.

Summary

  • Pressable is the recommended component for handling touch interactions in React Native
  • onPress is called when the user taps, onLongPress when they hold down
  • onPressIn and onPressOut give you precise control over press states
  • Use the style function pattern ({ pressed }) => [style, pressed && pressedStyle] for clean press styling
  • Pressable also supports a children function for conditional rendering based on pressed state
  • Add accessibility props like accessibilityLabel and accessibilityRole
  • Use disabled prop to prevent interactions when needed
