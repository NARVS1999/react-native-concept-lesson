Lesson 5: Props

Phase 1 — Foundational Concepts

Lesson Goal By the end of this lesson, you will understand what props are, how to pass and destructure them, how to set default values, how to use the children prop, how to define prop types with TypeScript, and the props drilling problem.

What Are Props?

Props (short for "properties") are how data flows from a parent component to a child component. They are the mechanism for component communication in React Native. Think of props as function arguments — they allow you to pass data into a component to customize its behavior or appearance.

Props are read-only. A child component can receive props but should never modify them. This ensures a predictable, unidirectional data flow: data goes down from parent to child, and events go up from child to parent via callback functions.

// Parent passes props to Child
function Parent() {
  return <Child name="Alice" age={25} />;
}

// Child receives and uses props
function Child({ name, age }) {
  return (
    <View>
      <Text>Name: {name}</Text>
      <Text>Age: {age}</Text>
    </View>
  );
}

Passing Props

Props are passed as attributes on JSX elements, just like HTML attributes. They can be strings, numbers, booleans, objects, arrays, functions, or even other React elements.

<UserCard
  name="Alice"
  age={25}
  isActive={true}
  avatar={{ uri: 'https://example.com/avatar.jpg' }}
  tags={['admin', 'verified']}
  onPress={() => console.log('Pressed')}
/>

Key rules for passing props:

  • Strings use quotes: name="Alice"
  • Numbers use curly braces: age={25}
  • Booleans use curly braces: isActive={true} or shorthand isActive
  • Objects, arrays, functions use curly braces: onPress={() => {}}

Destructuring Props

Destructuring in the function signature makes your code cleaner and more readable.

// WITHOUT destructuring (verbose)
function UserCard(props) {
  return (
    <View>
      <Text>{props.name}</Text>
      <Text>{props.email}</Text>
    </View>
  );
}

// WITH destructuring (clean)
function UserCard({ name, email }) {
  return (
    <View>
      <Text>{name}</Text>
      <Text>{email}</Text>
    </View>
  );
}

// WITH TypeScript interface (type-safe)
interface UserCardProps {
  name: string;
  email: string;
  avatar?: string;
}

function UserCard({ name, email, avatar }: UserCardProps) {
  return (
    <View>
      {avatar && <Image source={{ uri: avatar }} />}
      <Text>{name}</Text>
      <Text>{email}</Text>
    </View>
  );
}

Default Props

Default values ensure your component works even when optional props are not provided.

// Method 1: Default parameter values (recommended)
function Button({ title, variant = 'primary', size = 'medium' }) {
  return (
    <TouchableOpacity style={[styles[variant], styles[size]]}>
      <Text>{title}</Text>
    </TouchableOpacity>
  );
}

// Usage - variant and size default if not provided
<Button title="Submit" />  // uses primary, medium
<Button title="Cancel" variant="secondary" />  // uses medium
<Button title="Delete" variant="danger" size="large" />

// Method 2: With TypeScript optional properties
interface AvatarProps {
  uri: string;
  size?: number;
  borderRadius?: number;
}

function Avatar({ uri, size = 40, borderRadius }: AvatarProps) {
  return (
    <Image
      source={{ uri }}
      style={{
        width: size,
        height: size,
        borderRadius: borderRadius ?? size / 2,
      }}
    />
  );
}

The Children Prop

The children prop is a special prop that allows you to pass JSX elements as the content of a component. It enables powerful composition patterns.

// A Card wrapper that accepts any content via children
function Card({ title, children }) {
  return (
    <View style={styles.card}>
      {title && <Text style={styles.cardTitle}>{title}</Text>}
      <View style={styles.cardBody}>
        {children}
      </View>
    </View>
  );
}

// Usage - pass any content inside the Card tags
function App() {
  return (
    <Card title="User Profile">
      <Avatar uri="https://example.com/john.jpg" />
      <Text>John Doe</Text>
      <Text>john@example.com</Text>
      <Button title="Edit Profile" />
    </Card>
  );
}

// Another example: a layout wrapper
function ScreenLayout({ header, children, footer }) {
  return (
    <View style={styles.layout}>
      {header}
      <View style={styles.content}>
        {children}
      </View>
      {footer}
    </View>
  );
}

// Usage
<ScreenLayout
  header={<Text style={styles.header}>Settings</Text>}
  footer={<Button title="Save" />}
>
  <TextInput placeholder="Name" />
  <TextInput placeholder="Email" />
</ScreenLayout>

Prop Types with TypeScript Interfaces

TypeScript interfaces provide compile-time type checking for your props, catching errors before they reach runtime.

interface ProductCardProps {
  name: string;
  price: number;
  description?: string;
  imageUrl: string;
  inStock: boolean;
  rating: number;
  tags?: string[];
  onAddToCart: (productId: string) => void;
  onWishlist: () => void;
}

function ProductCard({
  name,
  price,
  description,
  imageUrl,
  inStock,
  rating,
  tags = [],
  onAddToCart,
  onWishlist,
}: ProductCardProps) {
  return (
    <View style={styles.productCard}>
      <Image source={{ uri: imageUrl }} style={styles.productImage} />
      <Text style={styles.productName}>{name}</Text>
      <Text style={styles.price}>${price.toFixed(2)}</Text>

      {tags.length > 0 && (
        <View style={styles.tags}>
          {tags.map((tag, index) => (
            <View key={index} style={styles.tag}>
              <Text style={styles.tagText}>{tag}</Text>
            </View>
          ))}
        </View>
      )}

      <View style={styles.actions}>
        <Button
          title={inStock ? 'Add to Cart' : 'Out of Stock'}
          disabled={!inStock}
          onPress={() => onAddToCart(name)}
        />
        <Button title="Wishlist" variant="ghost" onPress={onWishlist} />
      </View>
    </View>
  );
}

The Props Drilling Problem

Props drilling occurs when you need to pass props through multiple intermediate components that don't use them, just to reach a deeply nested child.

// Props drilling example - BAD
function App() {
  const [user, setUser] = useState({ name: 'Alice', theme: 'dark' });
  return <Layout user={user} />;
}

function Layout({ user }) {
  // Layout doesn't use 'user' at all, just passes it down
  return <Sidebar user={user} />;
}

function Sidebar({ user }) {
  // Sidebar doesn't use 'user' either
  return <UserProfile user={user} />;
}

function UserProfile({ user }) {
  // Finally, UserProfile uses it
  return <Text>{user.name}</Text>;
}

Solutions to props drilling include:

  • Context API: Pass data through the component tree without props
  • State management libraries: Redux, Zustand, or Jotai
  • Component composition: Restructure to reduce nesting

Mini-Project: Build a UserCard Component

Create a UserCard component that accepts name, email, and avatar as props, with TypeScript:

import React from 'react';
import { View, Text, Image, TouchableOpacity, StyleSheet } from 'react-native';

interface UserCardProps {
  name: string;
  email: string;
  avatar: string;
  role?: string;
  isOnline?: boolean;
  onPress?: () => void;
}

export default function UserCard({
  name,
  email,
  avatar,
  role = 'User',
  isOnline = false,
  onPress,
}: UserCardProps) {
  const cardContent = (
    <View style={styles.card}>
      <View style={styles.avatarContainer}>
        <Image source={{ uri: avatar }} style={styles.avatar} />
        {isOnline && <View style={styles.onlineIndicator} />}
      </View>
      <View style={styles.info}>
        <Text style={styles.name}>{name}</Text>
        <Text style={styles.email}>{email}</Text>
        <View style={styles.roleBadge}>
          <Text style={styles.roleText}>{role}</Text>
        </View>
      </View>
    </View>
  );

  if (onPress) {
    return (
      <TouchableOpacity onPress={onPress} activeOpacity={0.7}>
        {cardContent}
      </TouchableOpacity>
    );
  }

  return cardContent;
}

const styles = StyleSheet.create({
  card: {
    flexDirection: 'row',
    padding: 16,
    backgroundColor: '#fff',
    borderRadius: 12,
    alignItems: 'center',
    marginBottom: 12,
    elevation: 2,
    shadowColor: '#000',
    shadowOffset: { width: 0, height: 1 },
    shadowOpacity: 0.1,
    shadowRadius: 3,
  },
  avatarContainer: {
    position: 'relative',
    marginRight: 12,
  },
  avatar: {
    width: 56,
    height: 56,
    borderRadius: 28,
  },
  onlineIndicator: {
    position: 'absolute',
    bottom: 2,
    right: 2,
    width: 14,
    height: 14,
    borderRadius: 7,
    backgroundColor: '#22c55e',
    borderWidth: 2,
    borderColor: '#fff',
  },
  info: {
    flex: 1,
  },
  name: {
    fontSize: 16,
    fontWeight: 'bold',
    marginBottom: 2,
  },
  email: {
    fontSize: 14,
    color: '#666',
    marginBottom: 4,
  },
  roleBadge: {
    alignSelf: 'flex-start',
    backgroundColor: '#e0e7ff',
    paddingHorizontal: 8,
    paddingVertical: 2,
    borderRadius: 4,
  },
  roleText: {
    fontSize: 12,
    color: '#3730a3',
    fontWeight: '600',
  },
});

Summary

  • Props are read-only data passed from parent to child components
  • They enable unidirectional data flow (parent to child)
  • Destructure props in the function signature for cleaner code
  • Use default parameter values for optional props
  • The children prop allows passing JSX content to wrap components
  • TypeScript interfaces define the shape and types of your props
  • Props drilling (passing props through unnecessary intermediaries) can be solved with Context API or state management
