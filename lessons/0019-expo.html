Lesson 0019: Expo Managed Workflow

Phase 3 — Implementation Concepts

Lesson Goal Understand Expo managed workflow, create Expo apps, and learn when to use Expo for React Native development.

What is Expo?

Expo is a set of tools and services built around React Native that helps you build, deploy, and manage React Native apps without needing to touch native code directly.

The managed workflow means Expo handles the native project configuration for you, letting you focus on writing JavaScript/React code.

Creating an Expo App

To create a new Expo project, use the following command:

npx create-expo-app my-app
cd my-app
npm start

This sets up a complete React Native project with Expo's tools and configuration.

Expo Go App

Expo Go is a mobile app that lets you preview your React Native projects on physical devices without building native binaries.

  • Download Expo Go from App Store or Google Play
  • Scan the QR code from your terminal
  • See your app running instantly on your device

EAS Build

EAS (Expo Application Services) is Expo's build and submission service for creating production builds:

# Install EAS CLI
npm install -g eas-cli

# Login to your Expo account
eas login

# Build for Android
eas build --platform android

# Build for iOS
eas build --platform ios

Advantages for Beginners

  • No native setup required — No need to install Xcode or Android Studio
  • Instant feedback — Use Expo Go to test on real devices immediately
  • Managed native code — Expo handles complex native configuration
  • Rich ecosystem — Access to many pre-built modules and APIs
  • Easy deployment — EAS Build simplifies app store submission

Mini-Project: Create Your First Expo App

Create an Expo app and run it on your device:

# Create the project
npx create-expo-app HelloWorld
cd HelloWorld

# Start the development server
npm start

Then:

  1. Install Expo Go on your phone
  2. Scan the QR code shown in your terminal
  3. Modify App.js to display your name
  4. Save and see the changes on your device

Summary

  • Expo provides a managed workflow for React Native development
  • Use npx create-expo-app to create new projects
  • Expo Go allows instant testing on physical devices
  • EAS Build handles production builds and app store submission
  • Expo is ideal for beginners who want to focus on JavaScript/React
