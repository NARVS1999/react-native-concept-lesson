Lesson 18: Platform.select

Phase 2 — Core Concepts

Lesson Goal By the end of this lesson, you will be able to use Platform.select to apply platform-specific styles and behavior inline, use Platform.OS for conditional logic, and understand when to use file extensions versus Platform.select.

What is Platform?

The Platform API in React Native gives you information about the running platform (iOS, Android, web) and lets you apply platform-specific code.

import { Platform } from 'react-native';

console.log(Platform.OS);      // "ios" or "android"
console.log(Platform.Version); // iOS version number or Android API level

Platform.OS

The simplest way to check the platform is using Platform.OS:

import React from 'react';
import { View, Text, Platform, StyleSheet } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <Text style={styles.text}>Running on: {Platform.OS}</Text>
      <Text style={styles.text}>Version: {Platform.Version}</Text>
      {Platform.OS === 'ios' && <Text>This only shows on iOS</Text>}
      {Platform.OS === 'android' && <Text>This only shows on Android</Text>}
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', alignItems: 'center' },
  text: { fontSize: 16, marginBottom: 8 },
});

Platform.select

Platform.select takes an object with platform keys and returns the value for the current platform. This is perfect for inline platform-specific styling:

import React from 'react';
import { View, Text, Platform, StyleSheet } from 'react-native';

const styles = StyleSheet.create({
  container: {
    ...Platform.select({
      ios: {
        shadowColor: '#000',
        shadowOffset: { width: 0, height: 2 },
        shadowOpacity: 0.1,
        shadowRadius: 8,
      },
      android: {
        elevation: 4,
      },
      default: {
        shadowColor: '#000',
        shadowOffset: { width: 0, height: 2 },
        shadowOpacity: 0.1,
        shadowRadius: 8,
      },
    }),
    backgroundColor: '#ffffff',
    padding: 16,
    borderRadius: 8,
  },
});

export default function App() {
  return (
    <View style={styles.container}>
      <Text>Platform-specific shadows!</Text>
    </View>
  );
}

iOS uses shadow* properties, while Android uses elevation. Platform.select lets you handle both cleanly.

Platform.select with Values

You can use Platform.select for any value, not just styles:

import { Platform } from 'react-native';

// Platform-specific API endpoints
const API_URL = Platform.select({
  ios: 'https://api.ios.example.com',
  android: 'https://api.android.example.com',
  web: 'https://api.web.example.com',
});

// Platform-specific strings
const appName = Platform.select({
  ios: 'MyApp for iOS',
  android: 'MyApp for Android',
  default: 'MyApp',
});

// Platform-specific configurations
const config = Platform.select({
  ios: { analyticsId: 'ios-123', featureFlags: ['darkMode', 'haptics'] },
  android: { analyticsId: 'android-456', featureFlags: ['darkMode', 'widgets'] },
});

Platform-specific File Extensions

React Native supports platform-specific file extensions for entire components:

// These files will be resolved automatically based on platform:
// Button.ios.js     - Used on iOS
// Button.android.js - Used on Android
// Button.js         - Fallback for other platforms

// Import statement (same for all platforms):
import Button from './Button';

// React Native will automatically pick the right file
When to use file extensions vs Platform.select:
  • File extensions: Use when the entire component is different between platforms
  • Platform.select: Use when only a few props or styles differ

Platform-specific Code Examples

import React from 'react';
import { View, Text, Platform, Pressable, Alert, StyleSheet } from 'react-native';

export default function App() {
  const handlePress = () => {
    if (Platform.OS === 'ios') {
      Alert.alert('iOS Alert', 'This is a native iOS alert');
    } else {
      Alert.alert('Android Alert', 'This is a native Android alert');
    }
  };

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Platform Demo</Text>
      <View style={styles.card}>
        <Text style={styles.cardTitle}>Platform Info</Text>
        <Text>OS: {Platform.OS}</Text>
        <Text>Version: {Platform.Version}</Text>
      </View>
      <Pressable style={styles.button} onPress={handlePress}>
        <Text style={styles.buttonText}>Show Platform Alert</Text>
      </Pressable>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 20, justifyContent: 'center' },
  title: { fontSize: 24, fontWeight: 'bold', textAlign: 'center', marginBottom: 20 },
  card: {
    backgroundColor: '#fff', padding: 16, borderRadius: 8, marginBottom: 16,
    ...Platform.select({
      ios: { shadowColor: '#000', shadowOffset: { width: 0, height: 2 }, shadowOpacity: 0.1, shadowRadius: 8 },
      android: { elevation: 4 },
    }),
  },
  cardTitle: { fontSize: 18, fontWeight: 'bold', marginBottom: 8 },
  button: { backgroundColor: '#3498db', padding: 14, borderRadius: 8, alignItems: 'center' },
  buttonText: { color: '#fff', fontSize: 16, fontWeight: '600' },
});

Platform Version Checks

You can check the platform version for features that require specific OS versions:

import { Platform } from 'react-native';

// Check for specific iOS version
const supportsHaptics = Platform.OS === 'ios' && Platform.Version >= 13;

// Check for specific Android API level
const supportsPictureInPicture = Platform.OS === 'android' && Platform.Version >= 26;

Platform.select in StyleSheet

Here is a comprehensive example showing how to use Platform.select within StyleSheet:

import { Platform, StyleSheet } from 'react-native';

const styles = StyleSheet.create({
  text: {
    fontSize: 16,
    ...Platform.select({
      ios: { fontFamily: 'System' },
      android: { fontFamily: 'Roboto' },
    }),
  },
  header: {
    paddingTop: Platform.select({ ios: 44, android: 0 }),
    ...Platform.select({
      ios: { shadowColor: '#000', shadowOffset: { width: 0, height: 1 }, shadowOpacity: 0.2, shadowRadius: 4 },
      android: { elevation: 4 },
    }),
    backgroundColor: '#ffffff',
  },
  button: {
    paddingVertical: Platform.select({ ios: 12, android: 10 }),
    paddingHorizontal: Platform.select({ ios: 24, android: 20 }),
    borderRadius: Platform.select({ ios: 8, android: 4 }),
  },
});

Mini-Project: Build a Card with Platform-Specific Shadows/Elevation

Create a card component that handles platform differences for shadows and styling:

import React from 'react';
import { View, Text, Platform, StyleSheet } from 'react-native';

const styles = StyleSheet.create({
  container: {
    flex: 1,
    padding: 16,
    backgroundColor: Platform.select({ ios: '#f2f2f7', android: '#fafafa', default: '#f5f5f5' }),
  },
  card: {
    backgroundColor: '#ffffff',
    borderRadius: Platform.select({ ios: 12, android: 8 }),
    padding: 16,
    marginBottom: 16,
    ...Platform.select({
      ios: { shadowColor: '#000000', shadowOffset: { width: 0, height: 2 }, shadowOpacity: 0.15, shadowRadius: 8 },
      android: { elevation: 4 },
    }),
  },
  cardTitle: {
    fontSize: Platform.select({ ios: 20, android: 18 }),
    fontWeight: 'bold',
    color: '#2c3e50',
    marginBottom: 8,
  },
  cardBody: { fontSize: 14, color: '#7f8c8d', lineHeight: 20 },
  platformBadge: {
    alignSelf: 'flex-start',
    paddingHorizontal: 10,
    paddingVertical: 4,
    borderRadius: Platform.select({ ios: 12, android: 4 }),
    backgroundColor: Platform.select({ ios: '#007AFF', android: '#4CAF50', default: '#999' }),
    marginBottom: 12,
  },
  badgeText: { color: '#ffffff', fontSize: 12, fontWeight: '600' },
  divider: {
    height: 1,
    backgroundColor: Platform.select({ ios: '#c6c6c8', android: '#e0e0e0', default: '#ddd' }),
    marginVertical: 12,
  },
  infoRow: { flexDirection: 'row', justifyContent: 'space-between', alignItems: 'center' },
  infoLabel: { fontSize: 14, color: '#95a5a6' },
  infoValue: { fontSize: 14, fontWeight: '600', color: '#2c3e50' },
});

export default function PlatformCard() {
  return (
    <View style={styles.container}>
      <View style={styles.card}>
        <View style={styles.platformBadge}>
          <Text style={styles.badgeText}>{Platform.OS.toUpperCase()}</Text>
        </View>
        <Text style={styles.cardTitle}>Platform-Aware Card</Text>
        <Text style={styles.cardBody}>
          This card automatically adapts its styling based on the platform.
          Shadows use different APIs on iOS and Android.
        </Text>
        <View style={styles.divider} />
        <View style={styles.infoRow}>
          <Text style={styles.infoLabel}>Border Radius</Text>
          <Text style={styles.infoValue}>{Platform.select({ ios: '12px', android: '8px' })}</Text>
        </View>
        <View style={[styles.divider, { marginVertical: 8 }]} />
        <View style={styles.infoRow}>
          <Text style={styles.infoLabel}>Shadow/Elevation</Text>
          <Text style={styles.infoValue}>{Platform.select({ ios: 'shadow*', android: 'elevation: 4' })}</Text>
        </View>
      </View>
    </View>
  );
}

This creates a card component that automatically adapts its styling based on the running platform using Platform.select.

Summary

  • Platform.OS returns the current platform as a string ("ios" or "android")
  • Platform.select lets you define platform-specific values inline using an object
  • Platform.Version gives you the OS version for feature compatibility checks
  • Use file extensions (.ios.js, .android.js) when the entire component differs between platforms
  • Use Platform.select when only a few styles or values need to be different
  • Common use cases: shadows/elevation, font families, padding, and API endpoints
  • The "default" key in Platform.select handles platforms other than ios/android
