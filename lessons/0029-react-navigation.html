Lesson 0029: React Navigation

Phase 4 — Integration Concepts

Lesson Goal Install and configure React Navigation with its required dependencies, set up a NavigationContainer, and implement deep linking in a React Native app.

Why React Navigation?

React Navigation is the most popular navigation library for React Native. It provides a native-like navigation experience on both iOS and Android, handling stack transitions, tab bars, drawer menus, and deep linking out of the box.

Unlike basic screen switching, React Navigation integrates with the native navigation stack, giving you back-button support, smooth animations, and proper memory management.

Installing Dependencies

React Navigation requires several peer dependencies to work correctly:

npm install @react-navigation/native
npm install react-native-screens
npm install react-native-safe-area-context

react-native-screens wraps native navigation primitives for performance. react-native-safe-area-context handles notches and status bars. Both are required for production-quality navigation.

Setting Up NavigationContainer

The NavigationContainer is the root component that manages your navigation tree. It should wrap your entire app:

import React from 'react';
import { NavigationContainer } from '@react-navigation/native';
import { createNativeStackNavigator } from '@react-navigation/native-stack';
import HomeScreen from './screens/HomeScreen';
import DetailScreen from './screens/DetailScreen';

const Stack = createNativeStackNavigator();

export default function App() {
  return (
    <NavigationContainer>
      <Stack.Navigator initialRouteName="Home">
        <Stack.Screen name="Home" component={HomeScreen} />
        <Stack.Screen name="Detail" component={DetailScreen} />
      </Stack.Navigator>
    </NavigationContainer>
  );
}

Passing Parameters

Screens can receive parameters via the params prop:

// Navigate with params
navigation.navigate('Detail', { itemId: 42, title: 'Item Details' });

// Access in destination screen
function DetailScreen({ route, navigation }) {
  const { itemId, title } = route.params;
  return <Text>{title} (ID: {itemId})</Text>;
}

The Linking API

The Linking API maps URLs to screen names, enabling deep links that open specific screens directly:

const linking = {
  prefixes: ['myapp://', 'https://myapp.com'],
  config: {
    screens: {
      Home: '',
      Detail: 'item/:id',
    },
  },
};

export default function App() {
  return (
    <NavigationContainer linking={linking}>
      <Stack.Navigator>
        <Stack.Screen name="Home" component={HomeScreen} />
        <Stack.Screen name="Detail" component={DetailScreen} />
      </Stack.Navigator>
    </NavigationContainer>
  );
}

With this config, opening myapp://item/42 will navigate directly to the Detail screen with id=42.

Mini-Project: React Navigation with Deep Linking

Set up a complete React Navigation stack with three screens (Home, Profile, Settings) and configure the Linking API so that deep links can open any screen directly.

import React from 'react';
import { Text, Button, View } from 'react-native';
import { NavigationContainer } from '@react-navigation/native';
import { createNativeStackNavigator } from '@react-navigation/native-stack';

const Stack = createNativeStackNavigator();

const linking = {
  prefixes: ['myapp://', 'https://myapp.com'],
  config: {
    screens: {
      Home: '',
      Profile: 'profile/:userId',
      Settings: 'settings',
    },
  },
};

function HomeScreen({ navigation }) {
  return (
    <View style={{ padding: 20 }}>
      <Text style={{ fontSize: 24 }}>Home</Text>
      <Button
        title="Go to Profile"
        onPress={() => navigation.navigate('Profile', { userId: '123' })}
      />
      <Button
        title="Go to Settings"
        onPress={() => navigation.navigate('Settings')}
      />
    </View>
  );
}

function ProfileScreen({ route }) {
  const { userId } = route.params;
  return (
    <View style={{ padding: 20 }}>
      <Text style={{ fontSize: 24 }}>Profile - User {userId}</Text>
    </View>
  );
}

function SettingsScreen() {
  return (
    <View style={{ padding: 20 }}>
      <Text style={{ fontSize: 24 }}>Settings</Text>
    </View>
  );
}

export default function App() {
  return (
    <NavigationContainer linking={linking}>
      <Stack.Navigator initialRouteName="Home">
        <Stack.Screen name="Home" component={HomeScreen} />
        <Stack.Screen name="Profile" component={ProfileScreen} />
        <Stack.Screen name="Settings" component={SettingsScreen} />
      </Stack.Navigator>
    </NavigationContainer>
  );
}

Test the deep linking by running: npx uri-scheme open myapp://settings --android

Summary

  • React Navigation requires react-native-screens and react-native-safe-area-context as peer dependencies
  • The NavigationContainer is the root component that wraps your navigation tree
  • Use createNativeStackNavigator for stack-based navigation with native transitions
  • The Linking API maps URL patterns (prefixes + screen configs) to deep link routes
  • Parameters can be passed between screens via the route.params prop
