Understanding useColorScheme

React Native provides a built-in useColorScheme hook that returns the current color scheme of the user's device. It returns either 'light', 'dark', or null (if the preference cannot be determined).

This hook automatically listens for system-level changes — when the user toggles dark mode in their device settings, your app receives the updated value without any additional configuration.

import { useColorScheme } from 'react-native';

function MyComponent() {
  const colorScheme = useColorScheme(); // 'light' | 'dark' | null

  return (
    <View style={{
      backgroundColor: colorScheme === 'dark' ? '#000' : '#fff',
      flex: 1,
      justifyContent: 'center',
      alignItems: 'center',
    }}>
      <Text style={{
        color: colorScheme === 'dark' ? '#fff' : '#000',
        fontSize: 18,
      }}>
        Current scheme: {colorScheme}
      </Text>
    </View>
  );
}

System Preference Detection

When your app first loads, it inherits the device's current color scheme. On iOS, this is controlled by Settings → Display & Brightness → Appearance. On Android, it's Settings → Display → Dark theme.

The useColorScheme hook reacts to these changes in real-time. If the user switches their device from light to dark mode while your app is open, the hook will re-render your components with the new value.

import { useEffect, useState } from 'react';
import { useColorScheme, Appearance } from 'react-native';

function SystemThemeDetector() {
  const colorScheme = useColorScheme();
  const [events, setEvents] = useState([]);

  useEffect(() => {
    // Listen for appearance changes
    const subscription = Appearance.addChangeListener(({ colorScheme }) => {
      setEvents(prev => [
        `Switched to ${colorScheme} at ${new Date().toLocaleTimeString()}`,
        ...prev.slice(0, 4), // Keep last 5 events
      ]);
    });

    return () => subscription?.remove();
  }, []);

  return (
    <View style={{ padding: 20 }}>
      <Text style={{ fontSize: 20, fontWeight: 'bold' }}>
        System: {colorScheme}
      </Text>
      {events.map((event, i) => (
        <Text key={i} style={{ marginTop: 8 }}>{event}</Text>
      ))}
    </View>
  );
}

Dark/Light Theme Switching

A proper dark mode implementation gives users three options: follow the system, always light, or always dark. This requires managing the theme mode separately from the system preference.

import React, { createContext, useState, useEffect, useContext } from 'react';
import { useColorScheme } from 'react-native';
import AsyncStorage from '@react-native-async-storage/async-storage';

const ThemeContext = createContext();

const themes = {
  light: {
    dark: false,
    background: '#ffffff',
    surface: '#f5f5f5',
    text: '#1a1a1a',
    textSecondary: '#666666',
    primary: '#3b82f6',
    border: '#e0e0e0',
  },
  dark: {
    dark: true,
    background: '#121212',
    surface: '#1e1e1e',
    text: '#ffffff',
    textSecondary: '#aaaaaa',
    primary: '#60a5fa',
    border: '#333333',
  },
};

export function ThemeProvider({ children }) {
  const systemScheme = useColorScheme();
  const [mode, setMode] = useState('system');

  useEffect(() => {
    AsyncStorage.getItem('themeMode').then(stored => {
      if (stored) setMode(stored);
    });
  }, []);

  useEffect(() => {
    AsyncStorage.setItem('themeMode', mode);
  }, [mode]);

  const isDark = mode === 'system'
    ? systemScheme === 'dark'
    : mode === 'dark';

  const theme = {
    ...themes[isDark ? 'dark' : 'light'],
    mode,
    isDark,
    setMode,
    toggleTheme: () => setMode(isDark ? 'light' : 'dark'),
  };

  return (
    <ThemeContext.Provider value={theme}>
      {children}
    </ThemeContext.Provider>
  );
}

export const useTheme = () => useContext(ThemeContext);

Building a Dark Mode Toggle

Here is a complete dark mode toggle component that lets users switch between system, light, and dark modes with persistence:

import React from 'react';
import { View, Text, Pressable, StyleSheet } from 'react-native';
import { useTheme } from '../context/ThemeContext';

const modes = ['system', 'light', 'dark'];

export default function DarkModeToggle() {
  const { mode, setMode, colors } = useTheme();

  return (
    <View style={[styles.container, { backgroundColor: colors.background }]}>
      <Text style={[styles.label, { color: colors.text }]}>
        Theme Mode
      </Text>
      <View style={styles.options}>
        {modes.map(m => (
          <Pressable
            key={m}
            onPress={() => setMode(m)}
            style={[
              styles.option,
              {
                backgroundColor: mode === m ? colors.primary : colors.surface,
                borderColor: mode === m ? colors.primary : colors.border,
              },
            ]}
          >
            <Text style={[
              styles.optionText,
              { color: mode === m ? '#fff' : colors.text },
            ]}>
              {m.charAt(0).toUpperCase() + m.slice(1)}
            </Text>
          </Pressable>
        ))}
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { padding: 16, borderRadius: 12, margin: 16 },
  label: { fontSize: 16, fontWeight: '600', marginBottom: 12 },
  options: { flexDirection: 'row', gap: 8 },
  option: {
    flex: 1,
    paddingVertical: 10,
    paddingHorizontal: 12,
    borderRadius: 8,
    borderWidth: 1,
    alignItems: 'center',
  },
  optionText: { fontWeight: '500', fontSize: 14 },
});

Persisting Theme Preference with AsyncStorage

Persistence ensures the user's theme choice survives app restarts. AsyncStorage provides a simple key-value store for React Native.

// Complete dark mode hook with persistence
import { useState, useEffect, useCallback } from 'react';
import { useColorScheme } from 'react-native';
import AsyncStorage from '@react-native-async-storage/async-storage';

const THEME_KEY = '@app_theme_mode';

export function useDarkMode() {
  const systemScheme = useColorScheme();
  const [mode, setModeState] = useState('system');
  const [isLoaded, setIsLoaded] = useState(false);

  // Load persisted mode on mount
  useEffect(() => {
    AsyncStorage.getItem(THEME_KEY).then(stored => {
      if (stored && ['system', 'light', 'dark'].includes(stored)) {
        setModeState(stored);
      }
      setIsLoaded(true);
    });
  }, []);

  // Persist mode changes
  const setMode = useCallback(async (newMode) => {
    setModeState(newMode);
    await AsyncStorage.setItem(THEME_KEY, newMode);
  }, []);

  // Compute resolved theme
  const isDark = mode === 'system'
    ? systemScheme === 'dark'
    : mode === 'dark';

  const toggleTheme = useCallback(() => {
    setMode(isDark ? 'light' : 'dark');
  }, [isDark, setMode]);

  return {
    mode,
    setMode,
    isDark,
    isLoaded,
    toggleTheme,
    systemScheme,
  };
}

// Usage in a component
function ThemeSettings() {
  const { mode, setMode, isDark, systemScheme, isLoaded } = useDarkMode();

  if (!isLoaded) return <ActivityIndicator />;

  return (
    <View style={{ padding: 16 }}>
      <Text style={{ fontSize: 18, fontWeight: 'bold', marginBottom: 16 }}>
        Appearance
      </Text>
      <RadioButton
        label="System Default"
        sublabel={`Currently: ${systemScheme}`}
        selected={mode === 'system'}
        onPress={() => setMode('system')}
      />
      <RadioButton
        label="Light"
        selected={mode === 'light'}
        onPress={() => setMode('light')}
      />
      <RadioButton
        label="Dark"
        selected={mode === 'dark'}
        onPress={() => setMode('dark')}
      />
    </View>
  );
}

Mini-Project: Build a Dark Mode Toggle That Persists

Create a complete dark mode system with persistence:

// hooks/useDarkMode.js
import { useState, useEffect, useCallback } from 'react';
import { useColorScheme } from 'react-native';
import AsyncStorage from '@react-native-async-storage/async-storage';

const STORAGE_KEY = '@theme_mode';

export default function useDarkMode() {
  const systemScheme = useColorScheme();
  const [mode, setModeState] = useState('system');

  useEffect(() => {
    AsyncStorage.getItem(STORAGE_KEY).then(stored => {
      if (stored) setModeState(stored);
    });
  }, []);

  const setMode = useCallback(async (newMode) => {
    setModeState(newMode);
    await AsyncStorage.setItem(STORAGE_KEY, newMode);
  }, []);

  const isDark = mode === 'system' ? systemScheme === 'dark' : mode === 'dark';

  return { mode, setMode, isDark, systemScheme };
}

// screens/SettingsScreen.js
import { View, Text, Pressable, StyleSheet } from 'react-native';
import useDarkMode from '../hooks/useDarkMode';

export default function SettingsScreen() {
  const { mode, setMode, isDark } = useDarkMode();

  const options = [
    { key: 'system', label: 'System' },
    { key: 'light', label: 'Light' },
    { key: 'dark', label: 'Dark' },
  ];

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Theme</Text>
      {options.map(opt => (
        <Pressable
          key={opt.key}
          onPress={() => setMode(opt.key)}
          style={[styles.option, mode === opt.key && styles.selected]}
        >
          <Text style={styles.optionText}>{opt.label}</Text>
        </Pressable>
      ))}
    </View>
  );
}

Summary

  • useColorScheme returns 'light', 'dark', or null based on the device setting
  • The hook automatically listens for system appearance changes
  • Provide three options: system, light, and dark for maximum user control
  • Persist the user's choice with AsyncStorage so it survives app restarts
  • Use the Appearance API's addChangeListener for advanced event handling
  • Always respect the user's system preference as the default behavior
