What Are Design Tokens?

Design tokens are the visual design atoms of your application — they are named entities that store visual design attributes. Instead of hardcoding colors, spacing values, or font sizes throughout your codebase, you define them once as tokens and reference them everywhere.

Design tokens include:

  • Colors: primary, secondary, background, text, error, success colors
  • Spacing: padding, margin, gap values (xs, sm, md, lg, xl)
  • Typography: font sizes, font weights, line heights, font families
  • Borders: border widths, border radii
  • Shadows: shadow color, offset, radius
  • Breakpoints: screen size thresholds

The main benefit is that you can change your entire app's appearance by modifying a single file rather than hunting through dozens of components.

Creating a ThemeContext Provider

The ThemeContext provider wraps your application and makes the current theme available to all child components. It also provides a function to toggle between light and dark themes.

// theme/ThemeContext.js
import React, { createContext, useState, useEffect, useContext } from 'react';
import AsyncStorage from '@react-native-async-storage/async-storage';
import { colors } from './tokens';

const ThemeContext = createContext();

export function ThemeProvider({ children }) {
  const [isDark, setIsDark] = useState(false);
  const [isLoaded, setIsLoaded] = useState(false);

  // Load persisted theme on mount
  useEffect(() => {
    async function loadTheme() {
      try {
        const stored = await AsyncStorage.getItem('theme');
        if (stored !== null) {
          setIsDark(stored === 'dark');
        }
      } catch (e) {
        console.log('Failed to load theme');
      } finally {
        setIsLoaded(true);
      }
    }
    loadTheme();
  }, []);

  // Persist theme whenever it changes
  useEffect(() => {
    if (isLoaded) {
      AsyncStorage.setItem('theme', isDark ? 'dark' : 'light');
    }
  }, [isDark, isLoaded]);

  const toggleTheme = () => setIsDark(prev => !prev);

  const theme = {
    isDark,
    toggleTheme,
    colors: isDark ? colors.dark : colors.light,
  };

  if (!isLoaded) return null; // or a loading spinner

  return (
    <ThemeContext.Provider value={theme}>
      {children}
    </ThemeContext.Provider>
  );
}

export default ThemeContext;

The useTheme Hook

A custom hook that simplifies accessing the theme from any component. This avoids importing and calling useContext directly in every component.

// theme/useTheme.js
import { useContext } from 'react';
import ThemeContext from './ThemeContext';

export default function useTheme() {
  const context = useContext(ThemeContext);
  if (!context) {
    throw new Error('useTheme must be used within a ThemeProvider');
  }
  return context;
}

// Usage in any component:
import useTheme from '../theme/useTheme';
import { spacing, typography } from '../theme/tokens';

function Card({ title, children }) {
  const { colors, isDark } = useTheme();

  return (
    <View style={{
      backgroundColor: colors.surface,
      padding: spacing.md,
      borderRadius: 8,
      marginBottom: spacing.sm,
    }}>
      <Text style={{
        color: colors.text,
        fontSize: typography.sizes.lg,
        fontWeight: typography.weights.bold,
      }}>
        {title}
      </Text>
      <Text style={{ color: colors.textSecondary }}>
        {children}
      </Text>
    </View>
  );
}

Building a ThemeProvider with Light/Dark Colors

Here is a complete, production-ready ThemeProvider that supports both light and dark themes with persistence:

// Complete ThemeProvider implementation
import React, { createContext, useState, useEffect, useContext, useMemo } from 'react';
import { useColorScheme } from 'react-native';
import AsyncStorage from '@react-native-async-storage/async-storage';

const ThemeContext = createContext();

const lightTheme = {
  dark: false,
  colors: {
    primary: '#3b82f6',
    secondary: '#10b981',
    background: '#ffffff',
    surface: '#f3f4f6',
    text: '#111827',
    textSecondary: '#6b7280',
    border: '#e5e7eb',
    error: '#ef4444',
    success: '#22c55e',
  },
};

const darkTheme = {
  dark: true,
  colors: {
    primary: '#60a5fa',
    secondary: '#34d399',
    background: '#111827',
    surface: '#1f2937',
    text: '#f9fafb',
    textSecondary: '#9ca3af',
    border: '#374151',
    error: '#f87171',
    success: '#4ade80',
  },
};

export function ThemeProvider({ children }) {
  const systemScheme = useColorScheme();
  const [mode, setMode] = useState('system'); // 'light', 'dark', or 'system'

  useEffect(() => {
    AsyncStorage.getItem('themeMode').then(stored => {
      if (stored) setMode(stored);
    });
  }, []);

  useEffect(() => {
    AsyncStorage.setItem('themeMode', mode);
  }, [mode]);

  const isDark = mode === 'system'
    ? systemScheme === 'dark'
    : mode === 'dark';

  const theme = useMemo(() => ({
    ...(isDark ? darkTheme : lightTheme),
    mode,
    setMode,
    toggleTheme: () => setMode(prev => prev === 'dark' ? 'light' : 'dark'),
  }), [isDark, mode]);

  return (
    <ThemeContext.Provider value={theme}>
      {children}
    </ThemeContext.Provider>
  );
}

export const useTheme = () => useContext(ThemeContext);

Applying the Theme Throughout Your App

Wrap your root component with ThemeProvider and use the theme in any descendant component:

// App.js
import { ThemeProvider } from './theme/ThemeContext';
import HomeScreen from './screens/HomeScreen';

export default function App() {
  return (
    <ThemeProvider>
      <HomeScreen />
    </ThemeProvider>
  );
}

// screens/HomeScreen.js
import { View, Text, StyleSheet } from 'react-native';
import { useTheme } from '../theme/ThemeContext';
import { spacing, typography } from '../theme/tokens';

export default function HomeScreen() {
  const { colors, isDark, toggleTheme } = useTheme();

  return (
    <View style={[styles.container, { backgroundColor: colors.background }]}>
      <Text style={[styles.title, { color: colors.text }]}>
        Welcome Home
      </Text>
      <Text style={{ color: colors.textSecondary }}>
        Current theme: {isDark ? 'Dark' : 'Light'}
      </Text>
      <Pressable onPress={toggleTheme} style={styles.button}>
        <Text style={styles.buttonText}>Toggle Theme</Text>
      </Pressable>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', alignItems: 'center' },
  title: { fontSize: typography.sizes.xl, marginBottom: spacing.md },
  button: { marginTop: spacing.lg, padding: spacing.md, backgroundColor: '#3b82f6', borderRadius: 8 },
  buttonText: { color: '#fff', fontWeight: '600' },
});

Summary

  • Design tokens centralize visual attributes (colors, spacing, typography) in one place
  • ThemeContext provides theme values to all components without prop drilling
  • The useTheme hook gives easy access to the current theme in any component
  • Persist theme preference with AsyncStorage so it survives app restarts
  • Separate tokens from the ThemeProvider logic for maximum flexibility
  • Use useMemo to avoid unnecessary re-renders when the theme hasn't changed
