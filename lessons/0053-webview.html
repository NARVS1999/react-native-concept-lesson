Phase 6 — Design Concepts

Lesson Goal By the end of this lesson, you will understand how to use react-native-webview to embed web content, configure the WebView component, handle messages between native and web, and inject JavaScript into web pages.

What is WebView?

A WebView allows you to display web content (HTML, CSS, JavaScript) directly within your React Native app. Use cases include displaying web pages, running HTML5 games, embedding third-party content, or migrating web content to a mobile app without rewriting it.

Basic WebView Usage

The WebView component renders web content using the platform's native web rendering engine (WKWebView on iOS, WebView on Android).

import { View, StyleSheet, ActivityIndicator } from 'react-native';
import { WebView } from 'react-native-webview';

function BasicWebView() {
  return (
    <View style={styles.container}>
      <WebView
        source={{ uri: 'https://reactnative.dev' }}
        style={styles.webview}
        startInLoadingState={true}
        renderLoading={() => (
          <ActivityIndicator size="large" style={styles.loading} />
        )}
      />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1 },
  webview: { flex: 1 },
  loading: { position: 'absolute', top: '50%', left: '50%' },
});

The Source Prop

javaScriptEnabled

By default, JavaScript is enabled in WebView. You can disable it for security when displaying untrusted content.

import { WebView } from 'react-native-webview';
import { View, Switch, Text, StyleSheet, useState } from 'react-native';

function SecureWebView() {
  const [jsEnabled, setJsEnabled] = useState(true);

  return (
    <View style={styles.container}>
      <View style={styles.controls}>
        <Text style={styles.label}>JavaScript: {jsEnabled ? 'ON' : 'OFF'}</Text>
        <Switch value={jsEnabled} onValueChange={setJsEnabled} />
      </View>

      <WebView
        source={{ uri: 'https://example.com' }}
        style={styles.webview}
        javaScriptEnabled={jsEnabled}
        // Additional security props
        domStorageEnabled={true}
        allowFileAccess={false}
        allowUniversalAccessFromFileURLs={false}
        mixedContentMode="never"
      />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1 },
  controls: { flexDirection: 'row', justifyContent: 'space-between', alignItems: 'center', padding: 12, backgroundColor: '#f3f4f6' },
  label: { fontSize: 16, fontWeight: '500' },
  webview: { flex: 1 },
});

onMessage — Communication Between Native and Web

The onMessage prop allows JavaScript running inside the WebView to send messages back to React Native.

import { useState, useRef } from 'react';
import { View, Text, StyleSheet, Pressable } from 'react-native';
import { WebView } from 'react-native-webview';

function WebViewCommunication() {
  const [messages, setMessages] = useState([]);
  const webViewRef = useRef(null);

  // HTML with JavaScript that sends messages
  const htmlContent = `
    <!DOCTYPE html>
    <html>
    <head>
      <meta name="viewport" content="width=device-width, initial-scale=1.0">
      <style>
        body { padding: 20px; font-family: sans-serif; }
        button { padding: 10px 20px; margin: 5px; border: none; border-radius: 6px; cursor: pointer; font-size: 14px; }
        .blue { background: #3b82f6; color: white; }
        .green { background: #10b981; color: white; }
      </style>
    </head>
    <body>
      <h2>WebView Content</h2>
      <button class="blue" onclick="sendToNative('Button 1 clicked!')">Send Message 1</button>
      <button class="green" onclick="sendToNative('Button 2 clicked!')">Send Message 2</button>
      <p id="response"></p>

      <script>
        function sendToNative(message) {
          window.ReactNativeWebView.postMessage(JSON.stringify({
            type: 'BUTTON_CLICK',
            message: message,
            timestamp: Date.now()
          }));
        }

        // Function to receive messages from React Native
        function receiveFromNative(data) {
          document.getElementById('response').textContent = 'Response: ' + data;
        }
      </script>
    </body>
    </html>
  `;

  // Handle messages from WebView
  const handleMessage = (event) => {
    try {
      const data = JSON.parse(event.nativeEvent.data);
      setMessages(prev => [data, ...prev.slice(0, 9)]); // Keep last 10
    } catch (e) {
      console.log('Invalid message:', event.nativeEvent.data);
    }
  };

  // Send message TO the WebView
  const sendToWebView = () => {
    if (webViewRef.current) {
      webViewRef.current.injectJavaScript(`
        receiveFromNative('Hello from React Native!');
        true; // Required to avoid injection warning
      `);
    }
  };

  return (
    <View style={styles.container}>
      <WebView
        ref={webViewRef}
        source={{ html: htmlContent }}
        style={styles.webview}
        onMessage={handleMessage}
        javaScriptEnabled={true}
      />
      <View style={styles.footer}>
        <Pressable onPress={sendToWebView} style={styles.button}>
          <Text style={styles.buttonText}>Send to WebView</Text>
        </Pressable>
        <View style={styles.messageLog}>
          {messages.map((msg, i) => (
            <Text key={i} style={styles.message}>
              [{new Date(msg.timestamp).toLocaleTimeString()}] {msg.message}
            </Text>
          ))}
        </View>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1 },
  webview: { flex: 1 },
  footer: { padding: 12, backgroundColor: '#f3f4f6', borderTopWidth: 1, borderTopColor: '#e5e7eb' },
  button: { backgroundColor: '#3b82f6', padding: 12, borderRadius: 8, alignItems: 'center', marginBottom: 8 },
  buttonText: { color: '#fff', fontWeight: '600' },
  messageLog: { maxHeight: 80 },
  message: { fontSize: 12, color: '#666', marginBottom: 2 },
});

injectedJavaScript

The injectedJavaScript prop runs JavaScript code as soon as the page loads. Use it to customize the web content or set up listeners.

import { WebView } from 'react-native-webview';

function InjectedJSExample() {
  const injectedJS = `
    // This runs when the page loads
    console.log('WebView loaded!');

    // Override alert to prevent popups
    window.alert = function(message) {
      window.ReactNativeWebView.postMessage(JSON.stringify({ type: 'ALERT', message }));
    };

    // Listen for clicks on links
    document.addEventListener('click', function(e) {
      if (e.target.tagName === 'A') {
        e.preventDefault();
        window.ReactNativeWebView.postMessage(JSON.stringify({
          type: 'LINK_CLICK',
          href: e.target.href,
        }));
      }
    });
  `;

  return (
    <WebView
      source={{ uri: 'https://example.com' }}
      injectedJavaScript={injectedJS}
      onMessage={(event) => {
        const data = JSON.parse(event.nativeEvent.data);
        console.log('From WebView:', data);
      }}
    />
  );
}

// More advanced: Inject CSS
function StyledWebView() {
  const injectedCSS = `
    (function() {
      var style = document.createElement('style');
      style.textContent = \`
        body { background: #1a1a2e !important; color: #eee !important; }
        a { color: #3b82f6 !important; }
        img { max-width: 100% !important; height: auto !important; }
      \`;
      document.head.appendChild(style);
    })();
  `;

  return (
    <WebView
      source={{ uri: 'https://example.com' }}
      injectedJavaScript={injectedCSS}
    />
  );
}

WebView Events and Control

WebView provides several event props for monitoring loading state and navigation.

import { useState, useRef } from 'react';
import { View, Text, StyleSheet, Pressable, ActivityIndicator } from 'react-native';
import { WebView } from 'react-native-webview';

function ControlledWebView() {
  const [loading, setLoading] = useState(true);
  const [progress, setProgress] = useState(0);
  const [currentUrl, setCurrentUrl] = useState('');
  const webViewRef = useRef(null);

  return (
    <View style={styles.container}>
      {/* Progress bar */}
      {loading && (
        <View style={styles.progressBar}>
          <View style={[styles.progressFill, { width: `${progress * 100}%` }]} />
        </View>
      )}

      <WebView
        ref={webViewRef}
        source={{ uri: 'https://reactnative.dev' }}
        style={styles.webview}
        onLoadStart={() => setLoading(true)}
        onLoadProgress={(e) => setProgress(e.nativeEvent.progress)}
        onLoadEnd={() => setLoading(false)}
        onNavigationStateChange={(navState) => setCurrentUrl(navState.url)}
        onError={(e) => console.log('WebView error:', e.nativeEvent)}
      />

      {/* Navigation controls */}
      <View style={styles.controls}>
        <Text style={styles.url} numberOfLines={1}>{currentUrl}</Text>
        <View style={styles.buttons}>
          <Pressable
            onPress={() => webViewRef.current?.goBack()}
            style={styles.button}
          >
            <Text style={styles.buttonText}>Back</Text>
          </Pressable>
          <Pressable
            onPress={() => webViewRef.current?.goForward()}
            style={styles.button}
          >
            <Text style={styles.buttonText}>Forward</Text>
          </Pressable>
          <Pressable
            onPress={() => webViewRef.current?.reload()}
            style={styles.button}
          >
            <Text style={styles.buttonText}>Reload</Text>
          </Pressable>
        </View>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1 },
  webview: { flex: 1 },
  progressBar: { height: 3, backgroundColor: '#e5e7eb' },
  progressFill: { height: '100%', backgroundColor: '#3b82f6' },
  controls: { padding: 12, backgroundColor: '#f3f4f6', borderTopWidth: 1, borderTopColor: '#e5e7eb' },
  url: { fontSize: 12, color: '#666', marginBottom: 8 },
  buttons: { flexDirection: 'row', gap: 8 },
  button: { paddingVertical: 8, paddingHorizontal: 16, backgroundColor: '#3b82f6', borderRadius: 6 },
  buttonText: { color: '#fff', fontWeight: '500' },
});

Mini-Project: Embed a Webpage in Your App

Create a WebView screen that loads a webpage with bidirectional communication:

// screens/WebViewScreen.js
import { useState, useRef } from 'react';
import { View, Text, StyleSheet, Pressable, SafeAreaView } from 'react-native';
import { WebView } from 'react-native-webview';

export default function WebViewScreen({ url = 'https://reactnative.dev' }) {
  const [canGoBack, setCanGoBack] = useState(false);
  const [canGoForward, setCanGoForward] = useState(false);
  const [title, setTitle] = useState('');
  const webViewRef = useRef(null);

  const html = `
    <!DOCTYPE html>
    <html>
    <head>
      <meta name="viewport" content="width=device-width, initial-scale=1.0">
      <style>
        body { padding: 20px; font-family: sans-serif; text-align: center; }
        h1 { color: #3b82f6; }
        .btn { padding: 12px 24px; margin: 8px; border: none; border-radius: 8px; font-size: 16px; cursor: pointer; }
        .primary { background: #3b82f6; color: white; }
        .secondary { background: #10b981; color: white; }
        #output { margin-top: 20px; padding: 16px; background: #f3f4f6; border-radius: 8px; text-align: left; }
      </style>
    </head>
    <body>
      <h1>WebView Demo</h1>
      <p>This page communicates with React Native!</p>
      <button class="btn primary" onclick="send('Hello from WebView!')">Send Message</button>
      <button class="btn secondary" onclick="send(JSON.stringify({action: 'getData'}))">Request Data</button>
      <div id="output">Messages will appear here...</div>

      <script>
        function send(msg) {
          window.ReactNativeWebView.postMessage(msg);
          document.getElementById('output').innerHTML += '<p>Sent: ' + msg + '</p>';
        }
        function receive(msg) {
          document.getElementById('output').innerHTML += '<p>Received: ' + msg + '</p>';
        }
      </script>
    </body>
    </html>
  `;

  const handleMessage = (event) => {
    console.log('Message from WebView:', event.nativeEvent.data);
    // Send response back
    webViewRef.current?.injectJavaScript(
      `receive('Native received: ${event.nativeEvent.data}'); true;`
    );
  };

  return (
    <SafeAreaView style={styles.container}>
      <View style={styles.header}>
        <Text style={styles.title} numberOfLines={1}>{title || 'Loading...'}</Text>
      </View>

      <WebView
        ref={webViewRef}
        source={{ html }}
        style={styles.webview}
        onMessage={handleMessage}
        onLoadStart={() => setTitle('Loading...')}
        onLoadEnd={(e) => {
          setCanGoBack(e.nativeEvent.canGoBack);
          setCanGoForward(e.nativeEvent.canGoForward);
        }}
        onNavigationStateChange={(navState) => {
          setTitle(navState.title);
          setCanGoBack(navState.canGoBack);
          setCanGoForward(navState.canGoForward);
        }}
      />

      <View style={styles.footer}>
        <Pressable
          onPress={() => webViewRef.current?.goBack()}
          disabled={!canGoBack}
          style={[styles.button, !canGoBack && styles.disabled]}
        >
          <Text style={styles.buttonText}>← Back</Text>
        </Pressable>
        <Pressable onPress={() => webViewRef.current?.reload()} style={styles.button}>
          <Text style={styles.buttonText}>↻ Reload</Text>
        </Pressable>
        <Pressable
          onPress={() => webViewRef.current?.goForward()}
          disabled={!canGoForward}
          style={[styles.button, !canGoForward && styles.disabled]}
        >
          <Text style={styles.buttonText}>Forward →</Text>
        </Pressable>
      </View>
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#fff' },
  header: { padding: 12, backgroundColor: '#f3f4f6', borderBottomWidth: 1, borderBottomColor: '#e5e7eb' },
  title: { fontSize: 14, fontWeight: '500', textAlign: 'center' },
  webview: { flex: 1 },
  footer: { flexDirection: 'row', justifyContent: 'space-around', padding: 12, backgroundColor: '#f3f4f6', borderTopWidth: 1, borderTopColor: '#e5e7eb' },
  button: { paddingVertical: 8, paddingHorizontal: 16, backgroundColor: '#3b82f6', borderRadius: 6 },
  buttonText: { color: '#fff', fontWeight: '500' },
  disabled: { opacity: 0.5 },
});

Summary

  • react-native-webview renders web content using the platform's native browser engine
  • The source prop accepts { uri: '...' } for URLs or { html: '...' } for inline HTML
  • javaScriptEnabled controls whether JavaScript runs in the WebView
  • onMessage receives data sent from JavaScript via window.ReactNativeWebView.postMessage()
  • injectedJavaScript runs custom JavaScript when the page loads
  • Use ref.injectJavaScript() to send data from React Native to the WebView
  • Monitor navigation with onNavigationStateChange and control with goBack(), goForward(), reload()
