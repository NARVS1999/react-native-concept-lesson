Lesson 52: SVG

Phase 6 — Design Concepts

Lesson Goal By the end of this lesson, you will understand how to use react-native-svg to render vector graphics, including Svg, Circle, Rect, Path, Ellipse, G group, fill/stroke, viewBox, and animated SVGs.

Why SVG in React Native?

SVG (Scalable Vector Graphics) provides resolution-independent graphics that look crisp on any screen size. Unlike PNG or JPEG images, SVGs are defined as XML-based vector paths, making them infinitely scalable without quality loss.

In React Native, the react-native-svg library allows you to render SVG elements directly as native components.

Basic SVG Components

The react-native-svg library provides components that mirror SVG elements: Svg, Circle, Rect, Path, Ellipse, Line, Polygon, and more.

import Svg, { Circle, Rect, Path, Ellipse, Line, Polygon } from 'react-native-svg';

function BasicSVG() {
  return (
    <Svg width="300" height="300" viewBox="0 0 300 300">
      {/* Rectangle */}
      <Rect
        x="10"
        y="10"
        width="100"
        height="80"
        fill="#3b82f6"
        rx="8"
      />

      {/* Circle */}
      <Circle
        cx="200"
        cy="50"
        r="40"
        fill="#10b981"
      />

      {/* Ellipse */}
      <Ellipse
        cx="150"
        cy="180"
        rx="80"
        ry="40"
        fill="#f59e0b"
      />

      {/* Line */}
      <Line
        x1="10"
        y1="250"
        x2="290"
        y2="250"
        stroke="#ef4444"
        strokeWidth="3"
      />

      {/* Triangle using Polygon */}
      <Polygon
        points="150,100 100,200 200,200"
        fill="#8b5cf6"
      />
    </Svg>
  );
}

The Path Component

The Path component is the most powerful SVG element. It uses a mini-language of commands to define complex shapes:

  • M x,y: Move to point
  • L x,y: Draw line to point
  • H x: Horizontal line
  • V y: Vertical line
  • A: Arc
  • Q: Quadratic bezier curve
  • C: Cubic bezier curve
  • Z: Close path
import Svg, { Path } from 'react-native-svg';

function HeartShape() {
  return (
    <Svg width="200" height="200" viewBox="0 0 200 200">
      <Path
        d="M100,180 C60,140 10,100 10,60 C10,20 50,0 100,40 C150,0 190,20 190,60 C190,100 140,140 100,180Z"
        fill="#ef4444"
      />
    </Svg>
  );
}

function StarShape() {
  return (
    <Svg width="200" height="200" viewBox="0 0 200 200">
      <Path
        d="M100,10 L120,70 L190,70 L135,110 L155,180 L100,140 L45,180 L65,110 L10,70 L80,70Z"
        fill="#f59e0b"
        stroke="#d97706"
        strokeWidth="2"
      />
    </Svg>
  );
}

function CustomIcon() {
  return (

Fill, Stroke, and Styling

SVG elements support fill (interior color), stroke (outline color), strokeWidth, opacity, and other styling properties.

import Svg, { Circle, Rect } from 'react-native-svg';

function StyledSVG() {
  return (
    <Svg width="300" height="200" viewBox="0 0 300 200">
      {/* Filled shape */}
      <Circle cx="80" cy="100" r="50" fill="#3b82f6" />

      {/* Stroked shape (outline only) */}
      <Circle
        cx="200"
        cy="100"
        r="50"
        fill="none"
        stroke="#ef4444"
        strokeWidth="3"
      />

      {/* Semi-transparent fill */}
      <Rect
        x="120"
        y="50"
        width="80"
        height="80"
        fill="#10b981"
        fillOpacity="0.5"
      />

      {/* Dashed stroke */}
      <Circle
        cx="80"
        cy="100"
        r="60"
        fill="none"
        stroke="#f59e0b"
        strokeWidth="2"
        strokeDasharray="5,5"
      />

      {/* Line caps and joins */}
      <Path
        d="M150,30 Q200,100 150,170"
        fill="none"
        stroke="#8b5cf6"
        strokeWidth="4"
        strokeLinecap="round"
        strokeLinejoin="round"
      />
    </Svg>
  );
}

The G Group Component

The G component groups multiple SVG elements together, allowing you to apply transformations to all children at once.

import Svg, { G, Circle, Rect, Text } from 'react-native-svg';

function GroupedElements() {
  return (
    <Svg width="300" height="200" viewBox="0 0 300 200">
      {/* Group with rotation */}
      <G transform="rotate(30, 150, 100)">
        <Rect x="100" y="50" width="100" height="100" fill="#3b82f6" rx="8" />
        <Circle cx="150" cy="100" r="20" fill="#fff" />
      </G>

      {/* Group with scale */}
      <G transform="translate(50, 150) scale(0.5)">
        <Circle cx="100" cy="100" r="80" fill="#10b981" />
        <Text x="60" y="105" fill="#fff" fontSize="24" fontWeight="bold">
          Hi
        </Text>
      </G>

      {/* Nested groups inherit transforms */}
      <G transform="translate(200, 20)">
        <G transform="rotate(45, 40, 40)">
          <Rect x="0" y="0" width="80" height="80" fill="#f59e0b" rx="4" />
        </G>
      </G>
    </Svg>
  );
}

ViewBox

The viewBox attribute defines the coordinate system for your SVG. It allows you to design at a fixed resolution and scale to any size.

import Svg, { Circle, Rect } from 'react-native-svg';

function ViewBoxExample() {
  return (
    <View style={{ flex: 1 }}>
      {/* This SVG scales to fill its container while maintaining aspect ratio */}
      <Svg
        width="100%"
        height="100%"
        viewBox="0 0 100 100"
        preserveAspectRatio="xMidYMid meet"
      >
        {/* These coordinates are in the viewBox coordinate system (0-100) */}
        <Circle cx="50" cy="50" r="40" fill="#3b82f6" />
        <Rect x="20" y="20" width="60" height="60" fill="#10b981" fillOpacity="0.5" />
      </Svg>

      {/* Same SVG, different sizes — looks identical */}
      <View style={{ flexDirection: 'row', gap: 16, padding: 16 }}>
        <Svg width="50" height="50" viewBox="0 0 100 100">
          <Circle cx="50" cy="50" r="40" fill="#ef4444" />
        </Svg>
        <Svg width="100" height="100" viewBox="0 0 100 100">
          <Circle cx="50" cy="50" r="40" fill="#ef4444" />
        </Svg>
        <Svg width="200" height="200" viewBox="0 0 100 100">
          <Circle cx="50" cy="50" r="40" fill="#ef4444" />
        </Svg>
      </View>
    </View>
  );
}

Animated SVGs

You can animate SVG properties using Reanimated's Animated components or the built-in Animated API.

import { useEffect, useRef } from 'react';
import { Animated, View } from 'react-native';
import Svg, { Circle, Rect, Path } from 'react-native-svg';

const AnimatedCircle = Animated.createAnimatedComponent(Circle);

function AnimatedSVGExample() {
  const radiusAnim = useRef(new Animated.Value(0)).current;
  const opacityAnim = useRef(new Animated.Value(0)).current;
  const rotateAnim = useRef(new Animated.Value(0)).current;

  useEffect(() => {
    Animated.loop(
      Animated.parallel([
        Animated.sequence([
          Animated.timing(radiusAnim, { toValue: 50, duration: 1000, useNativeDriver: false }),
          Animated.timing(radiusAnim, { toValue: 20, duration: 1000, useNativeDriver: false }),
        ]),
        Animated.timing(opacityAnim, { toValue: 1, duration: 500, useNativeDriver: false }),
        Animated.timing(rotateAnim, { toValue: 360, duration: 3000, useNativeDriver: false }),
      ])
    ).start();
  }, []);

  return (
    <View style={{ alignItems: 'center', padding: 20 }}>
      <Svg width="200" height="200" viewBox="0 0 200 200">
        <AnimatedCircle
          cx="100"
          cy="100"
          r={radiusAnim}
          fill="#3b82f6"
          opacity={opacityAnim}
        />
      </Svg>
    </View>
  );
}

// Using Reanimated for SVG animations
import Animated, {
  useSharedValue,
  useAnimatedProps,
  withRepeat,
  withTiming,
} from 'react-native-reanimated';

const AnimatedPath = Animated.createAnimatedComponent(Path);

function ReanimatedSVG() {
  const rotate = useSharedValue(0);

  useEffect(() => {
    rotate.value = withRepeat(
      withTiming(360, { duration: 2000 }),
      -1
    );
  }, []);

  const animatedProps = useAnimatedProps(() => ({
    transform: [{ rotate: `${rotate.value}deg` }],
  }));

  return (
    <Svg width="200" height="200" viewBox="0 0 200 200">
      <AnimatedPath
        d="M100,10 L120,70 L190,70 L135,110 L155,180 L100,140 L45,180 L65,110 L10,70 L80,70Z"
        fill="#f59e0b"
        animatedProps={animatedProps}
      />
    </Svg>
  );
}

Mini-Project: Build a Custom SVG Icon

Create a reusable SVG icon component:

// components/Icon.js
import Svg, { Path, Circle, Rect, G } from 'react-native-svg';

// Checkmark icon
export function CheckIcon({ size = 24, color = '#10b981' }) {
  return (
    <Svg width={size} height={size} viewBox="0 0 24 24" fill="none">
      <Path
        d="M20 6L9 17l-5-5"
        stroke={color}
        strokeWidth="2"
        strokeLinecap="round"
        strokeLinejoin="round"
      />
    </Svg>
  );
}

// Heart icon
export function HeartIcon({ size = 24, color = '#ef4444', filled = false }) {

    <Svg width={size} height={size} viewBox="0 0 24 24">

Summary

  • react-native-svg provides vector graphics that scale perfectly on any screen
  • Use Svg as the container and child components like Circle, Rect, Path
  • The Path component supports complex shapes via the SVG path mini-language
  • fill and stroke control interior and outline colors
  • The G component groups elements for shared transforms
  • viewBox defines the coordinate system for responsive scaling
  • SVGs can be animated using Animated or Reanimated libraries
