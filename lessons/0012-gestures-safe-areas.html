Lesson 0012: Gestures and Safe Areas

Phase 4 — Integration Concepts

Lesson Goal Handle gesture interactions with Gesture Handler and ensure content respects device notches with Safe Area Context.

Safe Area Context

Modern phones have notches, rounded corners, and status bars. SafeAreaView ensures your content stays visible:

import { SafeAreaView, SafeAreaProvider } from 'react-native-safe-area-context';

function App() {
  return (
    <SafeAreaProvider>
      <SafeAreaView style={{ flex: 1 }}>
        <Text>This content is safe from notches!</Text>
      </SafeAreaView>
    </SafeAreaProvider>
  );
}

For nested content that needs its own safe area (e.g., headers inside a scroll view), use the useSafeAreaInsets hook:

import { useSafeAreaInsets } from 'react-native-safe-area-context';

function Header() {
  const insets = useSafeAreaInsets();
  return (
    <View style={{ paddingTop: insets.top, paddingHorizontal: 16 }}>
      <Text style={{ fontSize: 24, fontWeight: 'bold' }}>My App</Text>
    </View>
  );
}

Gesture Handler

react-native-gesture-handler provides a more powerful gesture system than basic Pressable — swipe, pinch, rotation, and multi-touch:

import { GestureHandlerRootView, PanGestureHandler } from 'react-native-gesture-handler';

function SwipeableCard() {
  const translateX = useSharedValue(0);

  const gesture = Gesture.Pan()
    .onUpdate((e) => { translateX.value = e.translationX; })
    .onEnd(() => { translateX.value = withSpring(0); });

  const animatedStyle = useAnimatedStyle(() => ({
    transform: [{ translateX: translateX.value }],
  }));

  return (
    <GestureHandlerRootView>
      <GestureDetector gesture={gesture}>
        <Animated.View style={[styles.card, animatedStyle]}>
          <Text>Swipe me!</Text>
        </Animated.View>
      </GestureDetector>
    </GestureHandlerRootView>
  );
}
Important Wrap your app root with <GestureHandlerRootView> for gesture handler to work. This is typically done in your entry file.
Gesture Handler vs Pressable Use <Pressable> for simple taps. Use Gesture Handler for swipes, drags, pinch-to-zoom, or complex multi-touch interactions.

Summary

  • SafeAreaView / useSafeAreaInsets handles notches, rounded corners, and status bars
  • Gesture Handler provides swipe, drag, pinch, and rotation gestures
  • Wrap your app in <GestureHandlerRootView>
  • Use <Pressable> for simple taps, Gesture Handler for complex gestures
