Lesson 58: List Virtualization

Phase 7 — Advanced Concepts

Lesson Goal Master FlatList virtualization details including windowSize, maxToRenderPerBatch, removeClippedSubviews, getItemLayout optimization, and inverted lists for chat-like interfaces.

How Virtualization Works

FlatList renders only the items currently visible on screen plus a buffer zone. Instead of rendering 10,000 items at once, it renders maybe 20-30 visible items, recycling DOM nodes as you scroll.

Key FlatList Props

Tune these props to control virtualization behavior and performance.

<FlatList
  data={items}
  keyExtractor={(item) => item.id}
  renderItem={({ item }) => <ItemRow item={item} />}

  // Number of items to render in the initial batch
  initialNumToRender={10}

  // How many items to render per batch (incremental loading)
  maxToRenderPerBatch={10}

  // How far ahead (in pixels) to render items
  windowSize={5}

  // Number of items to keep in the render window
  removeClippedSubviews={true}

  // Optimize when item height is known
  getItemLayout={(data, index) => ({
    length: ITEM_HEIGHT,
    offset: ITEM_HEIGHT * index,
    index,
  })}
/>

windowSize Explained

windowSize determines the render window size in multiples of the visible screen height. A windowSize of 5 means the visible screen + 2 screens above + 2 screens below are rendered.

windowSizeEffectMemory Usage
1Only visible itemsLowest — may show blank while scrolling
5 (default)Visible + 2 screens buffer each sideModerate — good balance
10+Large buffer zoneHigher — smoother scrolling, more memory

maxToRenderPerBatch

Controls how many items are rendered in each incremental batch. Higher values improve perceived performance but increase frame time per batch.

// Conservative — good for complex items
<FlatList
  maxToRenderPerBatch={5}
  windowSize={5}
  initialNumToRender={10}
  data={items}
  renderItem={renderItem}
/>

// Aggressive — good for simple items
<FlatList
  maxToRenderPerBatch={20}
  windowSize={10}
  initialNumToRender={15}
  data={items}
  renderItem={renderItem}
/>

removeClippedSubviews

When true, items scrolled off-screen are removed from the native view hierarchy, reducing memory usage. This can cause a brief flash on some platforms.

// Good for long lists with simple items
<FlatList
  removeClippedSubviews={true}
  data={items}
  renderItem={renderItem}
/>

// Disable if you notice visual glitches
<FlatList
  removeClippedSubviews={false}
  data={items}
  renderItem={renderItem}
/>

getItemLayout Optimization

When all items have the same height, providing getItemLayout lets FlatList calculate positions without measuring, enabling instant scrolling to any index.

const ITEM_HEIGHT = 80;

const renderItem = ({ item }) => (
  <View style={{ height: ITEM_HEIGHT, padding: 10 }}>
    <Text>{item.name}</Text>
  </View>
);

<FlatList
  data={items}
  renderItem={renderItem}
  getItemLayout={(data, index) => ({
    length: ITEM_HEIGHT,
    offset: ITEM_HEIGHT * index,
    index,
  })}
  // scrollToIndex works without measuring!
  onScrollToIndexFailed={(info) => {
    flatListRef.current.scrollToOffset({
      offset: info.averageItemLength * info.index,
      animated: true,
    });
  }}
/>

Inverted Lists

Inverted FlatLists display items from bottom to top — perfect for chat interfaces where new messages appear at the bottom.

<FlatList
  data={messages}
  inverted={true}
  keyExtractor={(item) => item.id}
  renderItem={({ item }) => (
    <View style={[
      styles.messageBubble,
      item.isMe ? styles.myMessage : styles.theirMessage,
    ]}>
      <Text>{item.text}</Text>
      <Text style={styles.timestamp}>{item.time}</Text>
    </View>
  )}
/>
Note: With inverted lists, the first item in the array appears at the bottom. Use data.slice().reverse() if you want the first item at the top.

Mini-Project: Optimize a Large FlatList

import React, { useState, useMemo, useRef, useCallback } from 'react';
import { View, Text, FlatList, TextInput, StyleSheet, TouchableOpacity } from 'react-native';

const ITEM_HEIGHT = 70;

// Generate 1000 items for performance testing
const generateItems = (count) =>
  Array.from({ length: count }, (_, i) => ({
    id: String(i),
    title: `Item ${i + 1}`,
    subtitle: `Description for item ${i + 1}`,
  }));

const ItemRow = React.memo(({ item, onPress }) => (
  <TouchableOpacity style={styles.item} onPress={() => onPress(item.id)}>
    <Text style={styles.itemTitle}>{item.title}</Text>
    <Text style={styles.itemSubtitle}>{item.subtitle}</Text>
  </TouchableOpacity>
));

const OptimizedList = () => {
  const [search, setSearch] = useState('');
  const flatListRef = useRef(null);
  const allItems = useMemo(() => generateItems(1000), []);

  const filteredItems = useMemo(() => {
    if (!search) return allItems;
    return allItems.filter(item =>
      item.title.toLowerCase().includes(search.toLowerCase())
    );
  }, [allItems, search]);

  const handlePress = useCallback((id) => {
    console.log('Pressed:', id);
  }, []);

  const scrollToTop = useCallback(() => {
    flatListRef.current?.scrollToOffset({ offset: 0, animated: true });
  }, []);

  const renderItem = useCallback(({ item }) => (
    <ItemRow item={item} onPress={handlePress} />
  ), [handlePress]);

  const getItemLayout = useCallback((data, index) => ({
    length: ITEM_HEIGHT,
    offset: ITEM_HEIGHT * index,
    index,
  }), []);

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Optimized FlatList ({filteredItems.length} items)</Text>
      <TextInput
        style={styles.searchInput}
        placeholder="Search items..."
        value={search}
        onChangeText={setSearch}
      />
      <FlatList
        ref={flatListRef}
        data={filteredItems}
        keyExtractor={(item) => item.id}
        renderItem={renderItem}
        getItemLayout={getItemLayout}
        initialNumToRender={15}
        maxToRenderPerBatch={10}
        windowSize={5}
        removeClippedSubviews={true}
        style={styles.list}
      />
      <TouchableOpacity style={styles.scrollTop} onPress={scrollToTop}>
        <Text style={styles.scrollTopText}>^</Text>
      </TouchableOpacity>
    </View>
  );
};

const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#f5f5f5' },
  title: { fontSize: 20, fontWeight: 'bold', padding: 15, textAlign: 'center' },
  searchInput: { margin: 10, padding: 12, backgroundColor: '#fff', borderRadius: 8, borderWidth: 1, borderColor: '#ddd' },
  list: { flex: 1 },
  item: { height: ITEM_HEIGHT, justifyContent: 'center', padding: 15, backgroundColor: '#fff', marginHorizontal: 10, marginVertical: 3, borderRadius: 8 },
  itemTitle: { fontSize: 16, fontWeight: '600' },
  itemSubtitle: { fontSize: 13, color: '#666', marginTop: 4 },
  scrollTop: { position: 'absolute', bottom: 20, right: 20, width: 50, height: 50, borderRadius: 25, backgroundColor: '#007AFF', justifyContent: 'center', alignItems: 'center' },
  scrollTopText: { color: '#fff', fontSize: 24, fontWeight: 'bold' },
});

export default OptimizedList;

Summary

  • FlatList virtualization renders only visible items plus a buffer zone
  • windowSize controls the buffer zone — higher means smoother scrolling but more memory
  • maxToRenderPerBatch controls how many items render per incremental batch
  • removeClippedSubviews removes off-screen items from native view hierarchy
  • getItemLayout enables instant scrolling by skipping measurement
  • Inverted lists display items bottom-to-top for chat interfaces
