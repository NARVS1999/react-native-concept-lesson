Lesson 0014: Server State and Storage

Phase 5 — Architectural Concepts

Lesson Goal Manage server data with React Query (TanStack Query) and choose the right local storage solution.

React Query (TanStack Query)

React Query manages server state — data from APIs. It handles fetching, caching, background refetching, and mutations automatically.

import { useQuery, useMutation, QueryClient, QueryClientProvider } from '@tanstack/react-query';

const queryClient = new QueryClient();

function UserList() {
  const { data, isLoading, error } = useQuery({
    queryKey: ['users'],
    queryFn: () => fetch('https://api.example.com/users').then(r => r.json()),
  });

  if (isLoading) return <Text>Loading...</Text>;
  if (error) return <Text>Error loading users</Text>;

  return (
    <FlatList
      data={data}
      keyExtractor={item => String(item.id)}
      renderItem={({ item }) => <Text>{item.name}</Text>}
    />
  );
}

// Mutations
function CreateUser() {
  const mutation = useMutation({
    mutationFn: (newUser) => fetch('https://api.example.com/users', {
      method: 'POST',
      body: JSON.stringify(newUser),
    }),
    onSuccess: () => queryClient.invalidateQueries({ queryKey: ['users'] }),
  });

  return (
    <Pressable onPress={() => mutation.mutate({ name: 'New User' })}>
      <Text>Add User</Text>
    </Pressable>
  );
}
Why React Query? It separates server state (async, shared, can become stale) from client state (local, synchronous). This is how most production apps are architected.

MMKV: Fast Local Storage

MMKV is a synchronous, encrypted key-value storage that is 30x faster than AsyncStorage:

import { MMKV } from 'react-native-mmkv';

const storage = new MMKV();

// Synchronous operations (no await needed!)
storage.set('user.name', 'Ana');
const name = storage.getString('user.name'); // 'Ana'
storage.delete('user.name');

SQLite: Structured Data

For complex queries, relationships, and structured data, use SQLite:

import * as SQLite from 'expo-sqlite';

const db = await SQLite.openDatabaseAsync('app.db');

// Create table
await db.execAsync(`
  CREATE TABLE IF NOT EXISTS todos (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    completed INTEGER DEFAULT 0
  );
`);

// Insert
await db.runAsync('INSERT INTO todos (title) VALUES (?)', ['Learn SQLite']);

// Query
const todos = await db.getAllAsync('SELECT * FROM todos');
Storage Decision Matrix
  • AsyncStorage: Simple key-value, no encryption, small data
  • MMKV: Fast key-value, encrypted, same use case as AsyncStorage but faster
  • SQLite: Structured data, complex queries, relationships, offline-first

Summary

  • React Query manages server state with caching, background refetch, and mutations
  • MMKV is a fast, synchronous, encrypted alternative to AsyncStorage
  • SQLite is for structured data with complex queries
  • Separate server state from client state for scalable architecture
