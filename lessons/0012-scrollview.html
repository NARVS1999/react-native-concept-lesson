Lesson 12: ScrollView

Phase 2 — Core Concepts

Lesson Goal By the end of this lesson, you will be able to create scrollable content, implement horizontal carousels, handle scroll events, and understand when to use ScrollView versus FlatList in React Native.

What is ScrollView?

ScrollView is a component that wraps content in a scrollable container. It is perfect for showing content that does not fit on a single screen, such as long forms, image galleries, or settings pages.

import React from 'react';
import { ScrollView, Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <ScrollView>
      <Text style={styles.item}>Item 1</Text>
      <Text style={styles.item}>Item 2</Text>
      <Text style={styles.item}>Item 3</Text>
      <Text style={styles.item}>Item 4</Text>
      <Text style={styles.item}>Item 5</Text>
      <Text style={styles.item}>Item 6</Text>
      <Text style={styles.item}>Item 7</Text>
      <Text style={styles.item}>Item 8</Text>
    </ScrollView>
  );
}

const styles = StyleSheet.create({
  item: {
    padding: 20,
    fontSize: 18,
    borderBottomWidth: 1,
    borderBottomColor: '#ccc',
  },
});

The ScrollView renders all its children at once, which is fine for a moderate number of items but can cause performance issues with very large lists.

Vertical Scrolling

By default, ScrollView scrolls vertically. You can control the scroll behavior with several props:

import React from 'react';
import { ScrollView, View, Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <ScrollView
      showsVerticalScrollIndicator={false}
      contentContainerStyle={styles.container}
    >
      {Array.from({ length: 20 }, (_, i) => (
        <View key={i} style={styles.card}>
          <Text style={styles.cardTitle}>Card {i + 1}</Text>
          <Text style={styles.cardContent}>
            This is the content of card number {i + 1}
          </Text>
        </View>
      ))}
    </ScrollView>
  );
}

const styles = StyleSheet.create({
  container: {
    padding: 16,
    gap: 12,
  },
  card: {
    backgroundColor: '#ffffff',
    padding: 16,
    borderRadius: 8,
    shadowColor: '#000',
    shadowOffset: { width: 0, height: 1 },
    shadowOpacity: 0.1,
    shadowRadius: 4,
    elevation: 2,
  },
  cardTitle: {
    fontSize: 18,
    fontWeight: 'bold',
    marginBottom: 4,
  },
  cardContent: {
    fontSize: 14,
    color: '#666',
  },
});

Horizontal Scrolling

Set horizontal={true} to create horizontal scrolling, which is perfect for carousels and horizontal lists:

import React from 'react';
import { ScrollView, View, Text, StyleSheet, Dimensions } from 'react-native';

const { width } = Dimensions.get('window');

export default function App() {
  return (
    <ScrollView
      horizontal={true}
      showsHorizontalScrollIndicator={false}
      pagingEnabled={true}
    >
      {['red', 'blue', 'green', 'orange', 'purple'].map((color, i) => (
        <View
          key={i}
          style={[styles.slide, { backgroundColor: color }]}
        >
          <Text style={styles.slideText}>Slide {i + 1}</Text>
        </View>
      ))}
    </ScrollView>
  );
}

const styles = StyleSheet.create({
  slide: {
    width,
    height: 200,
    justifyContent: 'center',
    alignItems: 'center',
  },
  slideText: {
    color: '#ffffff',
    fontSize: 24,
    fontWeight: 'bold',
  },
});

Setting pagingEnabled makes the scroll snap to page boundaries, creating a carousel effect.

contentContainerStyle

Use contentContainerStyle to style the inner content container. This is different from the ScrollView's own style — it styles the area that contains all the children:

import React from 'react';
import { ScrollView, Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <ScrollView
      style={styles.scroll}
      contentContainerStyle={styles.content}
    >
      <Text>Content with extra padding and centering</Text>
    </ScrollView>
  );
}

const styles = StyleSheet.create({
  scroll: {
    flex: 1,
    backgroundColor: '#ecf0f1',
  },
  content: {
    flexGrow: 1,
    justifyContent: 'center',
    alignItems: 'center',
    padding: 20,
  },
});

Handling Scroll Events

You can track the scroll position using onScroll:

import React, { useState } from 'react';
import { ScrollView, Text, View, StyleSheet } from 'react-native';

export default function App() {
  const [scrollY, setScrollY] = useState(0);

  return (
    <View style={styles.container}>
      <Text style={styles.header}>Scroll Position: {Math.round(scrollY)}px</Text>
      <ScrollView
        onScroll={(e) => setScrollY(e.nativeEvent.contentOffset.y)}
        scrollEventThrottle={16}
      >
        {Array.from({ length: 30 }, (_, i) => (
          <View key={i} style={styles.item}>
            <Text>Item {i + 1}</Text>
          </View>
        ))}
      </ScrollView>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1 },
  header: { padding: 16, fontSize: 16, fontWeight: 'bold' },
  item: { padding: 20, borderBottomWidth: 1, borderBottomColor: '#ddd' },
});

The scrollEventThrottle prop controls how often the scroll event fires (in milliseconds). Use 16 for smooth 60fps updates.

Performance Warning

Important: ScrollView renders ALL its children at once. If you have a long list of items (hundreds or thousands), use FlatList instead. FlatList renders items lazily as they come into view, which is much more performant for large datasets.

Use ScrollView when:

  • You have a small, fixed number of children
  • You need horizontal scrolling (like a carousel)
  • You need to scroll content that includes mixed components

Use FlatList when:

  • You have a long list of similar items
  • The data set could grow over time
  • You need pull-to-refresh or infinite scrolling

Key ScrollView Props

  • horizontal — Enables horizontal scrolling
  • pagingEnabled — Snaps to page boundaries
  • showsVerticalScrollIndicator — Shows/hides the scroll bar
  • showsHorizontalScrollIndicator — Shows/hides horizontal scroll bar
  • contentContainerStyle — Style for the inner content container
  • onScroll — Called during scroll with position data
  • scrollEventThrottle — How often onScroll fires (ms)
  • bounces — Whether content bounces at edges (iOS)
  • keyboardDismissMode — How keyboard is dismissed (none, on-drag, interactive)

Mini-Project: Build a Horizontal Image Carousel

Create a horizontal carousel with paging and page indicators:

import React, { useState, useRef } from 'react';
import { ScrollView, View, Text, StyleSheet, Dimensions } from 'react-native';

const { width } = Dimensions.get('window');

const SLIDES = [
  { id: '1', title: 'Welcome', color: '#3498db' },
  { id: '2', title: 'Explore', color: '#e74c3c' },
  { id: '3', title: 'Learn', color: '#27ae60' },
  { id: '4', title: 'Build', color: '#9b59b6' },
  { id: '5', title: 'Ship', color: '#f39c12' },
];

export default function Carousel() {
  const [activeIndex, setActiveIndex] = useState(0);
  const scrollViewRef = useRef(null);

  const handleScroll = (e) => {
    const index = Math.round(e.nativeEvent.contentOffset.x / width);
    setActiveIndex(index);
  };

  return (
    <View style={styles.container}>
      <ScrollView
        ref={scrollViewRef}
        horizontal
        pagingEnabled
        showsHorizontalScrollIndicator={false}
        onScroll={handleScroll}
        scrollEventThrottle={16}
      >
        {SLIDES.map((slide) => (
          <View
            key={slide.id}
            style={[styles.slide, { backgroundColor: slide.color }]}
          >
            <Text style={styles.slideTitle}>{slide.title}</Text>
          </View>
        ))}
      </ScrollView>

      <View style={styles.indicators}>
        {SLIDES.map((_, index) => (
          <View
            key={index}
            style={[
              styles.indicator,
              activeIndex === index && styles.activeIndicator,
            ]}
          />
        ))}
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
  },
  slide: {
    width,
    height: 300,
    justifyContent: 'center',
    alignItems: 'center',
  },
  slideTitle: {
    color: '#ffffff',
    fontSize: 32,
    fontWeight: 'bold',
  },
  indicators: {
    flexDirection: 'row',
    justifyContent: 'center',
    paddingVertical: 16,
    gap: 8,
  },
  indicator: {
    width: 10,
    height: 10,
    borderRadius: 5,
    backgroundColor: '#bdc3c7',
  },
  activeIndicator: {
    backgroundColor: '#2c3e50',
    width: 24,
  },
});

This creates a smooth horizontal carousel with paging, scroll tracking, and dynamic page indicators.

Summary

  • ScrollView makes content scrollable when it exceeds the screen size
  • Default scrolling is vertical; set horizontal={true} for horizontal scrolling
  • Use pagingEnabled for carousel-like snapping behavior
  • contentContainerStyle styles the inner scrollable area
  • onScroll provides access to the current scroll position
  • ScrollView renders all children at once — use FlatList for large lists
  • Set scrollEventThrottle={16} for smooth 60fps scroll tracking
