Phase 7 — Advanced Concepts

Lesson Goal Optimize React Native performance with memoization, useCallback, and lazy loading.

React.memo: Preventing Unnecessary Re-renders

React.memo wraps a component to skip re-rendering if its props haven't changed:

import { memo } from 'react';

const ExpensiveCard = memo(function ExpensiveCard({ title, description }) {
  // This component only re-renders when title or description actually changes
  return (
    <View style={{ padding: 16 }}>
      <Text style={{ fontWeight: 'bold' }}>{title}</Text>
      <Text>{description}</Text>
    </View>
  );
});

// Parent re-renders, but ExpensiveCard won't if props are the same
function Parent() {
  const [count, setCount] = useState(0);
  return (
    <View>
      <Text>Count: {count}</Text>
      <ExpensiveCard title="Stable" description="This won't re-render" />
      <Pressable onPress={() => setCount(count + 1)}><Text>+1</Text></Pressable>
    </View>
  );
}

useCallback: Stable Function References

useCallback memoizes functions so they maintain the same reference across renders — critical for passing callbacks to memoized children:

function TodoList() {
  const [todos, setTodos] = useState([]);
  const [filter, setFilter] = useState('');

  // Without useCallback: this creates a new function every render
  // causing TodoItem to re-render even with React.memo
  const removeTodo = useCallback((index) => {
    setTodos(prev => prev.filter((_, i) => i !== index));
  }, []); // ← empty deps = stable reference

  return (
    <View>
      {todos.map((todo, i) => (
        <TodoItem key={i} todo={todo} onRemove={() => removeTodo(i)} />
      ))}
    </View>
  );
}

useMemo: Expensive Computations

useMemo caches the result of expensive calculations:

function FilteredList({ items, query }) {
  // Without useMemo: filters on every render
  // With useMemo: only re-filters when items or query change
  const filtered = useMemo(() => {
    return items.filter(item => item.name.toLowerCase().includes(query.toLowerCase()));
  }, [items, query]);

  return (
    <FlatList data={filtered} renderItem={({ item }) => <Text>{item.name}</Text>} />
  );
}

Lazy Loading

Split your bundle so code is only loaded when needed:

import { lazy, Suspense } from 'react';

const HeavyChart = lazy(() => import('./HeavyChart'));

function Dashboard() {
  return (
    <Suspense fallback={<Text>Loading chart...</Text>}>

    </Suspense>
  );
}
When to use what
  • React.memo: Component re-renders too often with same props
  • useCallback: Passing functions to memoized children
  • useMemo: Expensive computations (filtering, sorting, complex calculations)
  • lazy: Large components not needed on initial load
