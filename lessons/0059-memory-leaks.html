Lesson 59: Memory Leaks

Phase 7 — Advanced Concepts

Lesson Goal Identify common causes of memory leaks in React Native (timers, listeners, subscriptions), learn proper cleanup in useEffect, understand the isMounted pattern, and profile memory usage to detect and fix leaks.

What is a Memory Leak?

A memory leak occurs when objects are allocated in memory but never released. In React Native, this commonly happens when components set up subscriptions, timers, or event listeners that aren't cleaned up when the component unmounts.

Common Causes

1. Timers Not Cleared

// Memory leak — timer keeps running after unmount
const PollingComponent = () => {
  const [data, setData] = useState(null);

  useEffect(() => {
    const fetchInterval = setInterval(() => {
      fetch('/api/data').then(res => res.json()).then(setData);
    }, 5000);

    // Missing cleanup!
  }, []);

  return <Text>{data ? data.name : 'Loading...'}</Text>;
};

// Fixed — timer is cleaned up
const PollingComponent = () => {
  const [data, setData] = useState(null);

  useEffect(() => {
    const fetchInterval = setInterval(() => {
      fetch('/api/data').then(res => res.json()).then(setData);
    }, 5000);

    return () => clearInterval(fetchInterval);
  }, []);

  return <Text>{data ? data.name : 'Loading...'}</Text>;
};

2. Event Listeners Not Removed

// Memory leak — listener persists after unmount
const DimensionsComponent = () => {
  const [dimensions, setDimensions] = useState(Dimensions.get('window'));

  useEffect(() => {
    const onChange = ({ window }) => setDimensions(window);
    Dimensions.addEventListener('change', onChange);
    // Missing cleanup!
  }, []);

  return <Text>{dimensions.width} x {dimensions.height}</Text>;
};

// Fixed
const DimensionsComponent = () => {
  const [dimensions, setDimensions] = useState(Dimensions.get('window'));

  useEffect(() => {
    const subscription = Dimensions.addEventListener('change', ({ window }) => {
      setDimensions(window);
    });
    return () => subscription.remove();
  }, []);

  return <Text>{dimensions.width} x {dimensions.height}</Text>;
};

3. Async Operations After Unmount

// Memory leak — setState called after unmount
const UserProfile = ({ userId }) => {
  const [user, setUser] = useState(null);

  useEffect(() => {
    fetch(`/api/users/${userId}`)
      .then(res => res.json())
      .then(data => setUser(data)); // May run after unmount!
  }, [userId]);

  return user ? <Text>{user.name}</Text> : <ActivityIndicator />;
};

// Fixed — ignore updates if unmounted
const UserProfile = ({ userId }) => {
  const [user, setUser] = useState(null);

  useEffect(() => {
    let isMounted = true;

    fetch(`/api/users/${userId}`)
      .then(res => res.json())
      .then(data => {
        if (isMounted) setUser(data);
      });

    return () => { isMounted = false; };
  }, [userId]);

  return user ? <Text>{user.name}</Text> : <ActivityIndicator />;
};

4. WebSocket Connections

// Memory leak — WebSocket not closed
const ChatComponent = () => {
  const [messages, setMessages] = useState([]);

  useEffect(() => {
    const ws = new WebSocket('wss://example.com/chat');
    ws.onmessage = (event) => {
      setMessages(prev => [...prev, JSON.parse(event.data)]);
    };
    // Missing cleanup!
  }, []);

  return <Text>{messages.length} messages</Text>;
};

// Fixed
const ChatComponent = () => {
  const [messages, setMessages] = useState([]);

  useEffect(() => {
    const ws = new WebSocket('wss://example.com/chat');
    ws.onmessage = (event) => {
      setMessages(prev => [...prev, JSON.parse(event.data)]);
    };
    return () => ws.close();
  }, []);

  return <Text>{messages.length} messages</Text>;
};

The Cleanup Function

The useEffect cleanup function runs when the component unmounts or before the effect re-runs. Always return a cleanup function when your effect sets up subscriptions, timers, or connections.

useEffect(() => {
  // Setup
  const timer = setInterval(tick, 1000);
  const unsubscribe = EventEmitter.on('event', handler);
  const ws = new WebSocket(url);
  const subscription = Keyboard.addListener('show', onShow);

  // Cleanup — all of these will be called on unmount
  return () => {
    clearInterval(timer);
    unsubscribe();
    ws.close();
    subscription.remove();
  };
}, [dependencies]);

Profiling Memory Usage

Use the React Native Performance Monitor or Flipper to track memory usage over time.

// Monitor memory in development
import { NativeModules } from 'react-native';

// iOS: Use Instruments or Xcode Memory Graph
// Android: Use Android Studio Profiler or adb commands

// JavaScript memory profiling
console.log('Memory usage:', performance.memory?.usedJSHeapSize);

// Track component mount/unmount
useEffect(() => {
  console.log('Component mounted');
  return () => console.log('Component unmounted — check for leaks');
}, []);

Mini-Project: Fix Memory Leaks in a Component

import React, { useState, useEffect, useCallback, useRef } from 'react';
import { View, Text, TextInput, FlatList, StyleSheet, TouchableOpacity } from 'react-native';

// Fixed component with proper cleanup
const ChatScreen = () => {
  const [messages, setMessages] = useState([]);
  const [input, setInput] = useState('');
  const [isConnected, setIsConnected] = useState(false);
  const wsRef = useRef(null);
  const intervalRef = useRef(null);

  useEffect(() => {
    let isMounted = true;

    // WebSocket connection
    const ws = new WebSocket('wss://echo.websocket.org');
    wsRef.current = ws;

    ws.onopen = () => {
      if (isMounted) setIsConnected(true);
    };

    ws.onmessage = (event) => {
      if (isMounted) {
        setMessages(prev => [...prev, {
          id: Date.now().toString(),
          text: event.data,
          isMe: false,
        }]);
      }
    };

    ws.onerror = () => {
      if (isMounted) setIsConnected(false);
    };

    // Polling for connection status
    intervalRef.current = setInterval(() => {
      if (isMounted && ws.readyState === WebSocket.OPEN) {
        ws.send(JSON.stringify({ type: 'ping' }));
      }
    }, 30000);

    return () => {
      isMounted = false;
      ws.close();
      if (intervalRef.current) clearInterval(intervalRef.current);
    };
  }, []);

  const sendMessage = useCallback(() => {
    if (!input.trim() || !wsRef.current) return;

    const message = {
      id: Date.now().toString(),
      text: input.trim(),
      isMe: true,
    };

    setMessages(prev => [...prev, message]);
    wsRef.current.send(input.trim());
    setInput('');
  }, [input]);

  return (
    <View style={styles.container}>
      <View style={styles.header}>
        <Text style={styles.title}>Chat (Fixed)</Text>
        <View style={[
          styles.statusDot,
          { backgroundColor: isConnected ? '#4CAF50' : '#F44336' }
        ]} />
      </View>

      <FlatList
        data={messages}
        keyExtractor={(item) => item.id}
        renderItem={({ item }) => (
          <View style={[
            styles.message,
            item.isMe ? styles.myMessage : styles.theirMessage,
          ]}>
            <Text style={styles.messageText}>{item.text}</Text>
          </View>
        )}
        style={styles.messageList}
      />

      <View style={styles.inputRow}>
        <TextInput
          style={styles.input}
          placeholder="Type a message..."
          value={input}
          onChangeText={setInput}
        />
        <TouchableOpacity style={styles.sendBtn} onPress={sendMessage}>
          <Text style={styles.sendText}>Send</Text>
        </TouchableOpacity>
      </View>
    </View>
  );
};

const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#f5f5f5' },
  header: { flexDirection: 'row', alignItems: 'center', padding: 15, backgroundColor: '#007AFF' },
  title: { fontSize: 20, fontWeight: 'bold', color: '#fff', flex: 1 },
  statusDot: { width: 10, height: 10, borderRadius: 5 },
  messageList: { flex: 1, padding: 10 },
  message: { maxWidth: '80%', padding: 10, borderRadius: 12, marginBottom: 8 },
  myMessage: { alignSelf: 'flex-end', backgroundColor: '#007AFF' },
  theirMessage: { alignSelf: 'flex-start', backgroundColor: '#e0e0e0' },
  messageText: { color: '#fff', fontSize: 15 },
  inputRow: { flexDirection: 'row', padding: 10, gap: 10 },
  input: { flex: 1, backgroundColor: '#fff', borderRadius: 20, paddingHorizontal: 15, borderWidth: 1, borderColor: '#ddd' },
  sendBtn: { backgroundColor: '#007AFF', borderRadius: 20, paddingHorizontal: 20, justifyContent: 'center' },
  sendText: { color: '#fff', fontWeight: '600' },
});

export default ChatScreen;

Summary

  • Memory leaks occur when timers, listeners, or subscriptions aren't cleaned up on unmount
  • Always return a cleanup function from useEffect when setting up side effects
  • The isMounted pattern prevents setState calls after unmount
  • Use ref to hold WebSocket instances and close them in cleanup
  • Profile memory usage with React Native Performance Monitor or Flipper
  • Common culprits: setInterval, EventEmitter, WebSocket, Dimensions.addEventListener
