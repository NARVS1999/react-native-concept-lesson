Lesson 0010: State Sharing with Context API

Phase 4 — Integration Concepts

Lesson Goal Share state across deeply nested components using Context API, and persist data locally with AsyncStorage.

The Prop Drilling Problem

When you need to pass data from a top-level component to a deeply nested child, you must pass it through every intermediate component — even if they don't use it. This is called prop drilling.

Context API solves this by letting you provide data to the entire component tree without threading props.

Creating Context

import { createContext, useContext, useState } from 'react';

// 1. Create the context
const ThemeContext = createContext();

// 2. Create a provider
function ThemeProvider({ children }) {
  const [isDark, setIsDark] = useState(false);

  return (
    <ThemeContext.Provider value={{ isDark, toggleTheme: () => setIsDark(!isDark) }}>
      {children}
    </ThemeContext.Provider>
  );
}

// 3. Use it anywhere in the tree
function ThemedButton() {
  const { isDark, toggleTheme } = useContext(ThemeContext);
  return (
    <Pressable onPress={toggleTheme}>
      <Text style={{ color: isDark ? '#fff' : '#000' }}>
        Toggle Theme
      </Text>
    </Pressable>
  );
}

// 4. Wrap your app with the provider
function App() {
  return (
    <ThemeProvider>
      <ThemedButton />
    </ThemeProvider>
  );
}
Key Insight useContext lets any component read the nearest context value. No prop drilling needed.

AsyncStorage: Local Persistence

AsyncStorage persists key-value data locally on the device — survives app restarts.

import AsyncStorage from '@react-native-async-storage/async-storage';

// Save data
await AsyncStorage.setItem('user_token', 'abc123');

// Read data
const token = await AsyncStorage.getItem('user_token');

// Remove data
await AsyncStorage.removeItem('user_token');

// Store objects (must JSON stringify)
await AsyncStorage.setItem('settings', JSON.stringify({ darkMode: true }));
const settings = JSON.parse(await AsyncStorage.getItem('settings'));
Storage Limits AsyncStorage is unencrypted and limited to ~6MB. For sensitive data or larger storage, use MMKV or SQLite (covered in a later lesson).

Summary

  • Context API eliminates prop drilling for shared state
  • Create context with createContext, provide with Context.Provider, consume with useContext
  • AsyncStorage persists key-value data locally on the device
  • Always JSON.stringify objects before storing, JSON.parse when reading
