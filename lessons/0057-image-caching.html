Lesson 57: Image Caching

Phase 7 — Advanced Concepts

Lesson Goal Learn how to use FastImage for advanced image handling in React Native, including priority control, cache management, preloading, fallback images, and understanding disk vs memory caching strategies.

Why FastImage?

React Native's built-in <Image> component has limited caching control. FastImage is a popular alternative that provides advanced caching, priority loading, preloading, and fallback image support.

npm install react-native-fast-image

Basic FastImage Usage

import FastImage from 'react-native-fast-image';

const Avatar = ({ uri, size = 50 }) => (
  <FastImage
    style={{ width: size, height: size, borderRadius: size / 2 }}
    source={{ uri }}
    resizeMode={FastImage.resizeMode.cover}
  />
);

export default Avatar;

Priority Control

FastImage allows you to set load priority, ensuring critical images load first.

// High priority — loads immediately (e.g., hero image, avatar)
<FastImage
  source={{
    uri: 'https://example.com/hero.jpg',
    priority: FastImage.priority.high,
  }}
  style={{ width: 400, height: 200 }}
  resizeMode={FastImage.resizeMode.cover}
/>

// Normal priority — default
<FastImage
  source={{
    uri: 'https://example.com/normal.jpg',
    priority: FastImage.priority.normal,
  }}
  style={{ width: 400, height: 200 }}
/>

// Low priority — loads when resources are available
<FastImage
  source={{
    uri: 'https://example.com/thumbnail.jpg',
    priority: FastImage.priority.low,
  }}
  style={{ width: 100, height: 100 }}
/>

Cache Control

FastImage gives you fine-grained control over how images are cached.

// Force reload — bypass cache
<FastImage
  source={{
    uri: 'https://example.com/image.jpg',
    cache: FastImage.cacheControl.immutable,
  }}
  style={styles.image}
/>

// Web-controlled caching (respects HTTP cache headers)
<FastImage
  source={{
    uri: 'https://example.com/image.jpg',
    cache: FastImage.cacheControl.web,
  }}
  style={styles.image}
/>

// Only use cached version — never fetch from network
<FastImage
  source={{
    uri: 'https://example.com/image.jpg',
    cache: FastImage.cacheControl.cacheOnly,
  }}
  style={styles.image}
/>

Preloading Images

Preload images before they're needed to ensure instant display.

import FastImage from 'react-native-fast-image';

// Preload a single image
FastImage.preload([
  {
    uri: 'https://example.com/hero.jpg',
    priority: FastImage.priority.high,
  },
]);

// Preload multiple images
FastImage.preload([
  { uri: 'https://example.com/banner1.jpg' },
  { uri: 'https://example.com/banner2.jpg' },
  { uri: 'https://example.com/banner3.jpg' },
]);

// Preload with cache control
FastImage.preload([{
  uri: 'https://example.com/image.jpg',
  cache: FastImage.cacheControl.immutable,
}]);

Fallback Images

Show a placeholder or error image while the main image loads or if it fails.

const ProductImage = ({ imageUrl }) => (
  <FastImage
    style={styles.productImage}
    source={{
      uri: imageUrl,
      priority: FastImage.priority.normal,
    }}
    defaultSource={require('./assets/placeholder.png')}
    resizeMode={FastImage.resizeMode.cover}
  />
);

// With error handling
const SafeImage = ({ uri, fallbackUri }) => {
  const [source, setSource] = useState({ uri });

  return (
    <FastImage
      style={styles.image}
      source={source}
      onError={() => setSource({ uri: fallbackUri })}
      resizeMode={FastImage.resizeMode.cover}
    />
  );
};

Disk vs Memory Caching

Cache TypeStoragePersistenceSpeed
Memory CacheRAMUntil app restartInstant access
Disk CacheDevice storagePersists across sessionsFast (no network)
No CacheN/AN/ANetwork fetch every time

FastImage uses both memory and disk caching. Images are first loaded into memory for instant access, then saved to disk for persistence across app sessions.

Event Handlers

<FastImage
  source={{ uri: 'https://example.com/image.jpg' }}
  style={styles.image}
  onLoadStart={() => console.log('Loading started')}
  onProgress={({ nativeEvent }) => {
    const percent = (nativeEvent.loaded / nativeEvent.total) * 100;
    console.log(`Loading: ${percent.toFixed(0)}%`);
  }}
  onLoad={({ nativeEvent }) => {
    console.log('Image loaded:', nativeEvent.width, 'x', nativeEvent.height);
  }}
  onError={() => console.log('Image failed to load')}
  resizeMode={FastImage.resizeMode.cover}
/>

Mini-Project: Build an Image Gallery with FastImage Caching

import React, { useState, useCallback } from 'react';
import { View, Text, FlatList, Dimensions, StyleSheet, ActivityIndicator } from 'react-native';
import FastImage from 'react-native-fast-image';

const { width } = Dimensions.get('window');
const IMAGE_SIZE = width / 2 - 15;

const IMAGES = [
  { id: '1', uri: 'https://picsum.photos/400/400?random=1' },
  { id: '2', uri: 'https://picsum.photos/400/400?random=2' },
  { id: '3', uri: 'https://picsum.photos/400/400?random=3' },
  { id: '4', uri: 'https://picsum.photos/400/400?random=4' },
  { id: '5', uri: 'https://picsum.photos/400/400?random=5' },
  { id: '6', uri: 'https://picsum.photos/400/400?random=6' },
  { id: '7', uri: 'https://picsum.photos/400/400?random=7' },
  { id: '8', uri: 'https://picsum.photos/400/400?random=8' },
  { id: '9', uri: 'https://picsum.photos/400/400?random=9' },
  { id: '10', uri: 'https://picsum.photos/400/400?random=10' },
];

// Preload images on app start
FastImage.preload(IMAGES.map(img => ({
  uri: img.uri,
  priority: FastImage.priority.normal,
})));

const GalleryItem = React.memo(({ item }) => {
  const [loading, setLoading] = useState(true);

  return (
    <View style={styles.imageContainer}>
      {loading && (
        <View style={styles.loader}>
          <ActivityIndicator color="#007AFF" />
        </View>
      )}
      <FastImage
        style={styles.image}
        source={{
          uri: item.uri,
          priority: FastImage.priority.normal,
          cache: FastImage.cacheControl.immutable,
        }}
        resizeMode={FastImage.resizeMode.cover}
        onLoad={() => setLoading(false)}
        onError={() => setLoading(false)}
      />
    </View>
  );
});

const ImageGallery = () => {
  const renderItem = useCallback(({ item }) => (
    <GalleryItem item={item} />
  ), []);

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Cached Image Gallery</Text>
      <FlatList
        data={IMAGES}
        keyExtractor={(item) => item.id}
        numColumns={2}
        renderItem={renderItem}
        contentContainerStyle={styles.list}
      />
    </View>
  );
};

const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#f5f5f5' },
  title: { fontSize: 24, fontWeight: 'bold', padding: 15, textAlign: 'center' },
  list: { padding: 10 },
  imageContainer: {
    width: IMAGE_SIZE,
    height: IMAGE_SIZE,
    margin: 5,
    borderRadius: 8,
    overflow: 'hidden',
    backgroundColor: '#eee',
  },
  image: { width: '100%', height: '100%' },
  loader: {
    position: 'absolute',
    top: 0,
    left: 0,
    right: 0,
    bottom: 0,
    justifyContent: 'center',
    alignItems: 'center',
    zIndex: 1,
  },
});

export default ImageGallery;

Summary

  • FastImage provides advanced caching, priority loading, and preloading over React Native's Image
  • Priority settings (high, normal, low) control load order for critical images
  • Cache control options: immutable (force reload), web (HTTP headers), cacheOnly (offline only)
  • Preload images before they're needed for instant display
  • Fallback images handle loading errors and improve UX
  • FastImage uses both memory and disk caching for optimal performance
