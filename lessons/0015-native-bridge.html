Lesson 0015: Native Bridge and Modules

Phase 5 — Architectural Concepts

Lesson Goal Understand how React Native bridges to native code, when to use native modules, and the new Turbo Modules architecture.

The Bridge (Old Architecture)

In the old architecture, React Native communicates between JavaScript and native code through an asynchronous bridge:

JS Thread → Bridge → Native Thread → Bridge → JS Thread

This is asynchronous — JS sends a message and continues. The native side processes it and sends a message back. This causes performance bottlenecks for fast animations and heavy UI updates.

Native Modules

Native Modules let you call native iOS/Android code from JavaScript. Use them when React Native doesn't expose an API you need:

// JavaScript side
import { NativeModules } from 'react-native';
const { BatteryModule } = NativeModules;

const level = await BatteryModule.getBatteryLevel();

Native Modules are written in Swift/Objective-C (iOS) and Kotlin/Java (Android). They require knowledge of the native platform.

When to use Native Modules Only when no existing library provides the functionality. Writing native code adds complexity and platform-specific maintenance.

Turbo Modules (New Architecture)

Turbo Modules are the new architecture's replacement for Native Modules. Key improvements:

FeatureNative Modules (Old)Turbo Modules (New)
LoadingEager (all loaded at startup)Lazy (loaded on demand)
CommunicationAsynchronous JSON bridgeSynchronous (JSI interface)
Type SafetyManualCodegen with TypeScript/Flow specs
PerformanceSlowerFaster (no serialization)
// Turbo Module spec (TypeScript)
import type { TurboModule } from 'react-native';
import { TurboModuleRegistry } from 'react-native';

export interface Spec extends TurboModule {
  getBatteryLevel(): Promise<number>;
}

export default TurboModuleRegistry.getEnforcing<Spec>('BatteryModule');

File System

React Native provides APIs for file operations, typically through libraries:

import * as FileSystem from 'expo-file-system';

// Write a file
await FileSystem.writeAsStringAsync(
  FileSystem.documentDirectory + 'notes.txt',
  'Hello, world!'
);

// Read a file
const content = await FileSystem.readAsStringAsync(
  FileSystem.documentDirectory + 'notes.txt'
);

// Check if file exists
const info = await FileSystem.getInfoAsync(
  FileSystem.documentDirectory + 'notes.txt'
);

Summary

  • The old bridge is asynchronous and causes performance issues
  • Native Modules let you call native code from JavaScript
  • Turbo Modules are lazy-loaded and synchronous via JSI
  • Only write native modules when no library provides the functionality
