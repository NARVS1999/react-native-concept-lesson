Lesson 0021: NavigationContainer

Phase 3 — Implementation Concepts

Lesson Goal Understand the NavigationContainer component, how to wrap your app with it, and configure navigation state and linking.

What is NavigationContainer?

NavigationContainer is the root component for React Navigation. It manages the navigation state and provides the navigation context to your app.

Every React Navigation app must have exactly one NavigationContainer component at the root.

Basic Setup

import React from 'react';
import { NavigationContainer } from '@react-navigation/native';
import { createNativeStackNavigator } from '@react-navigation/native-stack';

const Stack = createNativeStackNavigator();

function App() {
  return (
    <NavigationContainer>
      <Stack.Navigator>
        <Stack.Screen name="Home" component={HomeScreen} />
        <Stack.Screen name="Details" component={DetailsScreen} />
      </Stack.Navigator>
    </NavigationContainer>
  );
}

Wrapping Your App

The NavigationContainer should wrap your entire navigation structure. Place it in your root component (usually App.js):

// App.js
import React from 'react';
import { NavigationContainer } from '@react-navigation/native';
import HomeNavigator from './navigation/HomeNavigator';

export default function App() {
  return (
    <NavigationContainer>
      <HomeNavigator />
    </NavigationContainer>
  );
}

Navigation State Management

NavigationContainer manages the navigation state internally. You can access and modify the state using hooks:

import { useNavigationContainerRef } from '@react-navigation/native';

function App() {
  const navigationRef = useNavigationContainerRef();

  return (
    <NavigationContainer ref={navigationRef}>
      {/* Your navigators */}
    </NavigationContainer>
  );
}

Linking Configuration

Linking configuration maps URLs to screens for deep linking:

const linking = {
  prefixes: ['myapp://', 'https://myapp.com'],
  config: {
    screens: {
      Home: '',
      Details: 'details/:id',
      Profile: 'user/:userId',
    },
  },
};

function App() {
  return (
    <NavigationContainer linking={linking}>
      <Stack.Navigator>
        {/* screens */}
      </Stack.Navigator>
    </NavigationContainer>
  );
}

Event Listeners

You can listen to navigation events:

function App() {
  return (
    <NavigationContainer
      onReady={() => {
        console.log('Navigation is ready');
      }}
      onStateChange={(state) => {
        console.log('Navigation state changed:', state);
      }}
    >
      {/* Your navigators */}
    </NavigationContainer>
  );
}

Mini-Project: Set Up NavigationContainer with Basic Config

Create a basic React Navigation setup with NavigationContainer:

# Install dependencies
npm install @react-navigation/native
npm install react-native-screens react-native-safe-area-context

# Create navigation directory
mkdir navigation

Create navigation/HomeNavigator.js:

import React from 'react';
import { createNativeStackNavigator } from '@react-navigation/native-stack';
import HomeScreen from '../screens/HomeScreen';
import DetailsScreen from '../screens/DetailsScreen';

const Stack = createNativeStackNavigator();

export default function HomeNavigator() {
  return (
    <Stack.Navigator>
      <Stack.Screen name="Home" component={HomeScreen} />
      <Stack.Screen name="Details" component={DetailsScreen} />
    </Stack.Navigator>
  );
}

Update App.js:

import React from 'react';
import { NavigationContainer } from '@react-navigation/native';
import HomeNavigator from './navigation/HomeNavigator';

export default function App() {
  return (
    <NavigationContainer>
      <HomeNavigator />
    </NavigationContainer>
  );
}

Summary

  • NavigationContainer is the root component for React Navigation
  • It manages navigation state and provides context to child navigators
  • Only one NavigationContainer should exist at the app root
  • Linking configuration enables deep linking and URL mapping
  • Event listeners can track navigation state changes
