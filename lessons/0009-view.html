Lesson 9: View

Phase 2 — Core Concepts

Lesson Goal By the end of this lesson, you will be able to use the View component to build layouts, nest Views for complex structures, handle touch events, and apply styles to container elements in React Native.

What is a View?

The View component is the most fundamental building block in React Native. Think of it as the equivalent of an HTML <div>. It is a container that supports layout with Flexbox, styling, touch handling, and accessibility.

Every screen in your app is built using Views. You will never build a React Native app without using View — it is everywhere.

Basic View Usage

At its simplest, a View is a container you put things inside:

import React from 'react';
import { View, Text } from 'react-native';

export default function App() {
  return (
    <View>
      <Text>Hello World</Text>
    </View>
  );
}

Even this simple example uses a View. In React Native, every component must be inside a View for proper layout.

Styling a View

Views accept a style prop. You can style background color, dimensions, margins, padding, borders, and more.

import React from 'react';
import { View, Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <Text style={styles.text}>Styled Box</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    backgroundColor: '#3498db',
    padding: 20,
    margin: 10,
    borderRadius: 8,
    alignItems: 'center',
  },
  text: {
    color: '#ffffff',
    fontSize: 18,
  },
});

This creates a blue box with white text, centered content, rounded corners, and spacing around it.

Nesting Views

You can nest Views inside other Views to create complex layouts. This is the core pattern of React Native UI development.

import React from 'react';
import { View, Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <View style={styles.outer}>
      <View style={styles.header}>
        <Text style={styles.headerText}>Header</Text>
      </View>
      <View style={styles.content}>
        <View style={styles.card}>
          <Text>Card 1</Text>
        </View>
        <View style={styles.card}>
          <Text>Card 2</Text>
        </View>
      </View>
      <View style={styles.footer}>
        <Text>Footer</Text>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  outer: { flex: 1 },
  header: { backgroundColor: '#2c3e50', padding: 20 },
  headerText: { color: 'white', fontSize: 20 },
  content: { flex: 1, padding: 10 },
  card: { backgroundColor: '#ecf0f1', padding: 15, marginBottom: 10, borderRadius: 5 },
  footer: { backgroundColor: '#2c3e50', padding: 10, alignItems: 'center' },
});

This creates a layout with a header, scrollable content area with cards, and a footer — all using nested Views.

View with Touch Handling

Views can respond to touch events using the onStartShouldSetResponder family of props. However, for most touch interactions, you should use Pressable or TouchableOpacity instead.

import React from 'react';
import { View, Text, Alert, StyleSheet } from 'react-native';

export default function App() {
  return (
    <View
      style={styles.touchable}
      onStartShouldSetResponder={() => true}
      onResponderGrant={() => Alert.alert('View Pressed!')}
    >
      <Text>Tap Me</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  touchable: {
    backgroundColor: '#e74c3c',
    padding: 20,
    alignItems: 'center',
    borderRadius: 8,
  },
});

While this works, prefer Pressable for touch interactions — it provides better feedback and more features.

View Accessibility

Views support accessibility props that help screen readers understand your app. Use accessibilityLabel, accessibilityRole, and accessibilityHint.

import React from 'react';
import { View, Text } from 'react-native';

export default function App() {
  return (
    <View
      accessibilityLabel="Profile section"
      accessibilityRole="header"
      accessibilityHint="Contains user profile information"
    >
      <Text>My Profile</Text>
    </View>
  );
}

View Props Summary

Here are the key props that View supports:

  • style — Style object for the View
  • children — Nested components
  • onStartShouldSetResponder — Handle touch start
  • onResponderGrant — Called when touch is granted
  • onResponderRelease — Called when touch is released
  • accessibilityLabel — Label for screen readers
  • accessibilityRole — Role (header, button, etc.)
  • accessible — Whether the View is an accessible element

Common Patterns

Here are some common View patterns you will use frequently:

// Centering content
<View style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}>
  <Text>Centered!</Text>
</View>

// Creating a divider
<View style={{ height: 1, backgroundColor: '#ccc', marginVertical: 10 }} />

// Creating a row layout
<View style={{ flexDirection: 'row', gap: 10 }}>
  <View style={{ width: 50, height: 50, backgroundColor: 'red' }} />
  <View style={{ width: 50, height: 50, backgroundColor: 'blue' }} />
</View>

Mini-Project: Build a Layout with Nested Views

Create a profile card layout using nested Views with the following structure:

import { View, Text, StyleSheet } from 'react-native';

Summary

  • View is the fundamental container component in React Native, equivalent to <div> in web
  • Views support Flexbox layout, styling, touch handling, and accessibility
  • You can nest Views inside other Views to create complex layouts
  • For touch interactions, prefer Pressable over View's responder system
  • Views accept styles through the style prop
  • Use accessibility props like accessibilityLabel and accessibilityRole
  • Every screen in your app is composed of Views
