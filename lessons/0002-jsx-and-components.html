Lesson 0002: JSX and Components

Phase 1 — Foundational Concepts

Lesson Goal Write JSX to describe UI and create reusable components — the two building blocks of every React Native app.

What is JSX?

JSX is a syntax that looks like HTML but lives inside JavaScript. It lets you describe what your UI should look like declaratively.

import { Text, View } from 'react-native';

function Greeting() {
  return (
    <View>
      <Text>Hello, world!</Text>
    </View>
  );
}

JSX is not HTML. Notice:

  • Use className on web — use style on React Native
  • Use for on web — use htmlFor in JSX
  • All tags must be closed: <Image /> not <Image>
  • One root element per component (wrap with <View>)

What is a Component?

A component is a reusable function that returns JSX. Think of it as a custom UI building block.

// A simple component
function WelcomeBanner() {
  return (
    <View style={{ padding: 20 }}>
      <Text>Welcome back!</Text>
    </View>
  );
}

// Using the component
function App() {
  return (
    <View>
      <WelcomeBanner />
      <WelcomeBanner />
    </View>
  );
}
Key Insight Components must start with a capital letter. <greeting /> is treated as an HTML tag, but <Greeting /> is treated as a component.

Core React Native Components

React Native provides built-in components instead of HTML tags:

HTMLReact NativePurpose
<div><View>Container for layout
<p>, <span><Text>Display text (all text must be in Text)
<img><Image>Display images
<button><Pressable>Handle touch/tap
<input><TextInput>Text input field
<div style="overflow:auto"><ScrollView>Scrollable container
Important In React Native, you cannot use plain strings inside a <View>. All text must be wrapped in <Text>. This will crash your app.

Composing Components

The power of components is composition — building complex UIs by combining simple pieces:

function Card({ title, description }) {
  return (
    <View style={{ padding: 16, backgroundColor: '#fff', borderRadius: 8 }}>
      <Text style={{ fontSize: 18, fontWeight: 'bold' }}>{title}</Text>
      <Text style={{ marginTop: 8 }}>{description}</Text>
    </View>
  );
}

function App() {
  return (
    <View style={{ flex: 1, padding: 20 }}>
      <Card title="Lesson 1" description="What is React Native?" />
      <Card title="Lesson 2" description="JSX and Components" />
    </View>
  );
}

Mini-Project: Build a Profile Card

Create a component called ProfileCard that displays a name, role, and avatar placeholder. Use it twice in your App component with different data.

function ProfileCard({ name, role }) {
  return (
    <View style={{ padding: 16, margin: 8, backgroundColor: '#f0f0f0', borderRadius: 8 }}>
      <Text style={{ fontSize: 18, fontWeight: 'bold' }}>{name}</Text>
      <Text style={{ color: '#666' }}>{role}</Text>
    </View>
  );
}

// Use it:
// <ProfileCard name="Ana" role="React Native Developer" />

Summary

  • JSX is HTML-like syntax inside JavaScript for describing UI
  • Components are reusable functions that return JSX
  • <View>, <Text>, <Image> replace HTML div, p, img
  • All text must be wrapped in <Text> — raw strings in View crash the app
  • Components must start with a capital letter
