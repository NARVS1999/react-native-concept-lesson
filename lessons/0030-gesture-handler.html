Lesson 0030: Gesture Handler

Phase 4 — Integration Concepts

Lesson Goal Implement gesture recognition using react-native-gesture-handler, combine gestures with React Native Reanimated for smooth animations, and build interactive components like swipeable cards.

Introduction to Gesture Handler

React Native Gesture Handler is a library that provides native-driven gesture recognition. It replaces the JavaScript-based responder system with native handlers that run on the UI thread, resulting in 60fps gesture interactions without blocking the main thread.

Key benefits include better performance, more precise gesture recognition, and support for simultaneous and composed gestures.

GestureHandlerRootView

Every app using Gesture Handler must wrap its content in a GestureHandlerRootView. This is analogous to React Navigation's NavigationContainer:

import { GestureHandlerRootView } from 'react-native-gesture-handler';

export default function App() {
  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      {/* Your app content */}
    </GestureHandlerRootView>
  );
}

PanGesture for Dragging

The Pan gesture detects dragging motions. Combined with Reanimated's useAnimatedStyle, you can create smooth drag interactions:

import { Gesture, GestureDetector } from 'react-native-gesture-handler';
import Animated, { useSharedValue, useAnimatedStyle, withSpring } from 'react-native-reanimated';

function DraggableBox() {
  const translateX = useSharedValue(0);
  const translateY = useSharedValue(0);

  const panGesture = Gesture.Pan()
    .onUpdate((event) => {
      translateX.value = event.translationX;
      translateY.value = event.translationY;
    })
    .onEnd(() => {
      translateX.value = withSpring(0);
      translateY.value = withSpring(0);
    });

  const animatedStyle = useAnimatedStyle(() => ({
    transform: [
      { translateX: translateX.value },
      { translateY: translateY.value },
    ],
  }));

  return (
    <GestureDetector gesture={panGesture}>
      <Animated.View
        style={[{ width: 100, height: 100, backgroundColor: 'blue' }, animatedStyle]}
      />
    </GestureDetector>
  );
}

TapGesture for Taps

The Tap gesture detects tap and double-tap interactions:

const tapGesture = Gesture.Tap()
  .numberOfTaps(2)
  .onEnd((event, success) => {
    if (success) {
      console.log('Double tapped at', event.absoluteX, event.absoluteY);
    }
  });

return (
  <GestureDetector gesture={tapGesture}>
    <View style={{ width: 200, height: 200, backgroundColor: 'red' }} />
  </GestureDetector>
);

Swipeable Component

The Swipeable component provides built-in left/right swipe actions, commonly used for delete or archive actions in lists:

import { Swipeable } from 'react-native-gesture-handler';

function SwipeableItem({ onDelete }) {
  const renderRightActions = () => (
    <TouchableOpacity onPress={onDelete}>
      <View style={{ backgroundColor: 'red', justifyContent: 'center', padding: 20 }}>
        <Text style={{ color: 'white' }}>Delete</Text>
      </View>
    </TouchableOpacity>
  );

  return (
    <Swipeable renderRightActions={renderRightActions}>
      <View style={{ padding: 20, backgroundColor: 'white' }}>
        <Text>Swipe me left to delete</Text>
      </View>
    </Swipeable>
  );
}

Composing Gestures

You can combine multiple gestures using Gesture.Exclusive or Gesture.Simultaneous:

// Only one gesture wins (priority order)
const composed = Gesture.Exclusive(panGesture, tapGesture);

// Both gestures can run at the same time
const simultaneous = Gesture.Simultaneous(panGesture, rotateGesture);

Mini-Project: Swipeable Card

Build a card component that can be swiped left to reveal a delete action and right to reveal a favorite action, with smooth spring animations.

import React from 'react';
import { View, Text, StyleSheet } from 'react-native';
import { Gesture, GestureDetector } from 'react-native-gesture-handler';
import Animated, {
  useSharedValue,
  useAnimatedStyle,
  withSpring,
  interpolateColor,
} from 'react-native-reanimated';

export default function SwipeableCard({ title, onDelete, onFavorite }) {
  const translateX = useSharedValue(0);
  const cardWidth = 300;
  const threshold = cardWidth * 0.3;

  const panGesture = Gesture.Pan()
    .activeOffsetX([-20, 20])
    .onUpdate((event) => {
      translateX.value = event.translationX;
    })
    .onEnd((event) => {
      if (event.translationX < -threshold) {
        translateX.value = withSpring(-cardWidth);
        onDelete?.();
      } else if (event.translationX > threshold) {
        translateX.value = withSpring(cardWidth);
        onFavorite?.();
      } else {
        translateX.value = withSpring(0);
      }
    });

  const animatedStyle = useAnimatedStyle(() => ({
    transform: [{ translateX: translateX.value }],
    backgroundColor: interpolateColor(
      translateX.value,
      [-cardWidth, 0, cardWidth],
      ['#ff4444', '#ffffff', '#44ff44']
    ),
  }));

  return (
    <View style={styles.container}>
      <View style={styles.actionLeft}>
        <Text style={styles.actionText}>FAVORITE</Text>
      </View>
      <View style={styles.actionRight}>
        <Text style={styles.actionText}>DELETE</Text>
      </View>
      <GestureDetector gesture={panGesture}>
        <Animated.View style={[styles.card, animatedStyle]}>
          <Text style={styles.cardTitle}>{title}</Text>
        </Animated.View>
      </GestureDetector>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { marginVertical: 8, alignItems: 'center' },
  card: {
    width: 300,
    padding: 20,
    borderRadius: 12,
    elevation: 4,
    shadowColor: '#000',
    shadowOffset: { width: 0, height: 2 },
    shadowOpacity: 0.25,
    shadowRadius: 4,
  },
  cardTitle: { fontSize: 18, fontWeight: '600', color: '#333' },
  actionLeft: {
    position: 'absolute', left: 10, top: 8,
    backgroundColor: '#44ff44', padding: 20, borderRadius: 8,
  },
  actionRight: {
    position: 'absolute', right: 10, top: 8,
    backgroundColor: '#ff4444', padding: 20, borderRadius: 8,
  },
  actionText: { color: 'white', fontWeight: 'bold' },
});

Summary

  • Gesture Handler provides native-driven gesture recognition running on the UI thread for 60fps performance
  • Wrap your app root in GestureHandlerRootView before using any gesture components
  • Gesture.Pan detects drag motions with translation and velocity values
  • Gesture.Tap detects single and multi-tap interactions
  • Combine gestures with React Native Reanimated for smooth, performant animations
  • The built-in Swipeable component simplifies left/right action patterns
