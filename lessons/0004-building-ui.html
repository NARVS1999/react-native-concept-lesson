Lesson 0004: Building UI with Core Components

Phase 2 — Core Concepts

Lesson Goal Use View, Text, Pressable, and ScrollView to build interactive user interfaces.

View: Your Layout Container

The <View> component is the fundamental building block. It acts like a div — a container for layout and styling.

import { View, Text } from 'react-native';

function Card() {
  return (
    <View style={{ padding: 16, backgroundColor: '#e3f2fd', borderRadius: 8 }}>
      <Text>This is inside a View</Text>
    </View>
  );
}

<View> supports Flexbox layout, touch handling, and accessibility. It is used in almost every React Native screen.

Text: Displaying Content

All visible text in React Native must be inside <Text>. You can nest Text components for inline styling:

<Text style={{ fontSize: 16 }}>
  Hello <Text style={{ fontWeight: 'bold' }}>world</Text>!
</Text>
Key Insight <Text> supports numberOfLines, ellipsizeMode, and selectable props for controlling text overflow and behavior.

Pressable: Handling Touch

<Pressable> wraps any component to make it respond to taps, long presses, and other gestures:

import { Pressable, Text, Alert } from 'react-native';

function MyButton() {
  return (
    <Pressable
      onPress={() => Alert.alert('Pressed!')}
      onLongPress={() => Alert.alert('Long pressed!')}
      style={({ pressed }) => ({
        padding: 12,
        backgroundColor: pressed ? '#1976d2' : '#2196f3',
        borderRadius: 8,
      })}
    >
      <Text style={{ color: '#fff', textAlign: 'center' }}>Tap Me</Text>
    </Pressable>
  );
}

The style prop accepts a function that receives { pressed } — letting you style the button differently when pressed.

ScrollView: Scrolling Content

When content overflows the screen, <ScrollView> makes it scrollable:

import { ScrollView, View, Text } from 'react-native';

function LongList() {
  return (
    <ScrollView style={{ flex: 1 }}>
      {Array.from({ length: 20 }, (_, i) => (
        <View key={i} style={{ padding: 16, borderBottomWidth: 1, borderBottomColor: '#eee' }}>
          <Text>Item {i + 1}</Text>
        </View>
      ))}
    </ScrollView>
  );
}
Performance Warning <ScrollView> renders ALL children at once. For long lists (50+ items), use <FlatList> instead — we cover that in a later lesson.

Mini-Project: Contact List Card

Build a scrollable list of 5 contact cards. Each card should show a name, role, and a "Message" button that shows an alert with the contact's name.

function ContactCard({ name, role }) {
  return (
    <View style={{ padding: 16, margin: 8, backgroundColor: '#fff', borderRadius: 8, elevation: 2 }}>
      <Text style={{ fontSize: 18, fontWeight: 'bold' }}>{name}</Text>
      <Text style={{ color: '#666', marginBottom: 8 }}>{role}</Text>
      <Pressable
        onPress={() => Alert.alert('Message', `Send message to ${name}?`)}
        style={{ padding: 8, backgroundColor: '#2196f3', borderRadius: 4 }}
      >
        <Text style={{ color: '#fff', textAlign: 'center' }}>Message</Text>
      </Pressable>
    </View>
  );
}

Summary

  • <View> is your layout container (like a div)
  • <Text> wraps all visible text — nest for inline styling
  • <Pressable> handles touch with onPress and onLongPress
  • <ScrollView> makes content scrollable — use <FlatList> for long lists
