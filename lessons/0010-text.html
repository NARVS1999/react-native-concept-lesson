Lesson 10: Text

Phase 2 — Core Concepts

Lesson Goal By the end of this lesson, you will be able to display and format text in React Native, use nested Text components for inline styling, control text overflow, and handle text selection and font sizing.

What is a Text Component?

The Text component is used to display text in React Native. Unlike the web where you can put text anywhere, in React Native, all text must be wrapped in a Text component. You cannot place a string directly inside a View.

import React from 'react';
import { View, Text } from 'react-native';

export default function App() {
  return (
    <View>
      <Text>Hello World!</Text>
    </View>
  );
}

If you try to put a string directly in a View without wrapping it in Text, you will get an error.

Styling Text

Text supports a wide range of style props for controlling appearance:

import React from 'react';
import { Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <Text style={styles.title}>
      Welcome to React Native
    </Text>
  );
}

const styles = StyleSheet.create({
  title: {
    fontSize: 24,
    fontWeight: 'bold',
    color: '#2c3e50',
    textAlign: 'center',
    fontFamily: 'Roboto',
    letterSpacing: 1,
    lineHeight: 32,
  },
});

Common text style properties include: fontSize, fontWeight, color, fontFamily, textAlign, lineHeight, letterSpacing, textDecorationLine, and textTransform.

Nesting Text Components

You can nest Text components inside each other to apply inline formatting. This is similar to using <span> tags in HTML.

import React from 'react';
import { Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <Text style={styles.paragraph}>
      This is <Text style={styles.bold}>bold</Text> text and
      this is <Text style={styles.italic}>italic</Text> text.
      You can also use <Text style={styles.colored}>colors</Text>.
    </Text>
  );
}

const styles = StyleSheet.create({
  paragraph: { fontSize: 16, color: '#333' },
  bold: { fontWeight: 'bold' },
  italic: { fontStyle: 'italic' },
  colored: { color: '#e74c3c', fontWeight: 'bold' },
});

This pattern is extremely useful for creating rich text content with mixed formatting.

numberOfLines and ellipsizeMode

You can limit the number of lines displayed and control how overflow text is truncated:

import React from 'react';
import { Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <Text
      style={styles.truncated}
      numberOfLines={2}
      ellipsizeMode="tail"
    >
      This is a very long text that will be truncated after
      two lines. The remaining text will be replaced with
      an ellipsis character at the end.
    </Text>
  );
}

const styles = StyleSheet.create({
  truncated: {
    fontSize: 16,
    lineHeight: 22,
  },
});

The ellipsizeMode options are: "head", "middle", "tail" (default), and "clip".

Selectable Text

By default, text in React Native is not selectable. You can enable text selection with the selectable prop:

import React from 'react';
import { Text } from 'react-native';

export default function App() {
  return (
    <Text selectable={true}>
      You can long-press this text to select and copy it.
    </Text>
  );
}

adjustsFontSizeToFit

This prop automatically scales down the font size to fit the text within its container:

import React from 'react';
import { Text, View, StyleSheet } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <Text
        style={styles.autoSize}
        adjustsFontSizeToFit
        numberOfLines={1}
      >
        This text will shrink to fit!
      </Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { width: 200, height: 50, backgroundColor: '#ecf0f1' },
  autoSize: { fontSize: 24 },
});

Pressable Text

Text components can be made pressable by wrapping them in Pressable or by using the onPress prop (which is actually from a wrapping touchable):

import React from 'react';
import { Text, Alert, StyleSheet } from 'react-native';

export default function App() {
  return (
    <Text
      style={styles.link}
      onPress={() => Alert.alert('Link Pressed!')}
    >
      Click here for more info
    </Text>
  );
}

const styles = StyleSheet.create({
  link: {
    color: '#3498db',
    textDecorationLine: 'underline',
    fontSize: 16,
  },
});

Text Props Summary

  • numberOfLines — Limits the number of displayed lines
  • ellipsizeMode — How truncated text is shown (head, middle, tail, clip)
  • selectable — Enables text selection
  • adjustsFontSizeToFit — Auto-scales font to fit container
  • minimumFontScale — Minimum scale factor when adjustsFontSizeToFit is true
  • onPress — Called when text is pressed
  • style — Style object for the text

Mini-Project: Build a Text Component with Nested Formatting

Create a rich text component that demonstrates nested Text styling:

import React from 'react';
import { Text, StyleSheet, View } from 'react-native';

export default function RichTextExample() {
  return (
    <View style={styles.container}>
      <Text style={styles.title}>
        React Native <Text style={styles.highlight}>Text</Text> Formatting
      </Text>

      <Text style={styles.paragraph}>
        You can combine <Text style={styles.bold}>bold</Text>,{' '}
        <Text style={styles.italic}>italic</Text>, and{' '}
        <Text style={styles.underline}>underline</Text> styles
        in a single line of text.
      </Text>

      <Text style={styles.paragraph}>
        <Text style={styles.lead}>This is a lead paragraph</Text> that
        uses a larger font size to draw attention to important information.
      </Text>

      <Text style={styles.paragraph}>
        You can also use{' '}
        <Text style={styles.code}>monospace fonts</Text>{' '}
        for code snippets and{' '}
        <Text style={{ color: '#e74c3c' }}>colors</Text>{' '}
        to highlight specific words.
      </Text>

      <Text
        style={styles.truncated}
        numberOfLines={2}
        ellipsizeMode="middle"
      >
        This text will be truncated in the middle after two lines.
        The middle ellipsizeMode shows an ellipsis where the text was cut.
      </Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    padding: 16,
    backgroundColor: '#ffffff',
    flex: 1,
  },
  title: {
    fontSize: 24,
    fontWeight: 'bold',
    color: '#2c3e50',
    marginBottom: 16,
  },
  highlight: {
    color: '#3498db',
    fontWeight: 'bold',
  },
  paragraph: {
    fontSize: 16,
    lineHeight: 24,
    color: '#333',
    marginBottom: 12,
  },
  bold: {
    fontWeight: 'bold',
  },
  italic: {
    fontStyle: 'italic',
  },
  underline: {
    textDecorationLine: 'underline',
  },
  lead: {
    fontSize: 20,
    fontWeight: '600',
    color: '#2c3e50',
  },
  code: {
    fontFamily: 'monospace',
    backgroundColor: '#f0f0f0',
    paddingHorizontal: 4,
    paddingVertical: 2,
    borderRadius: 3,
  },
  truncated: {
    fontSize: 14,
    color: '#7f8c8d',
    lineHeight: 20,
    marginTop: 8,
  },
});

This creates a comprehensive text formatting showcase with nested styles, lead paragraphs, code-style text, and truncated text.

Summary

  • The Text component is required to display any visible text in React Native
  • All strings must be wrapped in Text components — you cannot place raw strings in Views
  • You can nest Text components to apply inline formatting like bold, italic, and colors
  • Use numberOfLines and ellipsizeMode to control text overflow
  • Enable selectable to allow users to copy text
  • Use adjustsFontSizeToFit to automatically scale text to fit its container
  • Text supports a wide range of style properties including font, color, alignment, and decoration
