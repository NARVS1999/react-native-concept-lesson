Lesson 0006: Component Lifecycle with Hooks

Phase 2 — Core Concepts

Lesson Goal Master useEffect and useRef to handle side effects, subscriptions, and values that persist across renders.

useEffect: Side Effects

useEffect runs code after render — for API calls, subscriptions, timers, or any "side effect" that doesn't belong in the render itself.

import { useState, useEffect } from 'react';

function UserProfile({ userId }) {
  const [user, setUser] = useState(null);

  useEffect(() => {
    // Runs after component mounts OR userId changes
    fetch(`https://api.example.com/users/${userId}`)
      .then(res => res.json())
      .then(data => setUser(data));
  }, [userId]); // ← dependency array

  if (!user) return <Text>Loading...</Text>;
  return <Text>{user.name}</Text>;
}

The dependency array controls when the effect re-runs:

ArrayBehavior
OmittedRuns after every render
[]Runs once on mount
[a, b]Runs when a or b changes
Cleanup Return a function from useEffect to clean up subscriptions, timers, or event listeners when the component unmounts: 
useEffect(() => {
  const timer = setInterval(() => {}, 1000);
  return () => clearInterval(timer); // cleanup
}, []);

useRef: Persisting Values

useRef holds a mutable value that persists across renders without triggering a re-render. Common uses: DOM refs, timers, previous values.

import { useRef, useState } from 'react';

function StopWatch() {
  const [time, setTime] = useState(0);
  const intervalRef = useRef(null);

  const start = () => {
    intervalRef.current = setInterval(() => {
      setTime(prev => prev + 1);
    }, 1000);
  };

  const stop = () => {
    clearInterval(intervalRef.current);
  };

  return (
    <View>
      <Text>Time: {time}s</Text>
      <Pressable onPress={start}><Text>Start</Text></Pressable>
      <Pressable onPress={stop}><Text>Stop</Text></Pressable>
    </View>
  );
}
Key Insight Changing a ref does not cause a re-render. Use refs for values that need to persist but don't affect the UI directly.

useRef for Previous Value

A common pattern — track the previous value of a prop or state:

function usePrevious(value) {
  const ref = useRef();
  useEffect(() => {
    ref.current = value;
  }, [value]);
  return ref.current;
}

// Usage
function Counter() {
  const [count, setCount] = useState(0);
  const prevCount = usePrevious(count);
  return <Text>Now: {count}, Before: {prevCount}</Text>;
}

Mini-Project: Live Clock

Create a component that shows the current time, updating every second using useEffect and useRef for the interval.

function LiveClock() {
  const [time, setTime] = useState(new Date());
  const intervalRef = useRef(null);

  useEffect(() => {
    intervalRef.current = setInterval(() => setTime(new Date()), 1000);
    return () => clearInterval(intervalRef.current);
  }, []);

  return <Text style={{ fontSize: 32 }}>{time.toLocaleTimeString()}</Text>;
}

Summary

  • useEffect handles side effects — API calls, subscriptions, timers
  • The dependency array controls when the effect re-runs
  • Always return a cleanup function for subscriptions and timers
  • useRef persists values across renders without triggering re-renders
