Lesson 0025: Network and Memory

Phase 9 — Optimization Concepts

Lesson Goal Optimize network requests with batching and caching, and profile memory usage to prevent bottlenecks.

Network Optimization

Network requests are often the biggest performance bottleneck. Optimize with:

Request Batching

Instead of making 10 separate API calls, batch them into one:

// BAD: 10 separate requests
for (const id of userIds) {
  await fetch(`/api/users/${id}`);
}

// GOOD: One batched request
const response = await fetch('/api/users/batch', {
  method: 'POST',
  body: JSON.stringify({ ids: userIds }),
});

Caching Strategies

React Query handles caching automatically. Configure it:

const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 5 * 60 * 1000,      // Data is fresh for 5 minutes
      cacheTime: 30 * 60 * 1000,     // Keep in cache for 30 minutes
      refetchOnWindowFocus: false,    // Don't refetch on focus
    },
  },
});

Image Optimization

  • Resize images server-side to the needed dimensions
  • Use modern formats (WebP) for smaller file sizes
  • Implement progressive loading with placeholders

Memory Profiling

Memory leaks cause app crashes and slowdowns. Profile with:

// Enable memory monitor in development
// Shake device → Dev Menu → Show Perf Monitor

// Check memory usage programmatically
import { PerformanceObserver } from 'react-native';

Common memory leak sources:

SourceSolution
Unmounted component timersClear in useEffect cleanup
Event listeners not removedRemove in useEffect cleanup
Large images in memoryResize and use FastImage with cache control
Accumulating state in arraysLimit array size or paginate
WebSocket connections not closedClose in cleanup function

Network Status Awareness

Handle offline and slow network gracefully:

import NetInfo from '@react-native-community/netinfo';

function useNetworkStatus() {
  const [isConnected, setIsConnected] = useState(true);

  useEffect(() => {
    const unsubscribe = NetInfo.addEventListener(state => {
      setIsConnected(state.isConnected);
    });
    return () => unsubscribe();
  }, []);

  return isConnected;
}
