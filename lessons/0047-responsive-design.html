Phase 6 — Design Concepts

Lesson Goal By the end of this lesson, you will understand how to use useWindowDimensions, create percentage-based layouts, build adaptive components, implement responsive typography, and handle platform-specific layouts.

Why Responsive Design Matters

React Native apps run on devices with vastly different screen sizes — from small phones (320px wide) to large tablets (1024px+). Responsive design ensures your UI looks great and functions well on all these screen sizes.

Unlike web development where you use media queries, React Native uses the useWindowDimensions hook and percentage-based layouts to achieve responsiveness.

useWindowDimensions Hook

The useWindowDimensions hook returns the current window width and height, and automatically updates when the device rotates or the window resizes (on web).

import { useWindowDimensions, View, Text, StyleSheet } from 'react-native';

function ResponsiveComponent() {
  const { width, height } = useWindowDimensions();

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Window Size</Text>
      <Text style={styles.dimension}>Width: {width}px</Text>
      <Text style={styles.dimension}>Height: {height}px</Text>
      <Text style={styles.dimension}>
        Aspect Ratio: {(width / height).toFixed(2)}
      </Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', alignItems: 'center', padding: 20 },
  title: { fontSize: 24, fontWeight: 'bold', marginBottom: 16 },
  dimension: { fontSize: 16, marginBottom: 8, color: '#666' },
});

Percentage-Based Layouts

React Native supports percentage values for width, height, padding, margin, and border radius. This is the foundation of responsive design.

import { View, Text, StyleSheet } from 'react-native';

function PercentageLayout() {
  return (
    <View style={styles.container}>
      {/* Full width header */}
      <View style={styles.header}>
        <Text style={styles.headerText}>Full Width Header</Text>
      </View>

      {/* Two columns using percentages */}
      <View style={styles.row}>
        <View style={styles.columnHalf}>
          <Text style={styles.columnText}>50% Width</Text>
        </View>
        <View style={styles.columnHalf}>
          <Text style={styles.columnText}>50% Width</Text>
        </View>
      </View>

      {/* Three columns using flex */}
      <View style={styles.row}>
        <View style={styles.columnThird}>
          <Text style={styles.columnText}>33%</Text>
        </View>
        <View style={styles.columnThird}>
          <Text style={styles.columnText}>33%</Text>
        </View>
        <View style={styles.columnThird}>
          <Text style={styles.columnText}>33%</Text>
        </View>
      </View>

      {/* Percentage-based padding */}
      <View style={styles.paddedBox}>
        <Text>5% padding on all sides</Text>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1 },
  header: { width: '100%', padding: 16, backgroundColor: '#3b82f6' },
  headerText: { color: '#fff', fontSize: 18, textAlign: 'center' },
  row: { flexDirection: 'row', marginTop: 8 },
  columnHalf: { width: '50%', padding: 8 },
  columnThird: { flex: 1, padding: 8 },
  columnText: { fontSize: 14, textAlign: 'center' },
  paddedBox: { margin: '5%', padding: '5%', backgroundColor: '#f0f0f0', borderRadius: 8 },
});

Building Adaptive Components

Adaptive components change their layout or behavior based on screen size. A card might show a horizontal layout on wide screens but stack vertically on narrow ones.

import { View, Text, Image, useWindowDimensions, StyleSheet } from 'react-native';

function AdaptiveCard({ title, description, imageUrl }) {
  const { width } = useWindowDimensions();
  const isWide = width > 600;

  return (
    <View style={[styles.card, isWide && styles.cardWide]}>
      <Image
        source={{ uri: imageUrl }}
        style={[styles.image, isWide && styles.imageWide]}
      />
      <View style={[styles.content, isWide && styles.contentWide]}>
        <Text style={styles.title}>{title}</Text>
        <Text style={styles.description}>{description}</Text>
        <View style={styles.actions}>
          <View style={styles.button}>
            <Text style={styles.buttonText}>Learn More</Text>
          </View>
          <View style={[styles.button, styles.buttonSecondary]}>
            <Text style={[styles.buttonText, styles.buttonSecondaryText]}>
              Save
            </Text>
          </View>
        </View>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  card: {
    backgroundColor: '#fff',
    borderRadius: 12,
    margin: 16,
    overflow: 'hidden',
    elevation: 3,
    shadowColor: '#000',
    shadowOffset: { width: 0, height: 2 },
    shadowOpacity: 0.1,
    shadowRadius: 4,
  },
  cardWide: {
    flexDirection: 'row',
  },
  image: {
    width: '100%',
    height: 200,
  },
  imageWide: {
    width: '40%',
    height: 'auto',
    minHeight: 200,
  },
  content: {
    padding: 16,
  },
  contentWide: {
    flex: 1,
    justifyContent: 'center',
  },
  title: { fontSize: 20, fontWeight: 'bold', marginBottom: 8 },
  description: { fontSize: 14, color: '#666', marginBottom: 16 },
  actions: { flexDirection: 'row', gap: 8 },
  button: {
    backgroundColor: '#3b82f6',
    paddingVertical: 8,
    paddingHorizontal: 16,
    borderRadius: 6,
  },
  buttonText: { color: '#fff', fontWeight: '600' },
  buttonSecondary: { backgroundColor: 'transparent', borderWidth: 1, borderColor: '#3b82f6' },
  buttonSecondaryText: { color: '#3b82f6' },
});

Responsive Typography

Font sizes should scale with the screen. A 24px title on a phone is fine, but it looks small on a tablet. Use the screen width to calculate proportional font sizes.

import { useWindowDimensions } from 'react-native';

const BASE_WIDTH = 375; // iPhone X width as reference

function useResponsiveFontSize() {
  const { width } = useWindowDimensions();
  const scale = width / BASE_WIDTH;

  const normalize = (size) => {
    const newSize = size * scale;
    // Clamp between min and max
    return Math.round(newSize * 100) / 100;
  };

  return {
    xs: normalize(12),
    sm: normalize(14),
    md: normalize(16),
    lg: normalize(18),
    xl: normalize(24),
    xxl: normalize(32),
    title: normalize(40),
  };
}

// Usage
function ResponsiveText() {
  const fontSizes = useResponsiveFontSize();

  return (
    <View style={{ padding: 16 }}>
      <Text style={{ fontSize: fontSizes.title, fontWeight: 'bold' }}>
        Responsive Title
      </Text>
      <Text style={{ fontSize: fontSizes.md, marginTop: 8 }}>
        This text scales proportionally with screen width.
      </Text>
    </View>
  );
}

// More advanced: min/max clamping
function useClampedFontSize() {
  const { width } = useWindowDimensions();
  const scale = width / BASE_WIDTH;

  const normalize = (size, min, max) => {
    const newSize = size * scale;
    return Math.min(Math.max(newSize, min), max);
  };

  return {
    xs: normalize(12, 10, 14),
    sm: normalize(14, 12, 16),
    md: normalize(16, 14, 18),
    lg: normalize(18, 16, 22),
    xl: normalize(24, 20, 32),
    xxl: normalize(32, 26, 42),
  };
}

Platform-Specific Layouts

Sometimes you need different layouts for iOS and Android due to platform conventions. Use Platform.OS to conditionally apply styles.

import { Platform, View, Text, StyleSheet, StatusBar } from 'react-native';

function PlatformAwareComponent() {
  return (
    <View style={styles.container}>
      {/* Add extra padding for iOS notch/status bar */}
      <View style={styles.header}>
        <Text style={styles.headerText}>Platform-Aware Header</Text>
      </View>

      {/* Different shadow styles per platform */}
      <View style={styles.card}>
        <Text style={styles.cardText}>Platform Card</Text>
      </View>

      {/* Platform-specific touch feedback */}
      <View style={[
        styles.button,
        Platform.OS === 'ios' && styles.buttonIOS,
        Platform.OS === 'android' && styles.buttonAndroid,
      ]}>
        <Text style={styles.buttonText}>Platform Button</Text>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    paddingTop: Platform.OS === 'ios' ? 44 : StatusBar.currentHeight || 0,
  },
  header: {
    padding: 16,
    backgroundColor: '#3b82f6',
  },
  headerText: { color: '#fff', fontSize: 18, fontWeight: '600' },
  card: {
    margin: 16,
    padding: 16,
    backgroundColor: '#fff',
    borderRadius: 12,
    // Platform-specific shadows
    ...Platform.select({
      ios: {
        shadowColor: '#000',
        shadowOffset: { width: 0, height: 2 },
        shadowOpacity: 0.1,
        shadowRadius: 4,
      },
      android: {
        elevation: 4,
      },
    }),
  },
  cardText: { fontSize: 16 },
  button: {
    margin: 16,
    padding: 12,
    borderRadius: 8,
    alignItems: 'center',
  },
  buttonIOS: {
    backgroundColor: '#007AFF',
  },
  buttonAndroid: {
    backgroundColor: '#6200EE',
    elevation: 4,
  },
  buttonText: { color: '#fff', fontWeight: '600' },
});

Mini-Project: Build a Responsive Card Grid

Create a responsive card grid that adapts from 1 column on phones to 3 columns on tablets:

// components/ResponsiveCardGrid.js
import { View, Text, useWindowDimensions, StyleSheet, ScrollView } from 'react-native';

const DATA = [
  { id: '1', title: 'Card One', color: '#3b82f6' },
  { id: '2', title: 'Card Two', color: '#10b981' },
  { id: '3', title: 'Card Three', color: '#f59e0b' },
  { id: '4', title: 'Card Four', color: '#ef4444' },
  { id: '5', title: 'Card Five', color: '#8b5cf6' },
  { id: '6', title: 'Card Six', color: '#ec4899' },
];

function getColumns(width) {
  if (width >= 900) return 3;
  if (width >= 600) return 2;
  return 1;
}

export default function ResponsiveCardGrid() {
  const { width } = useWindowDimensions();
  const columns = getColumns(width);
  const cardWidth = (width - 32 - (columns - 1) * 12) / columns;

  return (
    <ScrollView style={styles.container}>
      <Text style={styles.title}>Responsive Grid</Text>
      <Text style={styles.subtitle}>{columns} column{columns > 1 ? 's' : ''} on this screen</Text>
      <View style={styles.grid}>
        {DATA.map(item => (
          <View
            key={item.id}
            style={[styles.card, { width: cardWidth, backgroundColor: item.color }]}
          >
            <Text style={styles.cardTitle}>{item.title}</Text>
          </View>
        ))}
      </View>
    </ScrollView>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 16 },
  title: { fontSize: 24, fontWeight: 'bold', marginBottom: 4 },
  subtitle: { fontSize: 14, color: '#666', marginBottom: 16 },
  grid: { flexDirection: 'row', flexWrap: 'wrap', gap: 12 },
  card: {
    height: 120,
    borderRadius: 12,
    justifyContent: 'center',
    alignItems: 'center',
  },
  cardTitle: { color: '#fff', fontSize: 16, fontWeight: '600' },
});

Summary

  • useWindowDimensions provides real-time width and height that update on rotation
  • Use percentage values ('50%') for flexible layouts that adapt to any screen size
  • Adaptive components change layout based on available screen width (e.g., horizontal vs vertical)
  • Responsive typography scales font sizes proportionally using screen width ratios
  • Platform.select and Platform.OS enable platform-specific styling
  • Always test on multiple screen sizes to ensure your responsive design works correctly
