Lesson 0022: Ship Your App

Phase 8 — Production Concepts

Lesson Goal Prepare your app for production with code signing, App Store publishing, and version management.

Code Signing

Both Apple and Google require your app to be digitally signed with a certificate to verify your identity.

iOS (Apple Developer Account — $99/year)

  • Create an App ID in the Apple Developer portal
  • Generate a Distribution Certificate
  • Create a Provisioning Profile
  • Configure in Xcode or use EAS Build

Android (Google Play Console — $25 one-time)

  • Generate a keystore file: keytool -genkeypair -v -keystore my-key.keystore -alias myalias -keyalg RSA -keysize 2048 -validity 10000
  • Store the keystore securely (never commit to git)
  • Configure signing in android/app/build.gradle
Security Warning Never commit your keystore or certificates to version control. Use environment variables or secure vaults.

App Store Publishing

With Expo EAS Build, publishing is streamlined:

# Install EAS CLI
npm install -g eas-cli

# Login to Expo
eas login

# Configure your project
eas build:configure

# Build for iOS
eas build --platform ios --profile production

# Build for Android
eas build --platform android --profile production

# Submit to stores
eas submit --platform ios
eas submit --platform android
Best Practice Use eas build for cloud builds — you don't need a Mac for iOS builds.

Version Management

Use semantic versioning (semver): MAJOR.MINOR.PATCH

VersionWhen to bumpExample
MAJORBreaking changes, major redesign2.0.0
MINORNew features, backwards compatible1.2.0
PATCHBug fixes, no feature changes1.1.1

Update versions in package.json and the native config files (android/app/build.gradle versionCode, ios/Info.plist CFBundleShortVersionString).

Build Configuration

Manage different environments (development, staging, production) with environment variables:

// app.config.js
export default {
  extra: {
    apiUrl: process.env.API_URL || 'https://api.example.com',
  },
};
