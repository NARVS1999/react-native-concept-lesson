Lesson 0032: Context API

Phase 4 — Integration Concepts

Lesson Goal Use createContext, Provider, and useContext to share state across components without prop drilling, implement typed contexts with TypeScript, and understand performance implications.

The Problem: Prop Drilling

When you need to pass data from a parent component deep into the tree, you end up passing props through intermediate components that don't use them. This is called prop drilling and makes code harder to maintain:

// Without Context — prop drilling through 3 levels
function App() {
  const [theme, setTheme] = useState('light');
  return <Layout theme={theme} />;  // Layout doesn't use theme
}

function Layout({ theme }) {
  return <Sidebar theme={theme} />;  // Sidebar doesn't use theme
}

function Sidebar({ theme }) {
  return <ThemeToggle theme={theme} />;  // Actually uses theme
}

Creating Context

createContext creates a context object with a default value. Components below the provider can consume this value:

import { createContext, useContext, useState } from 'react';

// Create context with a default value
const ThemeContext = createContext('light');

// Provider component
function ThemeProvider({ children }) {
  const [theme, setTheme] = useState('light');

  const toggleTheme = () => {
    setTheme(prev => prev === 'light' ? 'dark' : 'light');
  };

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
}

// Consumer component
function ThemeToggle() {
  const { theme, toggleTheme } = useContext(ThemeContext);
  return (
    <Button
      title={`Current: ${theme}`}
      onPress={toggleTheme}
    />
  );
}

Provider Pattern

The Provider component wraps the part of your tree that needs access to the context value. Any descendant can consume it with useContext:

function App() {
  return (
    <ThemeProvider>
      <Layout />  {/* Layout and all its children can access theme */}
    </ThemeProvider>
  );
}

useContext Hook

The useContext hook reads the current context value from the nearest Provider above. It triggers a re-render when the value changes:

function ThemedCard({ children }) {
  const { theme } = useContext(ThemeContext);

  return (
    <View style={{
      backgroundColor: theme === 'dark' ? '#333' : '#fff',
      padding: 16,
      borderRadius: 8,
    }}>
      {children}
    </View>
  );
}

Context with TypeScript

Define a type for your context value to get proper type safety:

interface ThemeContextType {
  theme: 'light' | 'dark';
  toggleTheme: () => void;
}

const ThemeContext = createContext<ThemeContextType>({
  theme: 'light',
  toggleTheme: () => {},
});

function ThemeProvider({ children }: { children: React.ReactNode }) {
  const [theme, setTheme] = useState<'light' | 'dark'>('light');

  const toggleTheme = () => {
    setTheme(prev => prev === 'light' ? 'dark' : 'light');
  };

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
}

Performance Considerations

When a Provider's value changes, all consumers re-render. To optimize:

  • Split large contexts into smaller, focused ones (e.g., ThemeContext + AuthContext)
  • Use useMemo to memoize the value object passed to Provider
  • Keep state that changes frequently in separate contexts from state that rarely changes
function AuthProvider({ children }) {
  const [user, setUser] = useState(null);

  // Memoize to prevent unnecessary re-renders
  const value = useMemo(() => ({ user, setUser }), [user]);

  return (
    <AuthContext.Provider value={value}>
      {children}
    </AuthContext.Provider>
  );
}

Mini-Project: ThemeContext with Toggle

Build a ThemeContext that provides theme state and a toggle function, with a provider that wraps the app and consumer components that respond to theme changes.

import React, { createContext, useContext, useState, useMemo } from 'react';
import { View, Text, TouchableOpacity, StyleSheet } from 'react-native';

// Define context type
const ThemeContext = createContext({
  theme: 'light',
  toggleTheme: () => {},
  colors: { background: '#fff', text: '#000', primary: '#2196F3' },
});

// Theme color definitions
const themes = {
  light: { background: '#ffffff', text: '#000000', primary: '#2196F3' },
  dark: { background: '#1a1a1a', text: '#ffffff', primary: '#64B5F6' },
};

// Provider component
export function ThemeProvider({ children }) {
  const [theme, setTheme] = useState('light');

  const toggleTheme = () => {
    setTheme(prev => prev === 'light' ? 'dark' : 'light');
  };

  const value = useMemo(() => ({
    theme,
    toggleTheme,
    colors: themes[theme],
  }), [theme]);

  return (
    <ThemeContext.Provider value={value}>
      {children}
    </ThemeContext.Provider>
  );
}

// Custom hook for consuming
export function useTheme() {
  return useContext(ThemeContext);
}

// Themed components
function ThemedButton({ title, onPress }) {
  const { colors } = useTheme();
  return (
    <TouchableOpacity
      style={[styles.button, { backgroundColor: colors.primary }]}
      onPress={onPress}
    >
      <Text style={[styles.buttonText, { color: colors.text }]}>
        {title}
      </Text>
    </TouchableOpacity>
  );
}

function ThemedCard({ children }) {
  const { colors } = useTheme();
  return (
    <View style={[styles.card, { backgroundColor: colors.background, borderColor: colors.primary }]}>
      {children}
    </View>
  );
}

// App using the context
export default function App() {
  const { theme, toggleTheme, colors } = useTheme();

  return (
    <View style={[styles.container, { backgroundColor: colors.background }]}>
      <ThemedCard>
        <Text style={[styles.title, { color: colors.text }]}>
          Theme: {theme}
        </Text>
        <ThemedButton title="Toggle Theme" onPress={toggleTheme} />
      </ThemedCard>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', alignItems: 'center' },
  card: { padding: 24, borderRadius: 12, borderWidth: 2, alignItems: 'center' },
  title: { fontSize: 22, fontWeight: 'bold', marginBottom: 16 },
  button: { paddingHorizontal: 24, paddingVertical: 12, borderRadius: 8 },
  buttonText: { fontSize: 16, fontWeight: '600' },
});

Wrap your app with <ThemeProvider> at the root level, then any component can call useTheme() to access the current theme.

Summary

  • Context API eliminates prop drilling by providing data to any descendant component
  • createContext creates a context with a default value
  • Provider wraps the component tree and supplies the context value
  • useContext reads the current context value and re-renders on changes
  • TypeScript interfaces provide type safety for context values
  • Split large contexts and memoize values for better performance
