Lesson 61: New Architecture

Phase 7 — Advanced Concepts

Lesson Goal Understand the React Native New Architecture including Fabric renderer, Turbo Modules, JSI, and Codegen. Learn the migration path from the old architecture and assess compatibility with existing libraries.

Overview of the New Architecture

React Native's New Architecture replaces the old Bridge-based communication with a modern, synchronous, and more efficient system. It consists of four key pillars: Fabric, Turbo Modules, JSI, and Codegen.

The Bridge Problem

The old architecture uses an asynchronous JSON bridge to communicate between JavaScript and native code. This causes performance bottlenecks.

// Old Architecture (Bridge)
// JS → JSON serialization → Bridge → Native → JSON response → Bridge → JS
// Asynchronous, string-based, overhead on every call

// Problem: Layout calculations, gestures, and animations
// require frequent JS-native communication
// Bridge becomes a bottleneck

JavaScript Interface (JSI)

JSI replaces the Bridge with a direct, synchronous interface between JavaScript and native code. It allows JS to hold references to native objects.

// JSI allows synchronous calls
// JS can directly invoke native methods without serialization

// Before (Bridge): async, JSON-based
NativeModules.MyModule.doSomething(data)
  .then(result => console.log(result));

// After (JSI): synchronous, direct reference
const result = global.MyModule.doSomething(data);
console.log(result); // Available immediately

Fabric Renderer

Fabric is the new rendering system that enables synchronous layout calculations and concurrent rendering. It replaces the old Shadow Tree with a more efficient architecture.

// Fabric benefits:
// 1. Synchronous layout — no more layout thrashing
// 2. Concurrent rendering — UI stays responsive
// 3. Simpler shadow tree — easier to reason about
// 4. Better support for React 18 features (concurrent mode)

// Fabric enables:
// - Synchronous state updates
// - Immediate layout measurements
// - Better animation performance
// - Concurrent rendering support

Turbo Modules

Turbo Modules replace the old NativeModules system. They support lazy loading, type safety via Codegen, and synchronous access through JSI.

// TurboModule definition (TypeScript)
import type { TurboModule } from 'react-native';
import { TurboModuleRegistry } from 'react-native';

export interface Spec extends TurboModule {
  // Synchronous methods
  getConstants(): { [key: string]: string | number | boolean };
  doSomethingSync(value: string): string;

  // Async methods (still supported)
  doSomethingAsync(value: string): Promise<string>;
}

export default TurboModuleRegistry.getEnforcing<Spec>('MyModule');

Codegen

Codegen generates type-safe native interfaces from TypeScript/Flow specs. It ensures JS and native code agree on method signatures and types.

// Codegen process:
// 1. Write TurboModule spec in TypeScript
// 2. Codegen generates native interfaces
// 3. Native code implements the generated interface
// 4. Type safety is guaranteed across the bridge

// Benefits:
// - Compile-time type checking
// - Auto-generated native code
// - No runtime type mismatches
// - Better developer experience

Migration Path

Migrating to the New Architecture is incremental. You can enable it without rewriting your entire app.

// Step 1: Enable New Architecture in your project
// Android: android/gradle.properties
newArchEnabled=true

// iOS: ios/Podfile
ENV['RCT_NEW_ARCH_ENABLED'] = '1'

// Step 2: Update dependencies
// Most popular libraries support New Architecture
// Check compatibility before upgrading

// Step 3: Migrate NativeModules to TurboModules
// Start with simple modules, then migrate complex ones

// Step 4: Test thoroughly
// New Architecture may expose existing bugs

const MigrationChecklist = () => {
  const [steps, setSteps] = useState([
    { id: '1', text: 'Enable New Architecture flag', done: false },
    { id: '2', text: 'Check library compatibility', done: false },
    { id: '3', text: 'Update React Native to latest version', done: false },
    { id: '4', text: 'Migrate first TurboModule', done: false },
    { id: '5', text: 'Test on iOS and Android', done: false },
    { id: '6', text: 'Migrate remaining NativeModules', done: false },
    { id: '7', text: 'Enable Fabric renderer', done: false },
  ]);

  const toggleStep = (id) => {
    setSteps(prev =>
      prev.map(step =>
        step.id === id ? { ...step, done: !step.done } : step
      )
    );
  };

  return (
    <View style={styles.section}>
      <Text style={styles.sectionTitle}>Migration Checklist</Text>
      {steps.map(step => (
        <TouchableOpacity key={step.id} style={styles.checkRow} onPress={() => toggleStep(step.id)}>
          <Text style={styles.check}>{step.done ? '\u2611' : '\u2610'}</Text>
          <Text style={[styles.checkText, step.done && styles.checkDone]}>
            {step.text}
          </Text>
        </TouchableOpacity>
      ))}
    </View>
  );
};

Summary

  • The New Architecture replaces the Bridge with JSI for synchronous communication
  • Fabric enables synchronous layout and concurrent rendering
  • Turbo Modules provide lazy loading and type safety via Codegen
  • Codegen generates type-safe native interfaces from TypeScript specs
  • Migration is incremental — enable the flag and update dependencies
  • Most popular libraries already support the New Architecture
