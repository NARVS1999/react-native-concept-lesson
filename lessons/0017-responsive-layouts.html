Lesson 0017: Responsive Layouts

Phase 6 — Design Concepts

Lesson Goal Build layouts that adapt to different screen sizes, orientations, and device types.

useWindowDimensions

The useWindowDimensions hook gives you the current screen size and updates when the screen rotates or resizes:

import { useWindowDimensions } from 'react-native';

function ResponsiveLayout() {
  const { width, height } = useWindowDimensions();
  const isLandscape = width > height;

  return (
    <View style={{ flexDirection: isLandscape ? 'row' : 'column' }}>
      <View style={{ flex: 1 }}><Text>Sidebar</Text></View>
      <View style={{ flex: 2 }}><Text>Content</Text></View>
    </View>
  );
}

Breakpoints

Create breakpoint constants for consistent responsive behavior:

// breakpoints.js
export const breakpoints = {
  phone: 0,
  tablet: 768,
  desktop: 1024,
};

// Usage
function useBreakpoint() {
  const { width } = useWindowDimensions();
  if (width >= breakpoints.desktop) return 'desktop';
  if (width >= breakpoints.tablet) return 'tablet';
  return 'phone';
}

function AdaptiveGrid() {
  const breakpoint = useBreakpoint();
  const columns = breakpoint === 'desktop' ? 3 : breakpoint === 'tablet' ? 2 : 1;

  return (
    <FlatList
      data={items}
      numColumns={columns}
      key={columns} // Force re-render when columns change
      renderItem={({ item }) => <Card item={item} />}
    />
  );
}

Orientation Handling

React Native supports portrait and landscape modes. Use the Dimensions API or useWindowDimensions to adapt:

import { useWindowDimensions } from 'react-native';

function OrientationAware() {
  const { width, height } = useWindowDimensions();
  const isLandscape = width > height;

  return (
    <View style={{ flex: 1 }}>
      {isLandscape ? (
        <LandscapeLayout />
      ) : (
        <PortraitLayout />
      )}
    </View>
  );
}
Best Practice Always test your app in both orientations. Use useWindowDimensions instead of Dimensions.get() because it updates dynamically.
