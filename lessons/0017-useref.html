Lesson 17: useRef

Phase 2 — Core Concepts

Lesson Goal By the end of this lesson, you will be able to use useRef to store mutable values that persist across renders, access components imperatively, track previous values, and store timer IDs without triggering re-renders.

What is useRef?

useRef is a React hook that creates a mutable reference object. Unlike useState, updating a ref does NOT trigger a re-render. This makes it perfect for storing values that need to persist across renders but should not cause the UI to update.

import React, { useRef } from 'react';
import { View, Text, StyleSheet } from 'react-native';

export default function App() {
  const myRef = useRef('initial value');

  console.log(myRef.current); // "initial value"
  myRef.current = 'new value'; // No re-render!
  console.log(myRef.current); // "new value"

  return (
    <View style={styles.container}>
      <Text>useRef example</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', alignItems: 'center' },
});

A ref is an object with a single property: current. You can read and write to current freely.

No Re-render on Update

The key difference between useState and useRef is that useRef does not cause a re-render when updated:

import React, { useState, useRef } from 'react';
import { View, Text, Button, StyleSheet } from 'react-native';

export default function App() {
  const [stateCount, setStateCount] = useState(0);
  const refCount = useRef(0);

  const incrementState = () => {
    setStateCount(stateCount + 1); // Triggers re-render
  };

  const incrementRef = () => {
    refCount.current += 1; // No re-render!
    console.log('Ref count:', refCount.current);
  };

  return (
    <View style={styles.container}>
      <Text>State: {stateCount} (re-renders)</Text>
      <Text>Ref: {refCount.current} (no re-render)</Text>
      <Button title="Increment State" onPress={incrementState} />
      <Button title="Increment Ref" onPress={incrementRef} />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', alignItems: 'center', gap: 12 },
});

Accessing Components Imperatively

In React Native, useRef is commonly used to access component instances like TextInput for focusing, measuring, or other imperatively:

import React, { useRef } from 'react';
import { View, TextInput, Pressable, Text, StyleSheet } from 'react-native';

export default function App() {
  const inputRef = useRef(null);

  const focusInput = () => {
    inputRef.current?.focus();
  };

  const clearInput = () => {
    inputRef.current?.clear();
  };

  return (
    <View style={styles.container}>
      <TextInput
        ref={inputRef}
        style={styles.input}
        placeholder="Type something..."
      />
      <Pressable style={styles.button} onPress={focusInput}>
        <Text style={styles.buttonText}>Focus Input</Text>
      </Pressable>
      <Pressable style={styles.button} onPress={clearInput}>
        <Text style={styles.buttonText}>Clear Input</Text>
      </Pressable>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', padding: 20, gap: 12 },
  input: { borderWidth: 1, borderColor: '#ccc', borderRadius: 8, padding: 12, fontSize: 16 },
  button: { backgroundColor: '#3498db', padding: 12, borderRadius: 8, alignItems: 'center' },
  buttonText: { color: '#fff', fontSize: 16 },
});

Storing Previous Values

useRef is perfect for tracking the previous value of a state variable:

import React, { useState, useEffect, useRef } from 'react';
import { View, Text, Button, StyleSheet } from 'react-native';

export default function App() {
  const [count, setCount] = useState(0);
  const prevCountRef = useRef(count);

  useEffect(() => {
    prevCountRef.current = count;
  });

  const prevCount = prevCountRef.current;

  return (
    <View style={styles.container}>
      <Text style={styles.text}>Current: {count}</Text>
      <Text style={styles.text}>Previous: {prevCount}</Text>
      <Button title="Increment" onPress={() => setCount(c => c + 1)} />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', alignItems: 'center', gap: 12 },
  text: { fontSize: 20 },
});

Storing Timer IDs

useRef is ideal for storing interval and timeout IDs so you can clear them later:

import React, { useState, useEffect, useRef } from 'react';
import { View, Text, Pressable, StyleSheet } from 'react-native';

export default function Timer() {
  const [seconds, setSeconds] = useState(0);
  const [isRunning, setIsRunning] = useState(false);
  const intervalRef = useRef(null);

  useEffect(() => {
    if (isRunning) {
      intervalRef.current = setInterval(() => {
        setSeconds(prev => prev + 1);
      }, 1000);
    }
    return () => {
      if (intervalRef.current) clearInterval(intervalRef.current);
    };
  }, [isRunning]);

  return (
    <View style={styles.container}>
      <Text style={styles.timer}>{seconds}s</Text>
      <Pressable style={styles.button} onPress={() => setIsRunning(!isRunning)}>
        <Text style={styles.buttonText}>{isRunning ? 'Pause' : 'Start'}</Text>
      </Pressable>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', alignItems: 'center', gap: 16 },
  timer: { fontSize: 48, fontWeight: 'bold' },
  button: { backgroundColor: '#3498db', paddingVertical: 12, paddingHorizontal: 32, borderRadius: 8 },
  buttonText: { color: '#fff', fontSize: 18, fontWeight: '600' },
});

Feature useState useRef
Triggers re-render Yes No
Use for UI data Mutable values, DOM access
Persists across renders Yes Yes

Mini-Project: Build a Stopwatch Using useRef

Create a full-featured stopwatch with lap tracking using useRef:

import React, { useState, useRef } from 'react';
import { View, Text, Pressable, FlatList, StyleSheet } from 'react-native';

export default function Stopwatch() {
  const [time, setTime] = useState(0);
  const [isRunning, setIsRunning] = useState(false);
  const [laps, setLaps] = useState([]);
  const intervalRef = useRef(null);
  const startTimeRef = useRef(0);
  const elapsedTimeRef = useRef(0);

  const start = () => {
    setIsRunning(true);
    startTimeRef.current = Date.now() - elapsedTimeRef.current;
    intervalRef.current = setInterval(() => {
      setTime(Date.now() - startTimeRef.current);
    }, 10);
  };

  const stop = () => {
    setIsRunning(false);
    clearInterval(intervalRef.current);
    elapsedTimeRef.current = time;
  };

  const reset = () => {
    setIsRunning(false);
    clearInterval(intervalRef.current);
    setTime(0);
    elapsedTimeRef.current = 0;
    setLaps([]);
  };

  const addLap = () => {
    if (isRunning) setLaps(prev => [time, ...prev]);
  };

  const formatTime = (ms) => {
    const minutes = Math.floor(ms / 60000);
    const seconds = Math.floor((ms % 60000) / 1000);
    const centiseconds = Math.floor((ms % 1000) / 10);
    return `${minutes.toString().padStart(2, '0')}:${seconds.toString().padStart(2, '0')}.${centiseconds.toString().padStart(2, '0')}`;
  };

  return (
    <View style={styles.container}>
      <Text style={styles.display}>{formatTime(time)}</Text>
      <View style={styles.buttonRow}>
        <Pressable style={[styles.button, styles.secondaryButton]} onPress={isRunning ? addLap : reset}>
          <Text style={styles.buttonText}>{isRunning ? 'Lap' : 'Reset'}</Text>
        </Pressable>
        <Pressable style={[styles.button, isRunning ? styles.stopButton : styles.startButton]} onPress={isRunning ? stop : start}>
          <Text style={styles.buttonText}>{isRunning ? 'Stop' : 'Start'}</Text>
        </Pressable>
      </View>
      {laps.length > 0 && (
        <View style={styles.lapsContainer}>
          <Text style={styles.lapsTitle}>Laps</Text>
          <FlatList
            data={laps}
            keyExtractor={(item, index) => index.toString()}
            renderItem={({ item, index }) => (
              <View style={styles.lapItem}>
                <Text style={styles.lapNumber}>Lap {laps.length - index}</Text>
                <Text style={styles.lapTime}>{formatTime(item)}</Text>
              </View>
            )}
          />
        </View>
      )}
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', alignItems: 'center', padding: 20 },
  display: { fontSize: 56, fontWeight: '200', fontVariant: ['tabular-nums'], color: '#2c3e50', marginBottom: 40 },
  buttonRow: { flexDirection: 'row', gap: 16, marginBottom: 30 },
  button: { paddingVertical: 14, paddingHorizontal: 32, borderRadius: 8, minWidth: 120, alignItems: 'center' },
  startButton: { backgroundColor: '#27ae60' },
  stopButton: { backgroundColor: '#e74c3c' },
  secondaryButton: { backgroundColor: '#95a5a6' },
  buttonText: { color: '#fff', fontSize: 18, fontWeight: '600' },
  lapsContainer: { width: '100%', maxHeight: 200 },
  lapsTitle: { fontSize: 18, fontWeight: 'bold', marginBottom: 8, color: '#2c3e50' },
  lapItem: { flexDirection: 'row', justifyContent: 'space-between', paddingVertical: 8, borderBottomWidth: 1, borderBottomColor: '#ecf0f1' },
  lapNumber: { fontSize: 16, color: '#7f8c8d' },
  lapTime: { fontSize: 16, fontVariant: ['tabular-nums'], color: '#2c3e50' },
});

This creates a full-featured stopwatch with start/stop/reset, lap tracking, and precise timing using useRef for timer management.

Summary

  • useRef creates a mutable object with a current property that persists across renders
  • Updating a ref does NOT trigger a re-render, unlike useState
  • Use useRef for values that need to persist but should not cause UI updates
  • Common use cases: accessing TextInput, storing timer IDs, tracking previous values
  • The ref object is stable across renders — the same object is returned every time
  • Refs are ideal for imperative handles and mutable data that does not affect rendering
  • Access the value via ref.current and update it directly
