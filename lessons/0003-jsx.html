Lesson 3: JSX

Phase 1 — Foundational Concepts

Lesson Goal By the end of this lesson, you will understand what JSX is, how it compiles to JavaScript, the rules you must follow when writing JSX, how to use expressions, conditional rendering, and list rendering within JSX.

What is JSX?

JSX (JavaScript XML) is a syntax extension for JavaScript that looks like HTML but is actually JavaScript. It allows you to write UI structures in a familiar, declarative way. React Native uses JSX to describe what your UI should look like.

JSX is not valid JavaScript on its own — it must be compiled (transpiled) before it can run. Tools like Babel or Metro bundler transform JSX into regular JavaScript function calls.

// What you write (JSX):
const element = <Text>Hello, World!</Text>;

// What it compiles to (JavaScript):
const element = React.createElement(Text, null, 'Hello, World!');

// A more complex example:
const ui = (
  <View style={{ padding: 20 }}>
    <Text style={{ fontSize: 24 }}>Welcome</Text>
  </View>
);

// Compiles to:
const ui = React.createElement(
  View,
  { style: { padding: 20 } },
  React.createElement(Text, { style: { fontSize: 24 } }, 'Welcome')
);

Understanding this compilation helps you see that JSX is just syntactic sugar over React.createElement() calls. Every JSX element becomes a function call that returns a React element object.

JSX Rules

JSX has strict rules that you must follow. Violating them will cause compilation errors.

Rule 1: Return a Single Root Element

A component must return a single JSX element. If you need multiple elements, wrap them in a View or a Fragment.

// WRONG - returns two adjacent elements
function BadComponent() {
  return (
    <Text>First</Text>
    <Text>Second</Text>
  );
}

// CORRECT - wrapped in a View
function GoodComponent() {
  return (
    <View>
      <Text>First</Text>
      <Text>Second</Text>
    </View>
  );
}

// CORRECT - using Fragment (no extra wrapper element)
function AlsoCorrect() {
  return (
    <>
      <Text>First</Text>
      <Text>Second</Text>
    </>
  );
}

Rule 2: Close All Tags

Every tag must be explicitly closed, including self-closing tags.

// WRONG - self-closing tags not closed
<Image source={logo} />     // ✗ missing slash before >
<TextInput placeholder="Name" />  // ✗ missing slash

// CORRECT
<Image source={logo} />
<TextInput placeholder="Name" />

// WRONG - non-self-closing tags
<View>
  <Text>Hello
</View>

// CORRECT
<View>
  <Text>Hello</Text>
</View>

Rule 3: Use camelCase for Attributes

JSX uses camelCase for attribute names instead of the HTML lowercase convention.

// HTML vs JSX attribute names:
// class → className (not used in RN, but applies to React)
// for → htmlFor
// onclick → onPress
// onchange → onChangeText
// tabindex → tabIndex
// style takes an object, not a string

// WRONG
<TextInput
  onchange={handleChange}
  style="color: red"
/>

// CORRECT
<TextInput
  onChangeText={handleChange}
  style={{ color: 'red' }}
/>

Expressions in JSX

You can embed any valid JavaScript expression inside curly braces {} within JSX.

const name = 'Alice';
const age = 25;
const isLoggedIn = true;

const Profile = () => (
  <View>
    {/* String interpolation */}
    <Text>Hello, {name}!</Text>

    {/* Math expressions */}
    <Text>Double age: {age * 2}</Text>

    {/* Function calls */}
    <Text>Uppercase: {name.toUpperCase()}</Text>

    {/* Ternary expressions */}
    <Text>{isLoggedIn ? 'Welcome back!' : 'Please log in'}</Text>

    {/* Object access */}
    <Text>{`Name: ${name}, Age: ${age}`}</Text>
  </View>
);

Important: You can only embed expressions, not statements. Expressions produce a value; statements do not.

// VALID - expressions
{isLoggedIn && <Text>Logged in</Text>}
{items.length > 0 ? <List /> : <EmptyState />}
{users.map(user => <Text key={user.id}>{user.name}</Text>)}

// INVALID - statements (will cause errors)
{if (isLoggedIn) { return <Text>Yes</Text>; }}
{for (let i = 0; i < 10; i++) { ... }}

Conditional Rendering

There are several ways to conditionally render elements in JSX.

const Dashboard = ({ user, notifications, isAdmin }) => {
  // Method 1: Ternary operator
  return (
    <View>
      {user ? (
        <Text>Welcome, {user.name}!</Text>
      ) : (
        <Text>Please log in</Text>
      )}
    </View>
  );
};

// Method 2: Logical AND (&&)
const Notifications = ({ count }) => (
  <View>
    {count > 0 && (
      <View style={styles.badge}>
        <Text>{count}</Text>
      </View>
    )}
  </View>
);

// Method 3: Variable assignment
const AdminPanel = ({ isAdmin }) => {
  let content;

  if (isAdmin) {
    content = <Text>Admin Dashboard</Text>;
  } else {
    content = <Text>Access Denied</Text>;
  }

  return <View>{content}</View>;
};

// Method 4: Early return
const UserProfile = ({ user }) => {
  if (!user) return null;

  return (
    <View>
      <Text>{user.name}</Text>
    </View>
  );
};

List Rendering with Map

To render lists of data, use the Array.map() method to transform data into JSX elements. Always provide a unique key prop.

interface Todo {
  id: number;
  title: string;
  completed: boolean;
}

const TodoList = ({ todos }: { todos: Todo[] }) => (
  <View>
    {todos.map((todo) => (
      <View key={todo.id} style={styles.todoItem}>
        <Text style={todo.completed ? styles.done : styles.pending}>
          {todo.title}
        </Text>
      </View>
    ))}
  </View>
);

// With filtering
const ActiveTodos = ({ todos }) => (
  <View>
    {todos
      .filter((todo) => !todo.completed)
      .map((todo) => (
        <Text key={todo.id}>{todo.title}</Text>
      ))}
  </View>
);

// Nested lists
const UserGroups = ({ groups }) => (
  <View>
    {groups.map((group) => (
      <View key={group.id}>
        <Text style={styles.groupTitle}>{group.name}</Text>
        {group.members.map((member) => (
          <Text key={member.id}>  {member.name}</Text>
        ))}
      </View>
    ))}
  </View>
);

Why do we need keys? Keys help React identify which items have changed, been added, or removed. Without keys, React would re-render the entire list on every change, which is inefficient. Keys must be unique among siblings (they don't need to be globally unique).

Mini-Project: Build a JSX Component with Conditional Rendering

Create a NotificationBadge component that uses conditional rendering to show different UI based on the number of notifications:

import React from 'react';
import { View, Text, StyleSheet } from 'react-native';

interface NotificationBadgeProps {
  count: number;
  username: string;
}

export default function NotificationBadge({ count, username }: NotificationBadgeProps) {
  return (
    <View style={styles.container}>
      {/* Always show greeting */}
      <Text style={styles.greeting}>
        {username ? `Hello, ${username}!` : 'Hello, Guest!'}
      </Text>

      {/* Conditional: show badge only if there are notifications */}
      {count > 0 && (
        <View style={styles.badge}>
          <Text style={styles.badgeText}>{count}</Text>
        </View>
      )}

      {/* Ternary: show different messages */}
      <Text style={styles.message}>
        {count === 0
          ? 'No new notifications'
          : count === 1
          ? 'You have 1 new notification'
          : `You have ${count} new notifications`}
      </Text>

      {/* Conditional styling */}
      <View style={[styles.statusBar, count > 0 && styles.activeStatusBar]}>
        <Text style={styles.statusText}>
          {count > 0 ? 'Active' : 'Idle'}
        </Text>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    padding: 20,
    backgroundColor: '#f5f5f5',
    borderRadius: 10,
  },
  greeting: {
    fontSize: 18,
    fontWeight: 'bold',
  },
  badge: {
    backgroundColor: 'red',
    borderRadius: 12,
    paddingHorizontal: 8,
    paddingVertical: 2,
    alignSelf: 'flex-start',
    marginTop: 5,
  },
  badgeText: {
    color: 'white',
    fontWeight: 'bold',
    fontSize: 14,
  },
  message: {
    marginTop: 10,
    fontSize: 14,
    color: '#666',
  },
  statusBar: {
    marginTop: 15,
    padding: 10,
    borderRadius: 5,
    backgroundColor: '#e0e0e0',
  },
  activeStatusBar: {
    backgroundColor: '#4CAF50',
  },
  statusText: {
    color: 'white',
    fontWeight: 'bold',
  },
});

Test it: Use the component with different values like <NotificationBadge count={0} username="Alice" />, <NotificationBadge count={1} username="Bob" />, and <NotificationBadge count={5} username="" />.

Summary

  • JSX is a syntax extension that compiles to React.createElement() calls
  • Every component must return a single root element (use View or Fragment)
  • All tags must be explicitly closed, including self-closing tags
  • Use camelCase for attribute names (e.g., onPress instead of onclick)
  • Embed JavaScript expressions in JSX using curly braces {}
  • Conditional rendering uses ternary operators, logical AND, or variable assignment
  • List rendering uses .map() with unique key props
  • Only expressions (not statements) can be embedded in JSX
