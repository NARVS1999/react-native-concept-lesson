Lesson 74: Memory Profiling

Phase 9 — Optimization Concepts

Lesson Goal Learn to use memory profiling tools, detect memory leaks, take heap snapshots, understand common memory issues in React Native, and monitor memory usage in production.

Why Memory Profiling Matters

Memory leaks cause apps to slow down, consume excessive battery, and eventually crash. In React Native, memory issues are especially dangerous because they accumulate over long sessions — a user who keeps your app open for hours may experience crashes that never appear in short testing sessions.

Memory Profiling Tools

Several tools help you understand your app's memory behavior:

// iOS: Xcode Instruments > Memory Graph Debugger
// 1. Open Xcode → Product → Profile (Cmd+I)
// 2. Select "Leaks" or "Allocations" instrument
// 3. Record your app's memory usage over time

// Android: Android Studio Profiler
// 1. Open Android Studio → View → Tool Windows → Profiler
// 2. Select your app process
// 3. Click on Memory to see heap allocation over time

// React Native: Performance Monitor (Dev Menu)
// Shake device → Show Perf Monitor
// Watch the "Used JS Heap" value — if it keeps growing, you have a leak

// Programmatic memory monitoring
import { NativeModules } from 'react-native';

const logMemory = () => {
  if (global.HermesInternal) {
    const heapStats = global.HermesInternal.getInstrumentedStats();
    console.log('JS Heap:', {
      used: heapStats.js_heapSizeUsed,
      allocated: heapStats.js_heapSizeAllocated,
    });
  }
};

// Log memory every 5 seconds in development
setInterval(logMemory, 5000);

Detecting Memory Leaks

A memory leak occurs when objects are no longer needed but remain in memory because something still references them. Common signs: memory keeps growing over time, never stabilizes.

// Common leak: forgetting to clean up event listeners
// BAD
useEffect(() => {
  const subscription = DeviceEventEmitter.addListener('event', handler);
  // No cleanup — listener persists after component unmounts
}, []);

// GOOD
useEffect(() => {
  const subscription = DeviceEventEmitter.addListener('event', handler);
  return () => subscription.remove(); // cleanup on unmount
}, []);

// Common leak: timer not cleared
// BAD
useEffect(() => {
  const interval = setInterval(() => {
    fetchData();
  }, 5000);
  // No cleanup — interval runs forever
}, []);

// GOOD
useEffect(() => {
  const interval = setInterval(() => {
    fetchData();
  }, 5000);
  return () => clearInterval(interval); // cleanup on unmount
}, []);

// Common leak: large arrays accumulated in state
// BAD
const ChatScreen = () => {
  const [messages, setMessages] = useState([]);

  useEffect(() => {
    const unsubscribe = onNewMessage((msg) => {
      setMessages(prev => [...prev, msg]); // grows forever
    });
    return unsubscribe;
  }, []);
};

// GOOD — limit the number of messages kept in memory
const ChatScreen = () => {
  const MAX_MESSAGES = 100;
  const [messages, setMessages] = useState([]);

  useEffect(() => {
    const unsubscribe = onNewMessage((msg) => {
      setMessages(prev => {
        const updated = [...prev, msg];
        return updated.length > MAX_MESSAGES
          ? updated.slice(-MAX_MESSAGES) // keep only last 100
          : updated;
      });
    });
    return unsubscribe;
  }, []);
};

Heap Snapshots

Heap snapshots capture the state of memory at a specific moment. Compare two snapshots to find what grew between them.

// iOS: Use Xcode Allocations instrument
// 1. Start recording
// 2. Perform an action (e.g., navigate to a screen and back)
// 3. Take a heap snapshot
// 4. Perform the action again
// 5. Take another heap snapshot
// 6. Compare the two snapshots — objects that grew are potential leaks

// Android: Use Android Studio Memory Profiler
// 1. Click "Capture heap dump"
// 2. Perform an action
// 3. Capture another heap dump
// 4. Compare — look for objects that increased in count

// React Native: Use react-native-flipper for heap snapshots
// Install: npm install flipper-plugin-react-query-inspector

// Programmatic: Force garbage collection and measure
const measureMemoryLeak = async (action) => {
  // Take baseline measurement
  const before = global.HermesInternal?.getInstrumentedStats();

  // Perform the action multiple times
  for (let i = 0; i < 10; i++) {
    await action();
  }

  // Force garbage collection if available
  if (global.gc) global.gc();

  // Take measurement after
  const after = global.HermesInternal?.getInstrumentedStats();

  console.log('Memory before:', before?.js_heapSizeUsed);
  console.log('Memory after:', after?.js_heapSizeUsed);
  console.log('Growth:', after?.js_heapSizeUsed - before?.js_heapSizeUsed);
};

Common Memory Issues in React Native

// 1. Image caching — images stay in memory after navigating away
// Solution: Use FastImage with cacheControl or clear cache on unmount
import FastImage from 'react-native-fast-image';

useEffect(() => {
  return () => {
    FastImage.clearMemoryCache(); // clear when screen unmounts
  };
}, []);

// 2. Navigation memory — old screens remain mounted
// Solution: Use detachInactiveScreens in React Navigation
<Stack.Navigator
  screenOptions={{
    detachInactiveScreens: true, // unmount inactive screens
  }}
>
  ...
</Stack.Navigator>

// 3. Large list data — FlatList keeps items in memory
// Solution: Use removeClippedSubviews and limit windowSize
<FlatList
  data={largeDataset}
  removeClippedSubviews={true}  // remove offscreen views from native tree
  windowSize={5}                 // render only 5 screens worth of items
  maxToRenderPerBatch={10}       // render 10 items per batch
  initialNumToRender={10}        // render 10 items initially
/>

// 4. Event listener accumulation — multiple subscriptions
// Solution: Always return cleanup functions
useEffect(() => {
  const sub1 = emitter.addListener('event1', handler1);
  const sub2 = emitter.addListener('event2', handler2);
  return () => {
    sub1.remove();
    sub2.remove();
  };
}, []);

// 5. WebSocket connections not closed
// Solution: Close connections on unmount
useEffect(() => {
  const ws = new WebSocket('wss://api.example.com');
  ws.onmessage = handleMessage;

  return () => ws.close(); // close on unmount
}, []);

Monitoring Memory in Production

// Send memory metrics to your analytics service
import { Platform } from 'react-native';

const reportMemoryUsage = async (screenName) => {
  if (global.HermesInternal) {
    const stats = global.HermesInternal.getInstrumentedStats();
    await fetch('/api/analytics/memory', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        screen: screenName,
        heapUsed: stats.js_heapSizeUsed,
        heapAllocated: stats.js_heapSizeAllocated,
        platform: Platform.OS,
        timestamp: Date.now(),
      }),
    });
  }
};

// Use in navigation state change listener
const reportOnNavigation = (state) => {
  const currentRoute = state?.routes?.[state.index]?.name;
  if (currentRoute) {
    reportMemoryUsage(currentRoute);
  }
};

Mini-Project: Profile Memory Usage in Your App

Build a memory monitoring hook and identify leaks by navigating through your app.

import { useEffect, useRef, useCallback } from 'react';
import { DeviceEventEmitter, Platform } from 'react-native';

// Hook to monitor memory usage in a component
function useMemoryMonitor(componentName) {
  const renderCount = useRef(0);

  useEffect(() => {
    renderCount.current += 1;
    console.log(`[${componentName}] Mounted (render #${renderCount.current})`);

    // Log memory on mount
    if (global.HermesInternal) {
      const stats = global.HermesInternal.getInstrumentedStats();
      console.log(`[${componentName}] Memory:`, {
        heapUsed: `${(stats.js_heapSizeUsed / 1024 / 1024).toFixed(2)} MB`,
        heapAllocated: `${(stats.js_heapSizeAllocated / 1024 / 1024).toFixed(2)} MB`,
      });
    }

    return () => {
      console.log(`[${componentName}] Unmounted`);
    };
  }, [componentName]);
}

// Hook to detect memory leaks by tracking active subscriptions
function useLeakDetector() {
  const activeRefs = useRef(new Set());

  const track = useCallback((name) => {
    activeRefs.current.add(name);
    console.log(`[LeakDetector] Active: ${name}`);
    return () => {
      activeRefs.current.delete(name);
      console.log(`[LeakDetector] Cleaned: ${name}`);
    };
  }, []);

  useEffect(() => {
    return () => {
      if (activeRefs.current.size > 0) {
        console.warn('[LeakDetector] Potential leaks on unmount:',
          Array.from(activeRefs.current));
      }
    };
  }, []);

  return track;
}

// Usage in a component
function ChatScreen() {
  useMemoryMonitor('ChatScreen');
  const track = useLeakDetector();

  useEffect(() => {
    const cleanup1 = track('chatListener');
    const ws = new WebSocket('wss://chat.example.com');

    const cleanup2 = track('websocket');
    const interval = setInterval(pingServer, 30000);
    const cleanup3 = track('heartbeat');

    return () => {
      cleanup1();
      cleanup2();
      cleanup3();
      ws.close();
      clearInterval(interval);
    };
  }, [track]);

  return (
    // ... chat UI
  );
}

// Test for leaks: navigate to screen and back 10 times
const testForLeaks = async (navigation) => {
  const before = global.HermesInternal?.getInstrumentedStats();

  for (let i = 0; i < 10; i++) {
    navigation.navigate('ChatScreen');
    await new Promise(r => setTimeout(r, 1000));
    navigation.goBack();
    await new Promise(r => setTimeout(r, 500));
  }

  if (global.gc) global.gc();
  const after = global.HermesInternal?.getInstrumentedStats();

  const growth = after.js_heapSizeUsed - before.js_heapSizeUsed;
  console.log(`Memory after 10 navigations: ${(growth / 1024 / 1024).toFixed(2)} MB growth`);

  if (growth > 5 * 1024 * 1024) { // 5MB threshold
    console.warn('Possible memory leak detected!');
  }
};

Summary

  • Memory leaks cause apps to slow down, consume excessive battery, and crash over long sessions
  • Use Xcode Instruments (iOS), Android Studio Profiler, or Hermes heap stats to profile memory
  • Compare heap snapshots before and after actions to identify what's growing in memory
  • Common leaks: uncleared timers, missing event listener cleanup, unbounded data accumulation, unclosed connections
  • Always return cleanup functions from useEffect to remove listeners, timers, and subscriptions
  • Use removeClippedSubviews and windowSize on FlatList to limit memory for large lists
  • Monitor memory in production by sending heap stats to your analytics service
