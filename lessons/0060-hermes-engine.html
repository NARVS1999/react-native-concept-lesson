Phase 7 — Advanced Concepts

Lesson Goal Understand what the Hermes JavaScript engine is, learn how bytecode precompilation improves startup time, explore memory optimization features, and measure the performance impact of enabling or disabling Hermes in your app.

What is Hermes?

Hermes is an open-source JavaScript engine optimized for running React Native apps. Created by Meta, it compiles JavaScript source code into optimized bytecode ahead-of-time (AOT), resulting in faster startup times and lower memory usage compared to JavaScriptCore (JSC).

Bytecode Precompilation

Traditional JavaScript engines parse and compile JS at runtime. Hermes precompiles JS to bytecode during the build step, so the runtime only needs to execute pre-compiled bytecode.

EngineCompilationStartupRuntime
JavaScriptCoreJIT compilation at runtimeSlower (parse + compile)Faster (optimized machine code)
V8 (Chrome)JIT compilation at runtimeSlower (parse + compile)Fastest (optimized machine code)
HermesAOT bytecode compilationFaster (bytecode ready)Moderate (bytecode execution)

Startup Improvement

Hermes significantly improves Time-to-Interactive (TTI) — the time from app launch to when the first screen is interactive. Bytecode is smaller than source code and doesn't need parsing.

// Hermes bytecode is pre-compiled during build
// No runtime parsing needed — app starts faster

// Typical improvement:
// - Cold start: 30-50% faster
// - TTI: 40-60% improvement
// - App size: 10-20% smaller (bytecode vs source)

Memory Optimization

Hermes uses less memory than JSC because it avoids JIT compilation overhead and uses a more efficient garbage collector.

  • No JIT compiler memory overhead
  • Efficient garbage collection with generational GC
  • Smaller memory footprint for bytecode vs parsed AST
  • Lazy compilation — only compile what's needed

Enabling/Disabling Hermes

React Native CLI (Android)

// android/gradle.properties
hermesEnabled=true

// or in android/app/build.gradle
project.ext.react = [
    enableHermes: true,  // Set to false to disable Hermes
]

React Native CLI (iOS)

// ios/Podfile
:hermes_enabled => true

# Then reinstall pods
cd ios && pod install

Expo

// app.json or app.config.js
{
  "expo": {
    "plugins": [
      [
        "expo-build-properties",
        {
          "android": {
            "hermesEnabled": true
          },
          "ios": {
            "hermesEnabled": true
          }
        }
      ]
    ]
  }
}
