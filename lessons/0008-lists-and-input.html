Lesson 0008: Lists and Input

Phase 3 — Implementation Concepts

Lesson Goal Use FlatList and SectionList for performant lists, and TextInput for user input.

FlatList: Virtualized Lists

<FlatList> only renders items currently visible on screen — making it efficient for thousands of items.

import { FlatList, Text, View } from 'react-native';

const DATA = Array.from({ length: 1000 }, (_, i) => ({
  id: String(i),
  title: `Item ${i}`,
}));

function MyList() {
  return (
    <FlatList
      data={DATA}
      keyExtractor={item => item.id}
      renderItem={({ item }) => (
        <View style={{ padding: 16, borderBottomWidth: 1, borderBottomColor: '#eee' }}>
          <Text>{item.title}</Text>
        </View>
      )}
    />
  );
}
Key Props
  • data — the array of items
  • keyExtractor — unique key for each item
  • renderItem — function that returns the JSX for each item
  • ItemSeparatorComponent — divider between items
  • onEndReached — callback for infinite scroll / pagination

SectionList: Grouped Data

<SectionList> groups items under section headers — perfect for alphabetical lists, categorized data.

import { SectionList, Text, View } from 'react-native';

const SECTIONS = [
  { title: 'Fruits', data: ['Apple', 'Banana', 'Cherry'] },
  { title: 'Vegetables', data: ['Carrot', 'Broccoli', 'Spinach'] },
];

function GroupedList() {
  return (
    <SectionList
      sections={SECTIONS}
      keyExtractor={(item, index) => item + index}
      renderItem={({ item }) => <Text style={{ padding: 12 }}>{item}</Text>}
      renderSectionHeader={({ section }) => (
        <Text style={{ fontWeight: 'bold', padding: 12, backgroundColor: '#f5f5f5' }}>
          {section.title}
        </Text>
      )}
    />
  );
}

TextInput: User Input

<TextInput> is the component for text input fields:

import { TextInput, useState } from 'react-native';

function SearchBar() {
  const [query, setQuery] = useState('');

  return (
    <TextInput
      style={{ padding: 12, borderWidth: 1, borderColor: '#ccc', borderRadius: 8 }}
      placeholder="Search..."
      value={query}
      onChangeText={setQuery}
      autoCapitalize="none"
    />
  );
}
PropPurpose
valueControlled input value
onChangeTextCallback when text changes
placeholderHint text when empty
secureTextEntryFor passwords (hides text)
keyboardTypeKeyboard type (email, numeric, etc.)
autoCapitalizeControl auto-capitalization

Image: Displaying Images

Display images from local assets or remote URLs:

import { Image } from 'react-native';

// Local asset
<Image source={require('./assets/logo.png')} style={{ width: 100, height: 100 }} />

// Remote URL (must specify width and height)
<Image
  source={{ uri: 'https://example.com/photo.jpg' }}
  style={{ width: 200, height: 200, borderRadius: 8 }}
/>
Important Remote images require explicit width and height in the style. Without them, the image will not display.

  • <TextInput> handles user text input with onChangeText
