Lesson 0026: Image Component

Phase 3 — Implementation Concepts

Lesson Goal Master the Image component for displaying local and remote images, handle resizeMode, and use ImageBackground.

Basic Image Usage

The Image component displays images from various sources:

import React from 'react';
import { Image, View } from 'react-native';

function MyComponent() {
  return (
    <View>
      <Image
        source={require('./assets/photo.png')}
        style={{ width: 200, height: 200 }}
      />
    </View>
  );
}

Local Assets

Use require() for local images:

// Static asset (bundled with app)
<Image source={require('./assets/logo.png')} />

// Dynamic local image
const imageSource = require('./assets/photo.jpg');
<Image source={imageSource} />

Remote URIs

For remote images, specify both URI and dimensions:

<Image
  source={{ uri: 'https://example.com/image.jpg' }}
  style={{ width: 300, height: 200 }}
/>

ResizeMode

Control how images fit within their dimensions:

<Image
  source={require('./assets/photo.png')}
  style={{ width: 300, height: 300 }}
  resizeMode="cover"  // cover, contain, stretch, repeat, center
/>

resizeMode options:

  • cover — Scale to fill, may crop
  • contain — Scale to fit, may letterbox
  • stretch — Stretch to fill exactly
  • center — Center without resize

ImageBackground

Display content on top of an image background:

import { ImageBackground, Text, StyleSheet } from 'react-native';

function MyCard() {
  return (
    <ImageBackground
      source={{ uri: 'https://example.com/background.jpg' }}
      style={styles.background}
      imageStyle={styles.image}
    >
      <Text style={styles.text}>Hello World</Text>
    </ImageBackground>
  );
}

const styles = StyleSheet.create({
  background: { width: 300, height: 200, justifyContent: 'center' },
  image: { borderRadius: 10 },
  text: { color: 'white', fontSize: 24, textAlign: 'center' },
});

Image Events

<Image
  source={{ uri: 'https://example.com/image.jpg' }}
  style={{ width: 200, height: 200 }}
  onLoadStart={() => console.log('Loading started')}
  onLoadEnd={() => console.log('Loading finished')}
  onError={(error) => console.log('Error:', error)}
/>

FastImage for Caching

For better performance with remote images, use react-native-fast-image:

import FastImage from 'react-native-fast-image';

<FastImage
  source={{
    uri: 'https://example.com/image.jpg',
    priority: FastImage.priority.normal,
  }}
  style={{ width: 200, height: 200 }}
  resizeMode={FastImage.resizeMode.cover}
/>

Mini-Project: Build an Image Gallery with Thumbnails

Create an image gallery with thumbnails and a main image display:

import React, { useState } from 'react';
import { Image, View, FlatList, TouchableOpacity, StyleSheet, Dimensions } from 'react-native';

const images = [
  { id: '1', uri: 'https://picsum.photos/200/200?random=1', full: 'https://picsum.photos/800/600?random=1' },
  { id: '2', uri: 'https://picsum.photos/200/200?random=2', full: 'https://picsum.photos/800/600?random=2' },
  { id: '3', uri: 'https://picsum.photos/200/200?random=3', full: 'https://picsum.photos/800/600?random=3' },
  { id: '4', uri: 'https://picsum.photos/200/200?random=4', full: 'https://picsum.photos/800/600?random=4' },
  { id: '5', uri: 'https://picsum.photos/200/200?random=5', full: 'https://picsum.photos/800/600?random=5' },
  { id: '6', uri: 'https://picsum.photos/200/200?random=6', full: 'https://picsum.photos/800/600?random=6' },
];

export default function App() {
  const [selectedImage, setSelectedImage] = useState(images[0]);

  const renderThumbnail = ({ item }) => (
    <TouchableOpacity onPress={() => setSelectedImage(item)}>
      <Image
        source={{ uri: item.uri }}
        style={[
          styles.thumbnail,
          selectedImage.id === item.id && styles.selectedThumbnail,
        ]}
      />
    </TouchableOpacity>
  );

  return (
    <View style={styles.container}>
      <Image
        source={{ uri: selectedImage.full }}
        style={styles.mainImage}
        resizeMode="contain"
      />
      <FlatList
        data={images}
        renderItem={renderThumbnail}
        keyExtractor={(item) => item.id}
        horizontal
        showsHorizontalScrollIndicator={false}
        style={styles.thumbnailList}
      />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#000' },
  mainImage: { width: Dimensions.get('window').width, height: 400 },
  thumbnailList: { maxHeight: 100 },
  thumbnail: { width: 80, height: 80, margin: 5, borderRadius: 5 },
  selectedThumbnail: { borderWidth: 3, borderColor: '#007AFF' },
});

This creates an image gallery with a main display and horizontal thumbnail scroll.

Summary

  • Use require() for local images and { uri: '...' } for remote images
  • Remote images require explicit width and height
  • resizeMode controls how images fit their container
  • ImageBackground allows displaying content over images
  • Consider FastImage for better caching and performance with remote images
