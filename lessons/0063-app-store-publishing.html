Lesson 63: App Store Publishing with EAS

Phase 8 — Production Concepts

Lesson Goal Learn how to configure EAS Build, create optimized build profiles, and submit your React Native app to the Apple App Store and Google Play Store.

Setting Up EAS Build

EAS (Expo Application Services) Build is a cloud build service that compiles your React Native app into installable binaries for iOS and Android. It handles the complexity of native build environments so you don't need a Mac for iOS builds.

Installation and Configuration

# Install the EAS CLI globally
npm install -g eas-cli

# Log in to your Expo account
eas login

# Navigate to your project and configure EAS
cd my-app
eas build:configure

This creates an eas.json file in your project root with default build profiles.

Understanding Build Profiles

Build profiles define different configurations for various purposes. The default eas.json includes three profiles:

{
  "cli": {
    "version": ">= 5.0.0"
  },
  "build": {
    "development": {
      "developmentClient": true,
      "distribution": "internal",
      "ios": {
        "simulator": true
      }
    },
    "preview": {
      "distribution": "internal",
      "ios": {
        "simulator": false
      }
    },
    "production": {
      "autoIncrement": true
    }
  },
  "submit": {
    "production": {
      "ios": {
        "appleId": "your-apple-id@email.com",
        "ascAppId": "your-app-store-connect-app-id"
      },
      "android": {
        "serviceAccountKeyPath": "./google-services.json"
      }
    }
  }
}

Profile Breakdown

  • development — Dev client builds for internal testing with debugging tools enabled
  • preview — TestFlight/Play Internal Testing builds for broader internal testing
  • production — Final release builds optimized for App Store and Play Store submission

Building Your App

# Development build (for testing with dev tools)
eas build --profile development --platform ios
eas build --profile development --platform android

# Preview build (for TestFlight / Internal Testing)
eas build --profile preview --platform all

# Production build (for store submission)
eas build --profile production --platform all

Store Listing Requirements

Before submitting, prepare your store listings with:

Apple App Store

  • App name (up to 30 characters)
  • Subtitle (up to 30 characters)
  • Description (up to 4000 characters)
  • Keywords (up to 100 characters, comma-separated)
  • Screenshots for all required device sizes
  • App icon (1024x1024px)
  • Privacy policy URL
  • Support URL

Google Play Store

  • App title (up to 30 characters)
  • Short description (up to 80 characters)
  • Full description (up to 4000 characters)
  • Screenshots (min 2, max 8 per device type)
  • Feature graphic (1024x500px)
  • App icon (512x512px)
  • Privacy policy URL

Submitting Your App

# Submit to App Store Connect (iOS)
eas submit --platform ios --profile production

# Submit to Google Play Console (Android)
eas submit --platform android --profile production

# Submit to both stores
eas submit --platform all --profile production

Submission Checklist

  1. Run your app in production mode and test all features
  2. Verify your app icon and splash screen look correct
  3. Test on multiple device sizes and orientations
  4. Ensure all required store listing assets are ready
  5. Set up your app's privacy policy and support URLs
  6. Configure in-app purchases if applicable
  7. Review platform-specific guidelines (Apple Human Interface Guidelines, Material Design)

Mini-Project: Configure EAS Build for Your Project

Set up EAS Build with custom build profiles for your React Native project:

# Step 1: Install EAS CLI
npm install -g eas-cli

# Step 2: Login to Expo
eas login

# Step 3: Initialize EAS in your project
eas build:configure

# Step 4: Customize eas.json with your profiles
cat <<EOF > eas.json
{
  "cli": { "version": ">= 5.0.0" },
  "build": {
    "development": {
      "developmentClient": true,
      "distribution": "internal"
    },
    "staging": {
      "env": {
        "APP_ENV": "staging"
      },
      "distribution": "internal"
    },
    "production": {
      "env": {
        "APP_ENV": "production"
      },
      "autoIncrement": true
    }
  }
}
EOF

# Step 5: Build a preview version
eas build --profile preview --platform android

Verify the build completes and download the installable binary from the EAS dashboard.

Summary

  • EAS Build provides cloud-based compilation for React Native apps on iOS and Android
  • Build profiles (development, preview, production) configure builds for different purposes
  • eas build:configure generates the eas.json configuration file
  • Prepare store listings with screenshots, descriptions, icons, and privacy policies before submission
  • eas submit uploads your build directly to App Store Connect or Google Play Console
  • Always test thoroughly in preview mode before submitting to production
