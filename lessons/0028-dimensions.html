Lesson 0028: Dimensions API

Phase 3 — Implementation Concepts

Lesson Goal Master the Dimensions API and useWindowDimensions hook to create responsive layouts that adapt to different screen sizes.

Dimensions API

The Dimensions API provides information about the device screen:

import { Dimensions } from 'react-native';

const { width, height } = Dimensions.get('window');
console.log('Screen width:', width);
console.log('Screen height:', height);

useWindowDimensions Hook

The recommended way to get screen dimensions in functional components:

import { useWindowDimensions } from 'react-native';

function MyComponent() {
  const { width, height } = useWindowDimensions();
  
  return (
    <View>
      <Text>Width: {width}, Height: {height}</Text>
    </View>
  );
}

Responsive Sizing

Calculate sizes based on screen dimensions:

import { Dimensions } from 'react-native';

const { width, height } = Dimensions.get('window');

// Percentage-based sizing
const cardWidth = width * 0.9;  // 90% of screen width
const cardHeight = height * 0.3; // 30% of screen height

// Responsive font size
const fontSize = width < 350 ? 14 : 16;

// Responsive spacing
const padding = width < 350 ? 10 : 20;

Percentage-Based Layouts

Use percentage strings for flexible layouts:

<View style={{ width: '100%', height: '100%' }}>
  <View style={{ width: '50%', height: 100 }}>
    <Text>Half width</Text>
  </View>
</View>

Orientation Handling

import { useWindowDimensions } from 'react-native';

function ResponsiveComponent() {
  const { width, height } = useWindowDimensions();
  const isLandscape = width > height;
  
  return (
    <View style={{
      flexDirection: isLandscape ? 'row' : 'column',
    }}>
      <View style={{ flex: 1 }}>
        <Text>Content 1</Text>
      </View>
      <View style={{ flex: 1 }}>
        <Text>Content 2</Text>
      </View>
    </View>
  );
}

Breakpoints

Create breakpoint system for different screen sizes:

const breakpoints = {
  small: 350,
  medium: 600,
  large: 900,
};

const getBreakpoint = (width) => {
  if (width < breakpoints.small) return 'small';
  if (width < breakpoints.medium) return 'medium';
  return 'large';
};

function ResponsiveComponent() {
  const { width } = useWindowDimensions();
  const breakpoint = getBreakpoint(width);
  
  const styles = {
    small: { fontSize: 14, padding: 10 },
    medium: { fontSize: 16, padding: 15 },
    large: { fontSize: 18, padding: 20 },
  };
  
  return (
    <View style={styles[breakpoint]}>
      <Text>Responsive content</Text>
    </View>
  );
}

Mini-Project: Build a Responsive Layout

Create a responsive layout that adapts to different screen sizes:

import React from 'react';
import { View, Text, StyleSheet, useWindowDimensions } from 'react-native';

const breakpoints = {
  small: 350,
  medium: 600,
};

export default function ResponsiveLayout() {
  const { width, height } = useWindowDimensions();
  const isSmall = width < breakpoints.small;
  const isMedium = width < breakpoints.medium;
  const isLandscape = width > height;

  return (
    <View style={styles.container}>
      <Text style={styles.header}>
        Responsive Layout ({width.toFixed(0)} x {height.toFixed(0)})
      </Text>
      
      <View style={[
        styles.content,
        isLandscape && styles.landscapeContent,
      ]}>
        <View style={[
          styles.card,
          { width: isSmall ? '100%' : isMedium ? '80%' : '60%' },
        ]}>
          <Text style={[
            styles.cardTitle,
            { fontSize: isSmall ? 16 : 20 },
          ]}>
            Responsive Card
          </Text>
          <Text style={styles.cardText}>
            This card adapts to screen size: {isSmall ? 'Small' : isMedium ? 'Medium' : 'Large'}
          </Text>
        </View>
        
        <View style={[
          styles.grid,
          isLandscape && styles.gridLandscape,
        ]}>
          <View style={[styles.gridItem, { backgroundColor: '#007AFF' }]}>
            <Text style={styles.gridText}>Item 1</Text>
          </View>
          <View style={[styles.gridItem, { backgroundColor: '#34C759' }]}>
            <Text style={styles.gridText}>Item 2</Text>
          </View>
          {!isLandscape && (
            <View style={[styles.gridItem, { backgroundColor: '#FF9500' }]}>
              <Text style={styles.gridText}>Item 3</Text>
            </View>
          )}
        </View>
      </View>
      
      <View style={styles.footer}>
        <Text style={styles.footerText}>
          Orientation: {isLandscape ? 'Landscape' : 'Portrait'}
        </Text>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#f5f5f5' },
  header: { fontSize: 20, fontWeight: 'bold', padding: 20, textAlign: 'center' },
  content: { flex: 1, padding: 20 },
  landscapeContent: { flexDirection: 'row' },
  card: { backgroundColor: 'white', borderRadius: 10, padding: 20, marginBottom: 20, alignSelf: 'center' },
  cardTitle: { fontWeight: 'bold', marginBottom: 10 },
  cardText: { color: '#666' },
  grid: { flexDirection: 'row', flexWrap: 'wrap', justifyContent: 'space-between' },
  gridLandscape: { flexDirection: 'column', width: '30%' },
  gridItem: { width: '48%', height: 100, borderRadius: 10, justifyContent: 'center', alignItems: 'center', marginBottom: 10 },
  gridText: { color: 'white', fontWeight: 'bold' },
  footer: { padding: 20, backgroundColor: 'white' },
  footerText: { textAlign: 'center', color: '#666' },
});

This creates a responsive layout that adapts to screen size and orientation.

Summary

  • Use useWindowDimensions() to get responsive screen dimensions
  • Dimensions update automatically when screen size changes (rotation, etc.)
  • Use percentage-based layouts for flexible sizing
  • Create breakpoint systems for different screen sizes
  • Handle orientation changes with isLandscape checks
  • Always test on different screen sizes for responsive design
