Lesson 0024: FlatList

Phase 3 — Implementation Concepts

Lesson Goal Master FlatList for efficient rendering of lists, optimize performance, and implement infinite scrolling.

What is FlatList?

FlatList is a React Native component for rendering efficient, scrollable lists of data. It renders items lazily (only when they're about to appear on screen), making it perfect for large datasets.

Basic FlatList Usage

import React from 'react';
import { FlatList, Text, View } from 'react-native';

const data = [
  { id: '1', title: 'Item 1' },
  { id: '2', title: 'Item 2' },
  { id: '3', title: 'Item 3' },
];

function MyList() {
  return (
    <FlatList
      data={data}
      keyExtractor={(item) => item.id}
      renderItem={({ item }) => (
        <View>
          <Text>{item.title}</Text>
        </View>
      )}
    />
  );
}

Essential Props

data: Array of items to render

keyExtractor: Function to extract unique key for each item

renderItem: Function to render each item

initialNumToRender: Number of items to render initially

removeClippedSubviews: Remove off-screen views from native hierarchy

Infinite Scrolling (Pagination)

function InfiniteList() {
  const [data, setData] = useState([]);
  const [page, setPage] = useState(1);
  const [loading, setLoading] = useState(false);

  const loadMore = () => {
    if (loading) return;
    setLoading(true);
    // Fetch next page of data
    fetchMoreData(page).then((newData) => {
      setData([...data, ...newData]);
      setPage(page + 1);
      setLoading(false);
    });
  };

  return (
    <FlatList
      data={data}
      keyExtractor={(item) => item.id}
      renderItem={renderItem}
      onEndReached={loadMore}
      onEndReachedThreshold={0.5}
      ListFooterComponent={loading ? <ActivityIndicator /> : null}
    />
  );
}

Mini-Project: Build a FlatList with 100 Items

Create a performant FlatList with 100 items and infinite scrolling:

import React, { useState, useEffect } from 'react';
import { FlatList, Text, View, StyleSheet, ActivityIndicator } from 'react-native';

const generateData = (page) => {
  const items = [];
  for (let i = 1; i <= 20; i++) {
    const id = (page - 1) * 20 + i;
    items.push({ id: String(id), title: `Item ${id}` });
  }
  return items;
};

export default function App() {
  const [data, setData] = useState([]);
  const [page, setPage] = useState(1);
  const [loading, setLoading] = useState(false);
  const [refreshing, setRefreshing] = useState(false);

  useEffect(() => {
    // Load initial data
    setData(generateData(1));
  }, []);

  const loadMore = () => {
    if (loading) return;
    setLoading(true);
    setTimeout(() => {
      const newData = generateData(page + 1);
      setData([...data, ...newData]);
      setPage(page + 1);
      setLoading(false);
    }, 1000);
  };

  const onRefresh = () => {
    setRefreshing(true);
    setTimeout(() => {
      setData(generateData(1));
      setPage(1);
      setRefreshing(false);
    }, 1000);
  };

  const renderItem = ({ item }) => (
    <View style={styles.item}>
      <Text style={styles.itemText}>{item.title}</Text>
    </View>
  );

  return (
    <View style={styles.container}>
      <FlatList
        data={data}
        keyExtractor={(item) => item.id}
        renderItem={renderItem}
        onEndReached={loadMore}
        onEndReachedThreshold={0.5}
        ListFooterComponent={loading ? <ActivityIndicator style={styles.loader} /> : null}
        refreshing={refreshing}
        onRefresh={onRefresh}
        initialNumToRender={10}
        windowSize={5}
      />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#fff' },
  item: { padding: 20, borderBottomWidth: 1, borderBottomColor: '#eee' },
  itemText: { fontSize: 16 },
  loader: { padding: 20 },
});

This creates a FlatList with 100+ items, pull-to-refresh, and infinite scrolling.

Summary

  • FlatList renders items lazily for better performance with large lists
  • Always provide a unique keyExtractor for each item
  • Use onEndReached for infinite scrolling/pagination
  • Optimize with initialNumToRender, windowSize, and removeClippedSubviews
  • Use getItemLayout when item heights are fixed for better performance
