Lesson 73: Image Optimization

Phase 9 — Optimization Concepts

Lesson Goal Learn image compression, WebP format usage, lazy loading images, server-side resizing, progressive loading, and FastImage optimization for React Native apps.

Why Image Optimization Matters

Images are typically the largest assets in a mobile app. Unoptimized images waste memory, slow down rendering, consume mobile data, and cause frame drops when scrolling through lists. A single full-resolution photo can be 5-10MB — an image gallery could exhaust device memory quickly.

Image Compression

Compress images to reduce file size without visible quality loss. Always compress before displaying or uploading.

import ImageResizer from 'react-native-image-resizer';

// Compress a local image
const compressImage = async (uri, maxWidth = 800, quality = 80) => {
  try {
    const result = await ImageResizer.createResizedImage(
      uri,
      maxWidth,       // max width in pixels
      maxWidth * 0.75, // proportional height
      'JPEG',          // output format
      quality,         // quality 0-100
      0,               // rotation
      undefined,       // output path (undefined = temp)
      false,           // keep metadata
      { mode: 'contain' } // resize mode
    );
    console.log(`Compressed: ${result.size} bytes at ${result.uri}`);
    return result.uri;
  } catch (error) {
    console.error('Compression failed:', error);
    return uri; // fallback to original
  }
};

// Use in a component
const ProfilePhotoUpload = () => {
  const handleUpload = async () => {
    const image = await launchImageLibrary({ mediaType: 'photo' });
    if (image.assets?.[0]) {
      const compressedUri = await compressImage(
        image.assets[0].uri,
        600, // thumbnails should be smaller
        75
      );
      await uploadPhoto(compressedUri);
    }
  };

  return <Button title="Upload Photo" onPress={handleUpload} />;
};

WebP Format

WebP provides 25-35% smaller file sizes than JPEG at equivalent quality, and supports transparency like PNG. Use it whenever possible.

// Serving WebP from a CDN (recommended approach)
// Configure your CDN to serve WebP when the client supports it
const getImageUrl = (imageId, width = 400) => {
  return `https://cdn.example.com/images/${imageId}?w=${width}&fmt=webp`;
};

// In React Native, the Image component supports WebP on both platforms
import { Image } from 'react-native';

function ProductImage({ productId }) {
  return (
    <Image
      source={{ uri: `https://cdn.example.com/products/${productId}?w=400&fmt=webp` }}
      style={{ width: 200, height: 200 }}
      resizeMode="cover"
    />
  );
}

// Convert images to WebP during upload
import ImageResizer from 'react-native-image-resizer';

const convertToWebP = async (uri) => {
  const result = await ImageResizer.createResizedImage(
    uri,
    800,
    600,
    'WebP', // output as WebP
    85      // quality
  );
  return result.uri;
};

Lazy Loading Images

Only load images when they're about to enter the viewport. This is critical for long lists and galleries.

import React, { useState, useCallback } from 'react';
import { View, FlatList, Image, Dimensions } from 'react-native';

const { width: SCREEN_WIDTH } = Dimensions.get('window');

function ImageGallery({ images }) {
  const [visibleImages, setVisibleImages] = useState(new Set());

  const onViewableItemsChanged = useCallback(({ viewableItems }) => {
    const visible = new Set(viewableItems.map(item => item.index));
    setVisibleImages(visible);
  }, []);

  const viewabilityConfig = { itemVisiblePercentThreshold: 20 };

  const renderItem = useCallback(({ item, index }) => {
    const isVisible = visibleImages.has(index);

    return (
      <View style={{ width: SCREEN_WIDTH, height: SCREEN_WIDTH }}>
        {isVisible ? (
          <Image
            source={{ uri: item.url }}
            style={{ width: '100%', height: '100%' }}
            resizeMode="cover"
          />
        ) : (
          <View style={{ flex: 1, backgroundColor: '#f0f0f0' }} /> // placeholder
        )}
      </View>
    );
  }, [visibleImages]);

  return (
    <FlatList
      data={images}
      renderItem={renderItem}
      keyExtractor={item => item.id}
      onViewableItemsChanged={onViewableItemsChanged}
      viewabilityConfig={viewabilityConfig}
      getItemLayout={(_, index) => ({
        length: SCREEN_WIDTH,
        offset: SCREEN_WIDTH * index,
        index,
      })}
    />
  );
}

Server-Side Resizing

Never download a 4000x3000 image to display at 200x200. Request the exact size you need from the server.

// Use query parameters to request the right size
const getImageUrl = (imageId, width, height) => {
  const params = new URLSearchParams();
  params.set('w', width);
  if (height) params.set('h', height);
  params.set('fit', 'crop');     // crop to fit dimensions
  params.set('fmt', 'webp');     // serve as WebP
  params.set('q', '80');         // quality 80%
  return `https://cdn.example.com/images/${imageId}?${params}`;
};

// Usage — request different sizes for different contexts
const Thumbnail = ({ imageId }) => (
  <Image
    source={{ uri: getImageUrl(imageId, 100, 100) }}
    style={{ width: 50, height: 50, borderRadius: 25 }}
  />
);

const DetailImage = ({ imageId }) => (
  <Image
    source={{ uri: getImageUrl(imageId, 800) }}
    style={{ width: '100%', height: 300 }}
    resizeMode="cover"
  />
);

const FullScreenImage = ({ imageId }) => (
  <Image
    source={{ uri: getImageUrl(imageId, 1200) }}
    style={{ width: '100%', height: '100%' }}
    resizeMode="contain"
  />
);

Progressive Loading

Show a low-quality placeholder while the full image loads. This makes the app feel faster and reduces perceived wait time.

import { useState } from 'react';
import { View, Image, StyleSheet } from 'react-native';

function ProgressiveImage({ thumbnailUri, fullUri, style }) {
  const [loaded, setLoaded] = useState(false);

  return (
    <View style={[styles.container, style]}>
      {/* Low-quality placeholder — loads fast */}
      <Image
        source={{ uri: thumbnailUri }}
        style={[StyleSheet.absoluteFill, styles.placeholder]}
        blurRadius={2}
      />
      {/* Full quality image — loads over network */}
      <Image
        source={{ uri: fullUri }}
        style={[StyleSheet.absoluteFill, styles.fullImage]}
        onLoad={() => setLoaded(true)}
        resizeMode="cover"
      />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { overflow: 'hidden' },
  placeholder: { opacity: 0.6 },
  fullImage: { opacity: 1 },
});

// Usage
<ProgressiveImage
  thumbnailUri="https://cdn.example.com/img/123?w=20&q=10"
  fullUri="https://cdn.example.com/img/123?w=800&q=80"
  style={{ width: 300, height: 200 }}
/>

FastImage Optimization

react-native-fast-image is a high-performance image component with built-in caching, prioritization, and preloading.

import FastImage from 'react-native-fast-image';

// Basic usage with caching
<FastImage
  style={{ width: 200, height: 200 }}
  source={{
    uri: 'https://cdn.example.com/image.jpg',
    priority: FastImage.priority.normal,
    cache: FastImage.cacheControl.immutable, // cache forever
  }}
  resizeMode={FastImage.resizeMode.cover}
/>

// Preload images before they're displayed
FastImage.preload([
  { uri: 'https://cdn.example.com/image1.jpg' },
  { uri: 'https://cdn.example.com/image2.jpg' },
  { uri: 'https://cdn.example.com/image3.jpg' },
]);

// Priority loading — important images load first
<FastImage
  source={{
    uri: imageUrl,
    priority: FastImage.priority.high, // load this image first
  }}
  style={{ width: 100, height: 100 }}
/>

// Handle load events for progressive loading
function OptimizedImage({ uri }) {
  const [loaded, setLoaded] = useState(false);

  return (
    <View>
      {!loaded && <ActivityIndicator style={StyleSheet.absoluteFill} />}
      <FastImage
        source={{ uri, cache: FastImage.cacheControl.immutable }}
        style={{ width: '100%', height: 200 }}
        resizeMode={FastImage.resizeMode.cover}
        onLoad={() => setLoaded(true)}
      />
    </View>
  );
}

Mini-Project: Optimize Images in Your App

Implement image optimization with compression, lazy loading, and FastImage caching.

import React, { useState, useCallback } from 'react';
import { View, FlatList, Dimensions, StyleSheet } from 'react-native';
import FastImage from 'react-native-fast-image';
import ImageResizer from 'react-native-image-resizer';

const { width: SCREEN_WIDTH } = Dimensions.get('window');
const IMAGE_SIZE = (SCREEN_WIDTH - 30) / 3; // 3-column grid

// Optimized image component with caching and lazy loading
function OptimizedImage({ uri, size = IMAGE_SIZE }) {
  const [loaded, setLoaded] = useState(false);

  return (
    <View style={[styles.imageContainer, { width: size, height: size }]}>
      <FastImage
        source={{
          uri: `${uri}?w=${Math.round(size * 2)}&fmt=webp&q=75`,
          priority: FastImage.priority.normal,
          cache: FastImage.cacheControl.immutable,
        }}
        style={[styles.image, { opacity: loaded ? 1 : 0 }]}
        resizeMode={FastImage.resizeMode.cover}
        onLoad={() => setLoaded(true)}
      />
      {!loaded && <View style={[styles.placeholder, { width: size, height: size }]} />}
    </View>
  );
}

// Image compression utility
const compressForUpload = async (uri) => {
  const result = await ImageResizer.createResizedImage(
    uri, 1200, 1200, 'WebP', 80, 0
  );
  return result.uri;
};

// Gallery with lazy loading
export default function ImageGallery({ images }) {
  const renderItem = useCallback(({ item }) => (
    <OptimizedImage uri={item.url} />
  ), []);

  const keyExtractor = useCallback((item) => item.id, []);

  return (
    <FlatList
      data={images}
      renderItem={renderItem}
      keyExtractor={keyExtractor}
      numColumns={3}
      style={styles.list}
    />
  );
}

const styles = StyleSheet.create({
  list: { padding: 5 },
  imageContainer: { margin: 2, overflow: 'hidden', borderRadius: 4 },
  image: { width: '100%', height: '100%' },
  placeholder: { backgroundColor: '#e0e0e0', position: 'absolute' },
});

Test with a list of 100+ images. Use React DevTools Profiler to verify that images outside the viewport don't trigger unnecessary re-renders.

Summary

  • Images are the largest assets in mobile apps — optimize them aggressively
  • Compress images with ImageResizer before displaying or uploading
  • WebP format provides 25-35% smaller files than JPEG with equivalent quality
  • Only load images that are visible on screen — use FlatList's onViewableItemsChanged for lazy loading
  • Request images at the exact size you need from the server, not full resolution
  • Progressive loading shows a placeholder while the full image loads, improving perceived performance
  • FastImage provides built-in caching, priority loading, and preloading for high-performance image display
