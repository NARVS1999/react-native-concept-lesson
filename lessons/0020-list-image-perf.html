Lesson 0020: List and Image Performance

Phase 7 — Advanced Concepts

Lesson Goal Optimize FlatList performance with virtualization, cache images, and prevent memory leaks.

FlatList Optimization

FlatList is already virtualized, but you can optimize it further:

<FlatList
  data={DATA}
  keyExtractor={item => item.id}
  renderItem={renderItem}
  // Performance props
  initialNumToRender={10}        // How many items to render first
  maxToRenderPerBatch={10}       // Items per batch render
  windowSize={5}                  // Number of items kept in memory
  removeClippedSubviews={true}   // Unmount off-screen items
  getItemLayout={(data, index) => (  // Skip measurement calculation
    { length: 60, offset: 60 * index, index }
  )}
/>
getItemLayout If all items have the same height, provide getItemLayout so FlatList can skip layout measurement — significant performance boost.

Image Caching

Use react-native-fast-image for better image performance with caching:

import FastImage from 'react-native-fast-image';

function CachedImage({ uri }) {
  return (
    <FastImage
      style={{ width: 200, height: 200 }}
      source={{
        uri: uri,
        priority: FastImage.priority.normal,
        cache: FastImage.cacheControl.immutable,
      }}
      resizeMode={FastImage.resizeMode.cover}
    />
  );
}

FastImage automatically caches images to disk, reducing network requests on subsequent loads.

Memory Leaks

Memory leaks happen when you don't clean up resources. Common causes in React Native:

CauseSolution
Uncleaned intervals/timeoutsClear in useEffect cleanup
Event listeners not removedRemove in useEffect cleanup
Unmounted component state updatesTrack mount status with useRef
Large images in memoryUse FastImage with cache control
function SafeComponent() {
  const isMounted = useRef(true);

  useEffect(() => {
    return () => { isMounted.current = false; };
  }, []);

  useEffect(() => {
    fetchData().then(data => {
      if (isMounted.current) { // Only update if still mounted
        setData(data);
      }
    });
  }, []);
}
