Phase 8 — Production Concepts

Lesson Goal Set up CI/CD pipelines, crash reporting, and over-the-air updates for production apps.

CI/CD Pipelines

Continuous Integration/Continuous Deployment automates building, testing, and deploying your app on every code change.

# Example GitHub Actions workflow for React Native
name: Build & Test
on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3
        with:
          node-version: 18
      - run: npm ci
      - run: npm test
      - run: npx eas build --platform android --non-interactive

Popular CI/CD services for React Native:

  • GitHub Actions — Free for public repos, easy setup
  • EAS Build — Expo's cloud build service
  • Fastlane — Automate iOS/Android builds and submissions
  • Bitrise — Mobile-focused CI/CD platform

Crash Reporting

Crash reporting captures errors in production so you can fix them before users complain:

// Sentry setup
import * as Sentry from '@sentry/react-native';

Sentry.init({
  dsn: 'https://your-dsn@sentry.io/project-id',
});

Top crash reporting tools:

ToolKey Feature
SentryError tracking with source maps, performance monitoring
Crashlytics (Firebase)Free, integrates with Google ecosystem
BugsnagExcellent React Native support, stability scores

OTA Updates (Over-the-Air)

OTA updates let you push JavaScript changes without going through the app store review process:

# Install EAS Update
npm install eas-cli

# Create an update
eas update --branch production --message "Fix login bug"
Limitations OTA updates can only change JavaScript code and assets. Native code changes (new dependencies with native modules) still require a full app store release.

Summary

  • CI/CD automates building, testing, and deployment
  • Crash reporting (Sentry, Crashlytics) captures production errors
  • OTA updates push JS changes without app store review
  • OTA cannot change native code — that still needs a full release
