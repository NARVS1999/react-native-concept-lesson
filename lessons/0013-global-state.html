Lesson 0013: Global State Management

Phase 5 — Architectural Concepts

Lesson Goal Manage complex global state with Redux Toolkit and Zustand for scalable app architecture.

When to Use Global State

Context API works for simple shared state. But for complex apps with many state updates, complex transitions, and middleware needs, use a dedicated state management library.

Use global state for:

  • Authentication state (user login, tokens)
  • Shopping cart / user preferences
  • Data that many unrelated components need
  • Complex state transitions with reducers

Redux Toolkit (RTK)

Redux Toolkit is the official, modern way to write Redux. It reduces boilerplate significantly:

import { configureStore, createSlice } from '@reduxjs/toolkit';
import { Provider, useSelector, useDispatch } from 'react-redux';

// Create a slice (reducer + actions in one)
const counterSlice = createSlice({
  name: 'counter',
  initialState: { value: 0 },
  reducers: {
    increment: (state) => { state.value += 1; },
    decrement: (state) => { state.value -= 1; },
    incrementBy: (state, action) => { state.value += action.payload; },
  },
});

export const { increment, decrement, incrementBy } = counterSlice.actions;

// Create store
const store = configureStore({ reducer: { counter: counterSlice.reducer } });

// Use in components
function Counter() {
  const count = useSelector(state => state.counter.value);
  const dispatch = useDispatch();

  return (
    <View>
      <Text>{count}</Text>
      <Pressable onPress={() => dispatch(increment())}><Text>+1</Text></Pressable>
      <Pressable onPress={() => dispatch(decrement())}><Text>-1</Text></Pressable>
      <Pressable onPress={() => dispatch(incrementBy(5))}><Text>+5</Text></Pressable>
    </View>
  );
}

// Wrap app with Provider
function App() {
  return (
    <Provider store={store}>
      <Counter />
    </Provider>
  );
}
Key Insight RTK uses Immer under the hood, so you can write "mutating" logic that is actually immutable. state.value += 1 is safe and correct.

Zustand: Lightweight Alternative

Zustand is a minimal state management library — no providers, no boilerplate, just hooks:

import { create } from 'zustand';

const useStore = create((set) => ({
  count: 0,
  increment: () => set((state) => ({ count: state.count + 1 })),
  decrement: () => set((state) => ({ count: state.count - 1 })),
}));

function Counter() {
  const { count, increment, decrement } = useStore();

  return (
    <View>
      <Text>{count}</Text>
      <Pressable onPress={increment}><Text>+1</Text></Pressable>
      <Pressable onPress={decrement}><Text>-1</Text></Pressable>
    </View>
  );
}
RTK vs Zustand
  • RTK: Best for large teams, complex state, middleware, devtools, persistence
  • Zustand: Best for small-medium apps, simplicity, minimal boilerplate

Summary

  • Redux Toolkit: Official, feature-rich, best for large apps
  • Zustand: Minimal, hook-based, best for simplicity
  • Use global state when data is shared across unrelated components
  • RTK uses Immer for safe immutable updates
