Lesson 0036: Linking

Phase 4 — Integration Concepts

Lesson Goal Use the Linking API to open URLs, check if apps can handle links, open device settings, configure deep linking with URL schemes, and handle incoming links in your React Native app.

Introduction to Linking

The Linking API gives your React Native app the ability to open external URLs, interact with other apps, and handle deep links. It works on both iOS and Android with platform-specific behaviors.

Opening URLs with openURL

The most common use case is opening a URL in the device's default browser:

import { Linking } from 'react-native';

// Open a website
async function openWebsite() {
  const url = 'https://reactnative.dev';
  const supported = await Linking.canOpenURL(url);

  if (supported) {
    await Linking.openURL(url);
  } else {
    console.log("Don't know how to open this URL:", url);
  }
}

// Open an email compose
function openEmail() {
  Linking.openURL('mailto:support@example.com?subject=Help&body=Hello');
}

// Open a phone dialer
function openPhone() {
  Linking.openURL('tel:+1234567890');
}

// Open SMS
function openSMS() {
  Linking.openURL('sms:+1234567890?body=Hello!');
}

Checking with canOpenURL

Always check if a URL can be opened before attempting to open it. This prevents crashes and allows you to provide fallbacks:

async function shareOrFallback(url, fallbackMessage) {
  const canOpen = await Linking.canOpenURL(url);

  if (canOpen) {
    await Linking.openURL(url);
  } else {
    // App for this URL scheme is not installed
    Alert.alert('Not Available', fallbackMessage);
  }
}

// Example: Open in specific app or show web fallback
async function openInMap(address) {
  const mapUrl = `maps:q=${address}`;
  const webMapUrl = `https://maps.google.com?q=${address}`;

  if (await Linking.canOpenURL(mapUrl)) {
    await Linking.openURL(mapUrl);
  } else {
    await Linking.openURL(webMapUrl);
  }
}

Opening Device Settings

On iOS, you can open the app's settings page directly. On Android, you can open the general settings:

async function openAppSettings() {
  // iOS: Opens this app's settings page
  // Android: Opens general app settings
  const supported = await Linking.canOpenURL('app-settings:');

  if (supported) {
    await Linking.openURL('app-settings:');
  } else {
    // Fallback for platforms that don't support app-settings scheme
    Linking.openURL('package:com.myapp');
  }
}

Deep Linking Setup

Deep linking allows external sources (other apps, web pages, QR codes) to open specific screens in your app. Configure URL schemes in your native projects:

// In ios/MyApp/Info.plist — add URL scheme
// <key>CFBundleURLSchemes</key>
// <array>
//   <string>myapp</string>
// </array>

// In android/app/src/main/AndroidManifest.xml — add intent filter
// <intent-filter>
//   <action android:name="android.intent.action.VIEW" />
//   <category android:name="android.intent.category.DEFAULT" />
//   <category android:name="android.intent.category.BROWSABLE" />
//   <data android:scheme="myapp" android:host="open" />
// </intent-filter>

Handling Incoming Links

Use Linking.addEventListener to respond when the app is opened via a deep link:

import { Linking } from 'react-native';

function DeepLinkHandler({ navigation }) {
  useEffect(() => {
    // Handle links that opened the app
    async function handleInitialURL() {
      const initialUrl = await Linking.getInitialURL();
      if (initialUrl) {
        handleDeepLink(initialUrl);
      }
    }

    // Listen for links while the app is running
    const subscription = Linking.addEventListener('url', (event) => {
      handleDeepLink(event.url);
    });

    handleInitialURL();

    return () => subscription?.remove();
  }, []);

  function handleDeepLink(url) {
    // Parse the URL and navigate to the right screen
    const route = url.replace('myapp://open/', '');
    const [screen, param] = route.split('/');

    switch (screen) {
      case 'profile':
        navigation.navigate('Profile', { userId: param });
        break;
      case 'settings':
        navigation.navigate('Settings');
        break;
      default:
        navigation.navigate('Home');
    }
  }

  return null; // This component doesn't render anything
}

URL Scheme Patterns

Design clear, consistent URL schemes for your app:

// Custom scheme
myapp://open/profile/123
myapp://open/settings
myapp://open/order/456

// Universal links (iOS) / App links (Android)
https://myapp.com/profile/123
https://myapp.com/settings

Mini-Project: Help Screen with Links

Build a help screen with buttons that open email, website, phone, and device settings using the Linking API.

import React from 'react';
import { View, Text, TouchableOpacity, StyleSheet, ScrollView, Linking, Alert } from 'react-native';

function HelpScreen() {
  const openEmail = async () => {
    const url = 'mailto:support@myapp.com?subject=Help Request';
    const supported = await Linking.canOpenURL(url);
    if (supported) {
      await Linking.openURL(url);
    } else {
      Alert.alert('Error', 'No email app found');
    }
  };

  const openWebsite = async () => {
    const url = 'https://myapp.com/help';
    const supported = await Linking.canOpenURL(url);
    if (supported) {
      await Linking.openURL(url);
    } else {
      Alert.alert('Error', 'Cannot open browser');
    }
  };

  const openPhone = async () => {
    const url = 'tel:+18005551234';
    const supported = await Linking.canOpenURL(url);
    if (supported) {
      await Linking.openURL(url);
    } else {
      Alert.alert('Error', 'Phone not available on this device');
    }
  };

  const openSettings = async () => {
    const url = 'app-settings:';
    const supported = await Linking.canOpenURL(url);
    if (supported) {
      await Linking.openURL(url);
    } else {
      Alert.alert('Info', 'Open Settings app manually');
    }
  };

  return (
    <ScrollView style={styles.container}>
      <Text style={styles.title}>Help & Support</Text>

      <TouchableOpacity style={styles.button} onPress={openEmail}>
        <Text style={styles.buttonIcon}>✉️</Text>
        <View style={styles.buttonTextContainer}>
          <Text style={styles.buttonTitle}>Email Support</Text>
          <Text style={styles.buttonDesc}>support@myapp.com</Text>
        </View>
      </TouchableOpacity>

      <TouchableOpacity style={styles.button} onPress={openWebsite}>
        <Text style={styles.buttonIcon}>🌐</Text>
        <View style={styles.buttonTextContainer}>
          <Text style={styles.buttonTitle}>Visit Website</Text>
          <Text style={styles.buttonDesc}>myapp.com/help</Text>
        </View>
      </TouchableOpacity>

      <TouchableOpacity style={styles.button} onPress={openPhone}>
        <Text style={styles.buttonIcon}>📞</Text>
        <View style={styles.buttonTextContainer}>
          <Text style={styles.buttonTitle}>Call Us</Text>
          <Text style={styles.buttonDesc}>1-800-555-1234</Text>
        </View>
      </TouchableOpacity>

      <TouchableOpacity style={styles.button} onPress={openSettings}>
        <Text style={styles.buttonIcon}>⚙️</Text>
        <View style={styles.buttonTextContainer}>
          <Text style={styles.buttonTitle}>App Settings</Text>
          <Text style={styles.buttonDesc}>Manage permissions</Text>
        </View>
      </TouchableOpacity>
    </ScrollView>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 20, backgroundColor: '#f5f5f5' },
  title: { fontSize: 28, fontWeight: 'bold', marginBottom: 30, textAlign: 'center' },
  button: {
    flexDirection: 'row', alignItems: 'center',
    backgroundColor: 'white', padding: 16, marginBottom: 12,
    borderRadius: 12, elevation: 2,
  },
  buttonIcon: { fontSize: 28, marginRight: 16 },
  buttonTextContainer: { flex: 1 },
  buttonTitle: { fontSize: 18, fontWeight: '600' },
  buttonDesc: { fontSize: 14, color: '#666', marginTop: 2 },
});

export default HelpScreen;

Summary

  • Linking.openURL() opens URLs in the default browser, email, phone, or SMS app
  • Linking.canOpenURL() checks if a URL scheme is supported before opening
  • Linking.getInitialURL() gets the URL that opened the app (cold start deep link)
  • Linking.addEventListener('url', callback) handles deep links while the app is running
  • Configure custom URL schemes (e.g., myapp://) in native project settings for deep linking
  • Always provide fallbacks when a URL scheme is not available on the device
