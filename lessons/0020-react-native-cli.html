Lesson 0020: React Native CLI (Bare Workflow)

Phase 3 — Implementation Concepts

Lesson Goal Understand the React Native CLI bare workflow, set up native development environments, and know when to choose CLI over Expo.

What is React Native CLI?

The React Native CLI provides a bare workflow where you have full access to the native project files (iOS and Android). This gives you complete control over native code and configuration.

Unlike Expo's managed workflow, you're responsible for managing native dependencies and build configurations.

Creating a CLI Project

npx react-native init MyProject
cd MyProject

This creates a project with separate ios/ and directories containing native code.

Native Development Setup

To run CLI projects, you need native development environments:

For iOS:

  • macOS computer (required)
  • Xcode (latest version recommended)
  • CocoaPods (Ruby gem)
# Install CocoaPods
sudo gem install cocoapods

# Install iOS dependencies
cd ios && pod install && cd ..

For Android:

  • Android Studio
  • Java Development Kit (JDK)
  • Android SDK

Running the App

# Start Metro bundler
npm start

# Run on iOS
npx react-native run-ios

# Run on Android
npx react-native run-android

Project Structure Comparison

Expo Project:

my-app/
├── App.js
├── app.json
├── package.json
└── node_modules/

CLI Project:

MyProject/
├── App.js
├── android/
├── ios/
├── package.json
└── node_modules/

When to Choose CLI Over Expo

  • Custom native modules — When you need to write native code in Swift/Kotlin
  • Existing native apps — Integrating React Native into existing native projects
  • Specific SDK requirements — When you need access to latest native APIs not yet in Expo
  • Full control — When you need complete control over native build process
  • Enterprise requirements — Custom build pipelines and CI/CD configurations

Mini-Project: Compare Expo vs CLI Project Structure

Create both types of projects and compare their structures:

# Create Expo project
npx create-expo-app ExpoProject

# Create CLI project
npx react-native init CLIProject

Then:

  1. Compare the directory structures of both projects
  2. Note the presence of android/ and ios/ folders in CLI project
  3. Examine the app.json in Expo vs android/ and ios/ configs in CLI
  4. Run both projects and observe the differences
  5. Document which project type would be better for different scenarios

Summary

  • React Native CLI provides a bare workflow with full native access
  • CLI projects include ios/ and android/ directories
  • You need Xcode for iOS development and Android Studio for Android
  • Choose CLI when you need custom native modules or full control
  • Expo is better for beginners and rapid prototyping
