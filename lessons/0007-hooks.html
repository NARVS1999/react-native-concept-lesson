Lesson 7: Hooks

Phase 1 — Foundational Concepts

Lesson Goal By the end of this lesson, you will understand what hooks are, why they were introduced, the rules you must follow when using hooks, the most important built-in hooks, and how to create custom hooks for reusable logic.

What Are Hooks?

Hooks are functions that let you "hook into" React Native's features from function components. Before hooks, you needed class components to use state or lifecycle methods. Hooks brought that power to function components, making them the standard for React Native development.

The most common hooks are:

  • useState — Manage local state
  • useEffect — Handle side effects
  • useRef — Persist values without re-rendering
  • useMemo — Memoize expensive computations
  • useCallback — Memoize functions
  • useContext — Consume context values

Why Hooks Exist

Before hooks, class components had several pain points:

  • Complex lifecycle methods: componentDidMount, componentDidUpdate, componentWillUnmount scattered related logic across multiple methods
  • this-binding confusion: Class methods required manual binding of this
  • Hard to reuse stateful logic: Higher-order components (HOCs) and render props created wrapper hell
  • Complex components: Large components were hard to understand because related logic was separated

Hooks solve all of these problems by allowing you to extract and reuse stateful logic without changing your component hierarchy.

Hook Rules

Hooks have two critical rules that you must always follow:

Rule 1: Only Call Hooks at the Top Level

Never call hooks inside loops, conditions, or nested functions. Always call them at the top level of your component.

// WRONG - hook inside condition
function UserGreeting({ isLoggedIn }) {
  if (isLoggedIn) {
    const [name, setName] = useState('');  // WRONG!
  }
  return (/* ... */);
}

// CORRECT - hook always at top level
function UserGreeting({ isLoggedIn }) {
  const [name, setName] = useState('');

  return (/* ... */);
}

Rule 2: Only Call Hooks from React Functions

Only call hooks from React function components or from custom hooks. Never call them from regular JavaScript functions.

// WRONG - hook in a regular function
function getData() {
  const [data, setData] = useState(null);  // WRONG!
}

// CORRECT - hook in a component
function DataFetcher() {
  const [data, setData] = useState(null);
  return (/* ... */);
}

// CORRECT - hook in a custom hook
function useData() {
  const [data, setData] = useState(null);
  return data;
}

Built-in Hooks Overview

useState

Manages local component state. Returns the current value and a setter function.

const [count, setCount] = useState(0);
const [user, setUser] = useState({ name: '', email: '' });
const [items, setItems] = useState<string[]>([]);

// Update state
setCount(5);
setCount(prev => prev + 1);  // Functional update

// Update object state immutably
setUser(prev => ({ ...prev, name: 'Alice' }));

// Update array state immutably
setItems(prev => [...prev, 'new item']);

useEffect

Performs side effects after render. Replaces lifecycle methods like componentDidMount, componentDidUpdate, and componentWillUnmount.

import { useState, useEffect } from 'react';

function UserProfile({ userId }) {
  const [user, setUser] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    // Runs after every render
    let cancelled = false;

    async function fetchUser() {
      setLoading(true);
      const response = await fetch(`/api/users/${userId}`);
      const data = await response.json();
      if (!cancelled) {
        setUser(data);
        setLoading(false);
      }
    }

    fetchUser();

    // Cleanup function (runs before next effect or unmount)
    return () => {
      cancelled = true;
    };
  }, [userId]);  // Dependency array - re-runs when userId changes

  if (loading) return <Text>Loading...</Text>;
  return <Text>{user?.name}</Text>;
}

// Common patterns:
useEffect(() => {
  // Runs after EVERY render
});

useEffect(() => {
  // Runs only on MOUNT (first render)
}, []);

useEffect(() => {
  // Runs when 'count' changes
}, [count]);

useRef

Persists a mutable value across renders without triggering a re-render. Commonly used for TextInput references and storing interval IDs.

import { useRef } from 'react';
import { TextInput, Button, View } from 'react-native';

function SearchBar() {
  const inputRef = useRef<TextInput>(null);

  const focusInput = () => {
    inputRef.current?.focus();
  };

  return (
    <View>
      <TextInput ref={inputRef} placeholder="Search..." />
      <Button title="Focus" onPress={focusInput} />
    </View>
  );
}

// Storing interval ID
function Timer() {
  const [seconds, setSeconds] = useState(0);
  const intervalRef = useRef(null);

  const startTimer = () => {
    intervalRef.current = setInterval(() => {
      setSeconds(prev => prev + 1);
    }, 1000);
  };

  const stopTimer = () => {
    clearInterval(intervalRef.current);
  };

  useEffect(() => {
    return () => clearInterval(intervalRef.current);
  }, []);

  return (/* ... */);
}

useMemo

Memoizes an expensive computation so it only recalculates when its dependencies change.

import { useMemo } from 'react';

function ProductList({ products, searchTerm }) {
  // This expensive filter only runs when products or searchTerm changes
  const filteredProducts = useMemo(() => {
    console.log('Filtering products...');
    return products.filter(product =>
      product.name.toLowerCase().includes(searchTerm.toLowerCase())
    );
  }, [products, searchTerm]);

  return (
    <FlatList
      data={filteredProducts}
      renderItem={({ item }) => <Text>{item.name}</Text>}
    />
  );
}

useCallback

Memoizes a function definition so it doesn't get recreated on every render. Useful when passing callbacks to child components.

import { useCallback, useState } from 'react';

function TodoApp() {
  const [todos, setTodos] = useState([]);

  // This function is memoized and won't change between renders
  const addTodo = useCallback((text) => {
    setTodos(prev => [...prev, { id: Date.now(), text, done: false }]);
  }, []);

  const toggleTodo = useCallback((id) => {
    setTodos(prev =>
      prev.map(todo =>
        todo.id === id ? { ...todo, done: !todo.done } : todo
      )
    );
  }, []);

  return (
    <View>
      <TodoInput onAdd={addTodo} />
      <TodoList todos={todos} onToggle={toggleTodo} />
    </View>
  );
}

useContext

Consumes context values without prop drilling.

import { createContext, useContext, useState } from 'react';

const ThemeContext = createContext('light');

function App() {
  const [theme, setTheme] = useState('light');

  return (
    <ThemeContext.Provider value={theme}>
      <HomeScreen />
    </ThemeContext.Provider>
  );
}

function HomeScreen() {
  // No prop drilling needed!
  const theme = useContext(ThemeContext);

  return (
    <View style={{ backgroundColor: theme === 'dark' ? '#000' : '#fff' }}>
      <Text>Current theme: {theme}</Text>
    </View>
  );
}

Custom Hooks

Custom hooks let you extract reusable stateful logic into separate functions. A custom hook is simply a function whose name starts with "use" and that calls other hooks.

// Custom hook for form handling
function useForm(initialValues) {
  const [values, setValues] = useState(initialValues);

  const handleChange = (field, value) => {
    setValues(prev => ({ ...prev, [field]: value }));
  };

  const reset = () => setValues(initialValues);

  return { values, handleChange, reset };
}

// Usage
function ContactForm() {
  const { values, handleChange, reset } = useForm({
    name: '',
    email: '',
    message: '',
  });

  return (
    <View>
      <TextInput
        value={values.name}
        onChangeText={(val) => handleChange('name', val)}
      />
      <TextInput
        value={values.email}
        onChangeText={(val) => handleChange('email', val)}
      />
      <TextInput
        value={values.message}
        onChangeText={(val) => handleChange('message', val)}
        multiline
      />
      <Button title="Reset" onPress={reset} />
    </View>
  );
}

Mini-Project: Create a Custom useCounter Hook

Extract counter logic into a reusable custom hook:

// useCounter.ts - Custom hook
import { useState, useCallback } from 'react';

interface UseCounterOptions {
  initialValue?: number;
  step?: number;
  min?: number;
  max?: number;
}

interface UseCounterReturn {
  count: number;
  increment: () => void;
  decrement: () => void;
  reset: () => void;
  setCount: (value: number) => void;
  isAtMin: boolean;
  isAtMax: boolean;
}

export function useCounter({
  initialValue = 0,
  step = 1,
  min = -Infinity,
  max = Infinity,
}: UseCounterOptions = {}): UseCounterReturn {
  const [count, setCount] = useState(initialValue);

  const increment = useCallback(() => {
    setCount(prev => Math.min(prev + step, max));
  }, [step, max]);

  const decrement = useCallback(() => {
    setCount(prev => Math.max(prev - step, min));
  }, [step, min]);

  const reset = useCallback(() => {
    setCount(initialValue);
  }, [initialValue]);

  return {
    count,
    increment,
    decrement,
    reset,
    setCount,
    isAtMin: count <= min,
    isAtMax: count >= max,
  };
}

Summary

  • Hooks let function components use state, side effects, and other React features
  • They were introduced to solve class component pain points (complex lifecycle, this-binding, code reuse)
  • Always call hooks at the top level — never inside loops, conditions, or nested functions
  • Only call hooks from React function components or custom hooks
  • useState manages local state
  • useEffect handles side effects and lifecycle-like behavior
  • useRef persists mutable values without re-rendering
  • useMemo and useCallback optimize performance through memoization
  • Custom hooks extract reusable logic into clean, testable functions
