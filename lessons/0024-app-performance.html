Lesson 0024: App Performance

Phase 9 — Optimization Concepts

Lesson Goal Profile and optimize re-renders, reduce bundle size, and improve cold start time.

Re-render Optimization

Use the React DevTools Profiler to identify which components re-render and why:

// Enable in development
// Shake device → Dev Menu → Show Perf Monitor

// Or use React DevTools Profiler
// npm install -g react-devtools

Common causes of unnecessary re-renders:

  • Parent component re-renders (even if props don't change)
  • Inline styles/objects created every render
  • Context value changing too often
  • Missing key prop on list items
// BAD: Creates new object every render
<View style={{ padding: 16 }}>

// GOOD: Defined outside render or use StyleSheet
const styles = StyleSheet.create({ container: { padding: 16 } });
<View style={styles.container}>

Bundle Size Analysis

Analyze your JavaScript bundle to find large dependencies:

# Install bundle analyzer
npx react-native-bundle-visualizer

# Or for Expo
npx expo export --dump-sourcemap
npx source-map-explorer 'dist/*.js'

Tips to reduce bundle size:

  • Use import { specific } from 'library' instead of import * from 'library'
  • Replace heavy libraries with lighter alternatives
  • Enable tree shaking (most bundlers do this by default)
  • Lazy load screens not needed at startup

Startup Performance

Cold start time is critical for user retention. Optimize with:

1

Enable Hermes engine (default in RN 0.70+) — pre-compiles JS to bytecode

2

Lazy load non-critical screens and components

3

Minimize initial render — show a splash screen with minimal content

4

Use inline requires for modules only needed later

Mini-Project: Profile and Optimize

Use React DevTools Profiler to record a session while navigating your app. Identify one component that re-renders unnecessarily and fix it with React.memo or useMemo.

Summary

  • Use React DevTools Profiler to find unnecessary re-renders
  • Analyze bundle size to find heavy dependencies
  • Optimize startup with Hermes, lazy loading, and minimal initial render
  • Avoid inline objects — use StyleSheet.create
