Lesson 14: Flexbox

Phase 2 — Core Concepts

Lesson Goal By the end of this lesson, you will be able to master Flexbox layout in React Native, understand the column-first default direction, and build responsive layouts using justifyContent, alignItems, flex, and position properties.

Flexbox in React Native

Flexbox is the primary layout system in React Native. It is used to arrange and align elements within a container. If you are coming from web development, there is one critical difference: React Native defaults to flexDirection: column, not row.

Web vs React Native Default

Property Web (CSS) React Native
flexDirection default row column
display: flex default block flex
box-sizing border-box border-box

flexDirection

flexDirection controls the direction in which child elements are laid out.

import React from 'react';
import { View, Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <View style={styles.row}>
      <View style={styles.box}><Text>1</Text></View>
      <View style={styles.box}><Text>2</Text></View>
      <View style={styles.box}><Text>3</Text></View>
    </View>
  );
}

const styles = StyleSheet.create({
  row: {
    flexDirection: 'row',
    gap: 10,
  },
  box: {
    width: 80,
    height: 80,
    backgroundColor: '#3498db',
    justifyContent: 'center',
    alignItems: 'center',
  },
});

The four flexDirection options are: column (default), column-reverse, row, and row-reverse.

justifyContent

justifyContent aligns children along the main axis (the direction of flexDirection):

import React from 'react';
import { View, Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <View style={[styles.row, { justifyContent: 'flex-start' }]}>
        <Text>flex-start</Text>
      </View>
      <View style={[styles.row, { justifyContent: 'center' }]}>
        <Text>center</Text>
      </View>
      <View style={[styles.row, { justifyContent: 'flex-end' }]}>
        <Text>flex-end</Text>
      </View>
      <View style={[styles.row, { justifyContent: 'space-between' }]}>
        <Text>between</Text>
      </View>
      <View style={[styles.row, { justifyContent: 'space-around' }]}>
        <Text>around</Text>
      </View>
      <View style={[styles.row, { justifyContent: 'space-evenly' }]}>
        <Text>evenly</Text>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { gap: 10, padding: 10 },
  row: {
    flexDirection: 'row',
    height: 50,
    backgroundColor: '#ecf0f1',
  },
});

The options are: flex-start, center, flex-end, space-between, space-around, and space-evenly.

alignItems

alignItems aligns children along the cross axis (perpendicular to flexDirection):

import React from 'react';
import { View, Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <View style={[styles.row, { alignItems: 'flex-start', height: 100 }]}>
        <Text>flex-start</Text>
      </View>
      <View style={[styles.row, { alignItems: 'center', height: 100 }]}>
        <Text>center</Text>
      </View>
      <View style={[styles.row, { alignItems: 'flex-end', height: 100 }]}>
        <Text>flex-end</Text>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { gap: 10, padding: 10 },
  row: {
    flexDirection: 'row',
    backgroundColor: '#ecf0f1',
    gap: 10,
  },
});

alignSelf

alignSelf overrides alignItems for a single child element:

import React from 'react';
import { View, Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <View style={styles.row}>
        <View style={styles.box}><Text>Default</Text></View>
        <View style={[styles.box, { alignSelf: 'flex-start' }]}>
          <Text>flex-start</Text>
        </View>
        <View style={[styles.box, { alignSelf: 'center' }]}>
          <Text>center</Text>
        </View>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { padding: 10 },
  row: {
    flexDirection: 'row',
    height: 120,
    backgroundColor: '#ecf0f1',
    gap: 10,
    alignItems: 'stretch',
  },
  box: {
    width: 60,
    height: 40,
    backgroundColor: '#3498db',
    justifyContent: 'center',
    alignItems: 'center',
  },
});

flex Property

The flex property controls how much space a child takes up relative to its siblings:

import React from 'react';
import { View, Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <View style={[styles.box, { flex: 1 }]}>
        <Text>flex: 1</Text>
      </View>
      <View style={[styles.box, { flex: 2 }]}>
        <Text>flex: 2</Text>
      </View>
      <View style={[styles.box, { flex: 1 }]}>
        <Text>flex: 1</Text>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flexDirection: 'row',
    height: 100,
    gap: 4,
  },
  box: {
    backgroundColor: '#3498db',
    justifyContent: 'center',
    alignItems: 'center',
  },
});

With flex: 1, 2, and 1, the middle box takes up twice as much space as the others.

gap Property

The gap property adds consistent spacing between children without using margins:

import React from 'react';
import { View, Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <View style={styles.card}><Text>Card 1</Text></View>
      <View style={styles.card}><Text>Card 2</Text></View>
      <View style={styles.card}><Text>Card 3</Text></View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flexDirection: 'row',
    gap: 12,
    padding: 16,
  },
  card: {
    flex: 1,
    backgroundColor: '#ecf0f1',
    padding: 16,
    borderRadius: 8,
    alignItems: 'center',
  },
});

Position: Absolute and Relative

React Native supports both relative (default) and absolute positioning:

import React from 'react';
import { View, Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <View style={styles.parent}>
        <Text>Parent Container</Text>
        <View style={styles.absoluteBox}>
          <Text>Absolute</Text>
        </View>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { padding: 16 },
  parent: {
    backgroundColor: '#ecf0f1',
    padding: 20,
    height: 150,
  },
  absoluteBox: {
    position: 'absolute',
    bottom: 10,
    right: 10,
    backgroundColor: '#e74c3c',
    padding: 10,
  },
});

Summary

  • React Native defaults to flexDirection: column, unlike web CSS which defaults to row
  • justifyContent aligns children along the main axis
  • alignItems aligns children along the cross axis
  • alignSelf overrides alignItems for individual children
  • flex controls how much space a child takes relative to siblings
  • gap adds consistent spacing between children
  • Position absolute positions relative to the nearest positioned ancestor
  • Position relative (default) offsets the element from its normal position
