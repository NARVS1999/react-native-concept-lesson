Lesson 56: Lazy Loading

Phase 7 — Advanced Concepts

Lesson Goal Understand React.lazy and Suspense for code splitting, learn dynamic imports, implement route-based splitting, and handle loading states effectively in React Native apps.

Why Lazy Loading?

In a typical React Native app, all screen components are bundled together. As the app grows, the initial bundle size increases, slowing down startup. Lazy loading defers loading of non-critical components until they're actually needed.

React.lazy and Suspense

React.lazy lets you render a dynamic import as a regular component. Suspense shows a fallback UI while the lazy component loads.

import React, { Suspense, lazy } from 'react';
import { ActivityIndicator, View } from 'react-native';

// Dynamic import — code is split into a separate bundle
const HeavyScreen = lazy(() => import('./screens/HeavyScreen'));
const SettingsScreen = lazy(() => import('./screens/SettingsScreen'));
const ProfileScreen = lazy(() => import('./screens/ProfileScreen'));

const App = () => (
  <Suspense fallback={
    <View style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}>
      <ActivityIndicator size="large" color="#007AFF" />
      <Text>Loading...</Text>
    </View>
  }>
    <NavigationContainer>
      <Stack.Navigator>
        <Stack.Screen name="Home" component={HomeScreen} />
        <Stack.Screen name="Heavy" component={HeavyScreen} />
        <Stack.Screen name="Settings" component={SettingsScreen} />
        <Stack.Screen name="Profile" component={ProfileScreen} />
      </Stack.Navigator>
    </NavigationContainer>
  </Suspense>
);

Dynamic Imports

Dynamic imports use import() syntax which returns a Promise. React.lazy wraps this to create a lazy-loaded component.

// Static import (included in main bundle)
import HeavyComponent from './HeavyComponent';

// Dynamic import (split into separate chunk)
const HeavyComponent = lazy(() => import('./HeavyComponent'));

// Named exports with dynamic import
const HeavyComponent = lazy(() =>
  import('./HeavyComponent').then(module => ({
    default: module.HeavyComponent,
  }))
);

// Multiple named exports
const { HeavyComponent, LightComponent } = await import('./Components');

Code Splitting Strategy

Identify which components are loaded upfront vs. on demand. Route-based splitting is the most common strategy.

// Split by route — only load screens when navigating to them
const HomeScreen = lazy(() => import('./screens/HomeScreen'));
const DetailScreen = lazy(() => import('./screens/DetailScreen'));
const SettingsScreen = lazy(() => import('./screens/SettingsScreen'));
const ProfileScreen = lazy(() => import('./screens/ProfileScreen'));

// Split by feature — load feature modules on demand
const ChatFeature = lazy(() => import('./features/Chat'));
const PaymentFeature = lazy(() => import('./features/Payment'));
const AnalyticsFeature = lazy(() => import('./features/Analytics'));

Loading States

Handle loading and error states gracefully with Suspense boundaries and error boundaries.

import React, { Suspense, lazy, Component } from 'react';

// Error boundary for lazy loading failures
class LazyErrorBoundary extends Component {
  state = { hasError: false, error: null };

  static getDerivedStateFromError(error) {
    return { hasError: true, error };
  }

  render() {
    if (this.state.hasError) {
      return (
        <View style={styles.errorContainer}>
          <Text style={styles.errorText}>Failed to load component</Text>
          <Button
            title="Retry"
            onPress={() => this.setState({ hasError: false })}
          />
        </View>
      );
    }
    return this.props.children;
  }
}

const App = () => (
  <LazyErrorBoundary>
    <Suspense fallback={<LoadingSpinner />}>
      <NavigationContainer>
        {/* ... routes ... */}
      </NavigationContainer>
    </Suspense>
  </LazyErrorBoundary>
);

Preloading Components

You can preload lazy components during idle time to avoid loading delays.

// Preload a component (call this on app startup or during idle time)
const preloadDetailScreen = () => {
  // Trigger the dynamic import to start loading
  import('./screens/DetailScreen');
};

// In a touchable component, preload on press-in
<TouchableOpacity
  onPressIn={preloadDetailScreen}
  onPress={() => navigation.navigate('Detail')}
>
  <Text>View Details</Text>
</TouchableOpacity>

Mini-Project: Lazy Load a Heavy Screen

import React, { Suspense, lazy, useState, Component } from 'react';
import { View, Text, Button, ActivityIndicator, StyleSheet, FlatList } from 'react-native';
import { NavigationContainer } from '@react-navigation/native';
import { createNativeStackNavigator } from '@react-navigation/native-stack';

const Stack = createNativeStackNavigator();

// Lazy load the heavy screen
const HeavyScreen = lazy(() => import('./screens/HeavyScreen'));

class LazyErrorBoundary extends Component {
  state = { hasError: false };
  static getDerivedStateFromError() { return { hasError: true }; }
  render() {
    if (this.state.hasError) {
      return (
        <View style={styles.center}>
          <Text>Failed to load. Please try again.</Text>
          <Button title="Retry" onPress={() => this.setState({ hasError: false })} />
        </View>
      );
    }
    return this.props.children;
  }
}

const HomeScreen = ({ navigation }) => (
  <View style={styles.center}>
    <Text style={styles.title}>Lazy Loading Demo</Text>
    <Text style={styles.subtitle}>HeavyScreen is loaded on demand</Text>
    <Button
      title="Open Heavy Screen"
      onPress={() => navigation.navigate('Heavy')}
    />
  </View>
);

const App = () => (
  <LazyErrorBoundary>
    <Suspense fallback={
      <View style={styles.center}>
        <ActivityIndicator size="large" color="#007AFF" />
        <Text style={{ marginTop: 10 }}>Loading HeavyScreen...</Text>
      </View>
    }>
      <NavigationContainer>
        <Stack.Navigator>
          <Stack.Screen name="Home" component={HomeScreen} />
          <Stack.Screen name="Heavy" component={HeavyScreen} />
        </Stack.Navigator>
      </NavigationContainer>
    </Suspense>
  </LazyErrorBoundary>
);

const styles = StyleSheet.create({
  center: { flex: 1, justifyContent: 'center', alignItems: 'center', padding: 20 },
  title: { fontSize: 24, fontWeight: 'bold', marginBottom: 10 },
  subtitle: { fontSize: 14, color: '#666', marginBottom: 20 },
});

export default App;

Summary

  • React.lazy enables code splitting by dynamically importing components
  • Suspense provides a fallback UI while lazy components load
  • Route-based splitting is the most common code splitting strategy
  • Error boundaries handle lazy loading failures gracefully
  • Components can be preloaded during idle time for smoother navigation
  • Code splitting reduces initial bundle size and improves startup performance
