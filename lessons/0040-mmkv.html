What is MMKV?

MMKV is a key-value storage framework originally developed by WeChat. It's significantly faster than AsyncStorage because it uses memory-mapped files and runs synchronously on the native thread.

MMKV vs AsyncStorage

FeatureMMKVAsyncStorage
Speed~30x fasterSlow (async)
APISynchronousAsynchronous
EncryptionBuilt-in AESNot built-in
Size LimitNo practical limit6MB default
Multi-processSupportedNot supported

Instantiating MMKV

Create an MMKV instance to start storing data. You can create multiple instances with different names.

// storage/storage.js
import { MMKV } from 'react-native-mmkv';

// Default instance
export const storage = new MMKV();

// Custom instance with ID and encryption key
export const secureStorage = new MMKV({
  id: 'user-storage',
  encryptionKey: 'my-secret-key-123',
});

// Reset instance (useful for testing)
storage.clearAll();

Basic Operations: set, get, delete

MMKV provides simple synchronous methods for all operations.

import { storage } from './storage';

// SET - Store different types
storage.set('username', 'JohnDoe');
storage.set('age', 25);
storage.set('isLoggedIn', true);
storage.set('score', 3.14);

// GET - Retrieve values with type safety
const username = storage.getString('username');  // 'JohnDoe'
const age = storage.getNumber('age');              // 25
const isLoggedIn = storage.getBoolean('isLoggedIn'); // true

// Check if key exists
const hasKey = storage.contains('username'); // true

// DELETE - Remove a key
storage.delete('username');

// Clear all data
storage.clearAll();

Storing Complex Data

// Store objects/arrays as JSON strings
const user = { name: 'John', age: 25, hobbies: ['reading', 'coding'] };
storage.set('user', JSON.stringify(user));

// Retrieve and parse
const userStr = storage.getString('user');
const parsedUser = userStr ? JSON.parse(userStr) : null;

// Store with try-catch for safety
try {
  const data = JSON.stringify(largeObject);
  storage.set('largeData', data);
} catch (error) {
  console.error('Failed to store data:', error);
}

Encryption

MMKV supports AES encryption out of the box. Just provide an encryption key when creating an instance.

// storage/secureStorage.js
import { MMKV } from 'react-native-mmkv';

export const secureStorage = new MMKV({
  id: 'secure-storage',
  encryptionKey: 'your-256-bit-encryption-key',
});

// Store sensitive data
secureStorage.set('authToken', 'eyJhbGciOiJIUzI1NiIs...');
secureStorage.set('refreshToken', 'dGhpcyBpcyBhIHJlZnJl...');

// Read is transparent - decryption happens automatically
const token = secureStorage.getString('authToken');

The useMMKVString Hook

React Native MMKV provides hooks that make MMKV state reactive — components re-render when the value changes.

// hooks/useSettings.js
import { useMMKVString, useMMKVNumber, useMMKVBoolean } from 'react-native-mmkv';
import { storage } from '../storage/storage';

export function useSettings() {
  const [theme, setTheme] = useMMKVString('theme', storage);
  const [fontSize, setFontSize] = useMMKVNumber('fontSize', storage);
  const [notifications, setNotifications] = useMMKVBoolean('notifications', storage);

  return {
    theme,
    setTheme,
    fontSize,
    setFontSize,
    notifications,
    setNotifications,
  };
}

Using the Hook in Components

// screens/SettingsScreen.js
import { View, Text, Switch, StyleSheet } from 'react-native';
import { useSettings } from '../hooks/useSettings';

export default function SettingsScreen() {
  const { theme, setTheme, notifications, setNotifications, fontSize, setFontSize } = useSettings();

  return (
    <View style={styles.container}>
      <View style={styles.row}>
        <Text>Dark Mode</Text>
        <Switch
          value={theme === 'dark'}
          onValueChange={(val) => setTheme(val ? 'dark' : 'light')}
        />
      </View>

      <View style={styles.row}>
        <Text>Notifications</Text>
        <Switch
          value={notifications ?? true}
          onValueChange={setNotifications}
        />
      </View>

      <View style={styles.row}>
        <Text>Font Size: {fontSize ?? 16}</Text>
        <Button title="Increase" onPress={() => setFontSize((fontSize ?? 16) + 2)} />
        <Button title="Decrease" onPress={() => setFontSize(Math.max(12, (fontSize ?? 16) - 2))} />
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 20 },
  row: { flexDirection: 'row', justifyContent: 'space-between', alignItems: 'center', paddingVertical: 10 },
});

Performance Tips

  • Use MMKV for frequently accessed data (settings, auth tokens, caches)
  • Store large objects as JSON strings when needed
  • Use separate MMKV instances for different data categories
  • Leverage encryption for sensitive data like tokens
  • The synchronous API eliminates the need for async/await in storage operations

Summary

  • MMKV is ~30x faster than AsyncStorage using memory-mapped files
  • All operations are synchronous — no async/await needed
  • Encryption is built-in with AES, just pass an encryptionKey
  • useMMKVString/Number/Boolean hooks make data reactive in components
  • Use separate instances for different data categories (settings, auth, cache)
  • Store complex data as JSON strings with JSON.stringify/parse
