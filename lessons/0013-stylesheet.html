Lesson 13: StyleSheet

Phase 2 — Core Concepts

Lesson Goal By the end of this lesson, you will be able to create and use StyleSheet for declarative styling, understand why StyleSheet is preferred over inline styles, compose styles using arrays, and optimize your React Native apps styling approach.

What is StyleSheet?

StyleSheet is a React Native API for creating style objects. It provides a declarative way to define styles similar to CSS classes. While you can use plain JavaScript objects for styles, StyleSheet offers important benefits.

import React from 'react';
import { View, Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <Text style={styles.title}>Hello StyleSheet!</Text>
      <Text style={styles.subtitle}>This is styled properly</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    justifyContent: 'center',
    alignItems: 'center',
    backgroundColor: '#f5f5f5',
  },
  title: {
    fontSize: 24,
    fontWeight: 'bold',
    color: '#2c3e50',
  },
  subtitle: {
    fontSize: 16,
    color: '#7f8c8d',
    marginTop: 8,
  },
});

Why Use StyleSheet Instead of Inline Styles?

There are three key reasons to prefer StyleSheet over inline styles:

1. Validation

StyleSheet validates your styles at creation time. If you make a typo like fotSize instead of fontSize, you will get a clear warning in development. Inline styles would silently fail.

// This will warn you about the typo
const styles = StyleSheet.create({
  title: {
    fotSize: 24,  // Warning: "fotSize" is not a valid style property
    fontSize: 24, // Correct
  },
});

// This would fail silently with inline styles
<Text style={{ fotSize: 24 }}>No warning!</Text>

2. Optimization

StyleSheet creates style IDs that are passed to the native layer. This reduces the amount of data sent over the bridge between JavaScript and native code, improving performance.

// Inline styles create a new object every render
<Text style={{ fontSize: 24, color: 'red' }}>Each render creates new object</Text>

// StyleSheet creates an ID reference - only the ID is sent over the bridge
const styles = StyleSheet.create({
  text: { fontSize: 24, color: 'red' }
});
<Text style={styles.text}>Only ID reference sent</Text>

3. Readability and Organization

StyleSheet separates styles from component logic, making your code cleaner and easier to maintain.

// Hard to read - styles mixed with logic
<View style={{ flex: 1, backgroundColor: '#fff', padding: 20, borderRadius: 8 }}>
  <Text style={{ fontSize: 18, fontWeight: 'bold', color: '#333' }}>
    Title
  </Text>
</View>

// Clean and readable - styles separated
<View style={styles.card}>
  <Text style={styles.cardTitle}>Title</Text>
</View>

const styles = StyleSheet.create({
  card: { flex: 1, backgroundColor: '#fff', padding: 20, borderRadius: 8 },
  cardTitle: { fontSize: 18, fontWeight: 'bold', color: '#333' },
});

Style Composition with Arrays

You can combine multiple styles using an array syntax. This is useful for creating reusable base styles with variants:

import React from 'react';
import { View, Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <Text style={[styles.text, styles.bold]}>Bold Text</Text>
      <Text style={[styles.text, styles.italic]}>Italic Text</Text>
      <Text style={[styles.text, styles.bold, styles.italic]}>Both</Text>
      <Text style={[styles.text, styles.red]}>Red Bold Text</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { padding: 20, gap: 10 },
  text: { fontSize: 16 },
  bold: { fontWeight: 'bold' },
  italic: { fontStyle: 'italic' },
  red: { color: '#e74c3c' },
});

Later styles in the array override earlier ones, so you can use this for conditional styling:

<Text style={[styles.text, isError && styles.error]}>
  {isError ? 'Something went wrong' : 'All good!'}
</Text>

StyleSheet.create vs Plain Objects

You can also define styles as plain JavaScript objects, but StyleSheet.create is preferred:

// Plain object - works but not recommended
const styles = {
  container: { flex: 1, backgroundColor: '#fff' },
  title: { fontSize: 24, fontWeight: 'bold' },
};

// StyleSheet.create - recommended
const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#fff' },
  title: { fontSize: 24, fontWeight: 'bold' },
});

Both work the same way, but StyleSheet.create provides validation and optimization benefits.

Dynamic Styles

You can create styles dynamically based on props or state using conditional arrays:

import React from 'react';
import { View, Text, StyleSheet } from 'react-native';

export default function Badge({ count, size = 'medium' }) {
  const badgeStyle = [
    styles.badge,
    size === 'large' ? styles.badgeLarge : styles.badgeSmall,
    count === 0 && styles.badgeEmpty,
  ];

  return (
    <View style={badgeStyle}>
      <Text style={styles.badgeText}>{count}</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  badge: {
    borderRadius: 12,
    backgroundColor: '#e74c3c',
    justifyContent: 'center',
    alignItems: 'center',
  },
  badgeLarge: { width: 32, height: 32 },
  badgeSmall: { width: 24, height: 24 },
  badgeEmpty: { backgroundColor: '#bdc3c7' },
  badgeText: { color: '#fff', fontSize: 12, fontWeight: 'bold' },
});

StyleSheet.flatten

The StyleSheet.flatten method merges multiple style objects into a single object:

import { StyleSheet } from 'react-native';

const merged = StyleSheet.flatten([
  { fontSize: 16, color: 'black' },
  { fontSize: 20, fontWeight: 'bold' },
]);
// Result: { fontSize: 20, color: 'black', fontWeight: 'bold' }
// Later values override earlier ones

Mini-Project: Create a Styled Card Component Using StyleSheet

Create a reusable card component with styled variants using StyleSheet:

import React from 'react';
import { View, Text, StyleSheet } from 'react-native';

export default function Card({ title, description, variant = 'default' }) {
  return (
    <View style={[styles.card, styles[variant]]}>
      <View style={[styles.badge, styles[variant + 'Badge']]}>
        <Text style={styles.badgeText}>{variant.toUpperCase()}</Text>
      </View>
      <Text style={styles.title}>{title}</Text>
      <Text style={styles.description}>{description}</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  card: {
    backgroundColor: '#ffffff',
    borderRadius: 12,
    padding: 20,
    margin: 16,
    shadowColor: '#000',
    shadowOffset: { width: 0, height: 2 },
    shadowOpacity: 0.1,
    shadowRadius: 8,
    elevation: 4,
  },
  default: { borderLeftWidth: 4, borderLeftColor: '#3498db' },
  success: { borderLeftWidth: 4, borderLeftColor: '#27ae60' },
  warning: { borderLeftWidth: 4, borderLeftColor: '#f39c12' },
  danger: { borderLeftWidth: 4, borderLeftColor: '#e74c3c' },
  badge: {
    alignSelf: 'flex-start',
    paddingHorizontal: 8,
    paddingVertical: 4,
    borderRadius: 4,
    marginBottom: 8,
  },
  defaultBadge: { backgroundColor: '#ebf5fb' },
  successBadge: { backgroundColor: '#eafaf1' },
  warningBadge: { backgroundColor: '#fef9e7' },
  dangerBadge: { backgroundColor: '#fdedec' },
  badgeText: { fontSize: 10, fontWeight: 'bold', color: '#333' },
  title: { fontSize: 18, fontWeight: 'bold', color: '#2c3e50', marginBottom: 4 },
  description: { fontSize: 14, color: '#7f8c8d', lineHeight: 20 },
});

This creates a card component with different color variants, all defined using StyleSheet.create for validation and optimization.

Summary

  • StyleSheet.create provides validation, optimization, and better code organization
  • Use array syntax [style1, style2] to combine multiple styles
  • Later styles in an array override earlier ones, enabling conditional styling
  • StyleSheet creates style IDs that are more efficient over the React Native bridge
  • Plain JavaScript objects work but miss the validation and optimization benefits
  • StyleSheet.flatten merges multiple style objects into one
  • Always prefer StyleSheet.create for static styles in your components
