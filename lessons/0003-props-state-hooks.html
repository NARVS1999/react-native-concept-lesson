Lesson 0003: Props, State, and Hooks

Phase 1 — Foundational Concepts

Lesson Goal Understand how data flows through components with props, how components manage their own data with state, and how hooks extend component capabilities.

Props: Data In

Props (short for "properties") are how a parent component passes data to a child. Props are read-only — the child cannot modify them.

// Parent passes props
<Greeting name="Ana" role="Developer" />

// Child receives props
function Greeting({ name, role }) {
  return (
    <View>
      <Text>Hello, {name}!</Text>
      <Text>Role: {role}</Text>
    </View>
  );
}
Props are immutable A child component should never try to modify its props. If you need to change data, use state instead.

State: Data That Changes

State is data owned by a component that can change over time. When state changes, the component re-renders with the new data.

import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <View>
      <Text>Count: {count}</Text>
      <Pressable onPress={() => setCount(count + 1)}>
        <Text>Add One</Text>
      </Pressable>
    </View>
  );
}

useState returns two things:

  • count — the current value
  • setCount — a function to update it (triggers re-render)

Hooks: Extending Components

Hooks are special functions that let you "hook into" React features. They only work inside functional components.

The most common hooks:

HookPurpose
useStateManage local state
useEffectRun side effects (API calls, subscriptions)
useRefPersist a value across renders without re-rendering
Hook Rules
  • Only call hooks at the top level of a component (not inside loops, conditions, or nested functions)
  • Only call hooks from React components or custom hooks

Putting It Together

Props + State + Components = a complete data flow:

function TodoItem({ title, onDelete }) {
  return (
    <View style={{ flexDirection: 'row', justifyContent: 'space-between' }}>
      <Text>{title}</Text>
      <Pressable onPress={onDelete}>
        <Text style={{ color: 'red' }}>Delete</Text>
      </Pressable>
    </View>
  );
}

function TodoList() {
  const [todos, setTodos] = useState(['Learn props', 'Learn state']);

  const removeTodo = (index) => {
    setTodos(todos.filter((_, i) => i !== index));
  };

  return (
    <View>
      {todos.map((todo, index) => (
        <TodoItem key={index} title={todo} onDelete={() => removeTodo(index)} />
      ))}
    </View>
  );
}

Mini-Project: Toggle Switch

Create a component with a boolean state that toggles between "ON" and "OFF" when pressed. Display the current state and change the background color based on it.

function ToggleSwitch() {
  const [isOn, setIsOn] = useState(false);

  return (
    <Pressable
      onPress={() => setIsOn(!isOn)}
      style={{
        padding: 20,
        backgroundColor: isOn ? '#4CAF50' : '#f44336',
        borderRadius: 8,
        alignItems: 'center'
      }}
    >
      <Text style={{ color: '#fff', fontSize: 18 }}>
        {isOn ? 'ON' : 'OFF'}
      </Text>
    </Pressable>
  );
}

Summary

  • Props pass data from parent to child — they are read-only
  • State is mutable data owned by a component — changing it triggers a re-render
  • Hooks let functional components use state and side effects
  • useState returns [value, setValue]
  • Only call hooks at the top level of components
