Lesson 4: Components

Phase 1 — Foundational Concepts

Lesson Goal By the end of this lesson, you will understand what components are, the difference between function and class components, how to compose components, naming conventions, file organization, and how to build reusable component patterns.

What Are Components?

Components are the building blocks of a React Native application. A component is a self-contained piece of UI that can accept data (props) and manage its own state. Think of components as reusable UI recipes — you define them once and use them throughout your app.

Every React Native app is a tree of components. At the top is your root component (usually App), and beneath it are increasingly specific UI pieces. For example, a social media feed might have a FeedScreen component containing PostCard components, each containing Avatar, PostContent, and LikeButton components.

// The simplest possible component
function Greeting() {
  return <Text>Hello, World!</Text>;
}

// Used in JSX
<Greeting />

Function Components vs Class Components

React Native supports two types of components. Function components are now the standard and should always be preferred.

Function Components (Modern, Recommended)

import React, { useState } from 'react';
import { View, Text, Button, StyleSheet } from 'react-native';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <View style={styles.container}>
      <Text style={styles.count}>{count}</Text>
      <Button title="Increment" onPress={() => setCount(count + 1)} />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { alignItems: 'center', padding: 20 },
  count: { fontSize: 48, fontWeight: 'bold' },
});

export default Counter;

Class Components (Legacy, Avoid)

import React, { Component } from 'react';
import { View, Text, Button, StyleSheet } from 'react-native';

class Counter extends Component {
  constructor(props) {
    super(props);
    this.state = { count: 0 };
  }

  increment = () => {
    this.setState({ count: this.state.count + 1 });
  };

  render() {
    return (
      <View style={styles.container}>
        <Text style={styles.count}>{this.state.count}</Text>
        <Button title="Increment" onPress={this.increment} />
      </View>
    );
  }
}

export default Counter;

Why Function Components Win

  • Simpler syntax: Less boilerplate, no constructor or this-binding
  • Hooks: Only available in function components — give you state, side effects, and more
  • Better performance: No overhead of class instantiation
  • Easier testing: Simple functions are easier to test than class instances
  • Future-proof: React team focuses all new features on function components

Component Composition

Composition is the practice of combining smaller components to build larger ones. This is the core principle of component-based architecture.

// Small, focused components
function Avatar({ imageUrl, size = 40 }) {
  return (
    <Image
      source={{ uri: imageUrl }}
      style={{ width: size, height: size, borderRadius: size / 2 }}
    />
  );
}

function Badge({ text, color = 'red' }) {
  return (
    <View style={[styles.badge, { backgroundColor: color }]}>
      <Text style={styles.badgeText}>{text}</Text>
    </View>
  );
}

// Composed component that combines smaller pieces
function UserHeader({ user }) {
  return (
    <View style={styles.header}>
      <Avatar imageUrl={user.avatar} size={50} />
      <View style={styles.headerInfo}>
        <Text style={styles.name}>{user.name}</Text>
        <Text style={styles.email}>{user.email}</Text>
      </View>
      {user.isVerified && <Badge text="Verified" color="blue" />}
    </View>
  );
}

Component Naming Rules

Following naming conventions keeps your codebase consistent and readable:

  • Component names must start with a capital letter: function MyComponent(), not function myComponent()
  • Use PascalCase: UserCard, NavigationHeader, TodoList
  • File names match component names: UserCard.tsx contains the UserCard component
  • One component per file: Each file should export one main component
// CORRECT - PascalCase component name
function UserCard() { /* ... */ }
export default UserCard;

// WRONG - lowercase starts with function call interpretation
function userCard() { /* ... */ }

Reusable Component Patterns

Here is a detailed example of a well-designed, reusable Button component:

import React from 'react';
import { TouchableOpacity, Text, ActivityIndicator, StyleSheet } from 'react-native';

type ButtonVariant = 'primary' | 'secondary' | 'danger' | 'ghost';
type ButtonSize = 'small' | 'medium' | 'large';

interface ButtonProps {
  title: string;
  onPress: () => void;
  variant?: ButtonVariant;
  size?: ButtonSize;
  loading?: boolean;
  disabled?: boolean;
}

export default function Button({
  title,
  onPress,
  variant = 'primary',
  size = 'medium',
  loading = false,
  disabled = false,
}: ButtonProps) {
  const buttonStyles = [
    styles.base,
    styles[variant],
    styles[size],
    disabled && styles.disabled,
  ];

  const textStyles = [
    styles.text,
    styles[`${variant}Text`],
    styles[`${size}Text`],
  ];

  return (
    <TouchableOpacity
      style={buttonStyles}
      onPress={onPress}
      disabled={disabled || loading}
      activeOpacity={0.7}
    >
      {loading ? (
        <ActivityIndicator color="#fff" size="small" />
      ) : (
        <Text style={textStyles}>{title}</Text>
      )}
    </TouchableOpacity>
  );
}

const styles = StyleSheet.create({
  base: {
    borderRadius: 8,
    alignItems: 'center',
    justifyContent: 'center',
    flexDirection: 'row',
  },
  primary: { backgroundColor: '#3b82f6' },
  secondary: { backgroundColor: '#6b7280' },
  danger: { backgroundColor: '#ef4444' },
  ghost: { backgroundColor: 'transparent' },
  small: { paddingVertical: 6, paddingHorizontal: 12 },
  medium: { paddingVertical: 10, paddingHorizontal: 20 },
  large: { paddingVertical: 14, paddingHorizontal: 28 },
  disabled: { opacity: 0.5 },
  text: { fontWeight: '600', color: '#fff' },
  primaryText: { color: '#fff' },
  secondaryText: { color: '#fff' },
  dangerText: { color: '#fff' },
  ghostText: { color: '#3b82f6' },
  smallText: { fontSize: 12 },
  mediumText: { fontSize: 16 },
  largeText: { fontSize: 18 },
});

Mini-Project: Build a Reusable Card Component

Create a flexible Card component that can display content in various configurations:

import React from 'react';
import { View, Text, Image, TouchableOpacity, StyleSheet } from 'react-native';

interface CardProps {
  title: string;
  subtitle?: string;
  description?: string;
  imageUrl?: string;
  onPress?: () => void;
  variant?: 'default' | 'outlined' | 'elevated';
}

export default function Card({
  title,
  subtitle,
  description,
  imageUrl,
  onPress,
  variant = 'default',
}: CardProps) {
  const cardContent = (
    <View style={[styles.card, styles[variant]]}>
      {imageUrl && (
        <Image source={{ uri: imageUrl }} style={styles.image} />
      )}
      <View style={styles.content}>
        <Text style={styles.title}>{title}</Text>
        {subtitle && <Text style={styles.subtitle}>{subtitle}</Text>}
        {description && <Text style={styles.description}>{description}</Text>}
      </View>
    </View>
  );

  if (onPress) {
    return (
      <TouchableOpacity onPress={onPress} activeOpacity={0.8}>
        {cardContent}
      </TouchableOpacity>
    );
  }

  return cardContent;
}

const styles = StyleSheet.create({
  card: {
    borderRadius: 12,
    overflow: 'hidden',
    marginBottom: 16,
    backgroundColor: '#fff',
  },
  default: {
    elevation: 2,
    shadowColor: '#000',
    shadowOffset: { width: 0, height: 1 },
    shadowOpacity: 0.1,
    shadowRadius: 3,
  },
  outlined: {
    borderWidth: 1,
    borderColor: '#e0e0e0',
  },
  elevated: {
    elevation: 5,
    shadowColor: '#000',
    shadowOffset: { width: 0, height: 3 },
    shadowOpacity: 0.2,
    shadowRadius: 5,
  },
  image: {
    width: '100%',
    height: 150,
  },
  content: {
    padding: 16,
  },
  title: {
    fontSize: 18,
    fontWeight: 'bold',
    marginBottom: 4,
  },
  subtitle: {
    fontSize: 14,
    color: '#666',
    marginBottom: 8,
  },
  description: {
    fontSize: 14,
    color: '#333',
    lineHeight: 20,
  },
});

Summary

  • Components are self-contained, reusable building blocks of your UI
  • Always use function components over class components
  • Compose small, focused components to build complex UIs
  • Component names must use PascalCase and start with a capital letter
  • One component per file is the recommended file organization pattern
  • Use TypeScript interfaces to define component props for type safety
  • Design components with sensible defaults and flexible prop options
