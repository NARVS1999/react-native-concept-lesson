Lesson 0031: Safe Area Context

Phase 4 — Integration Concepts

Lesson Goal Use SafeAreaProvider and SafeAreaView to handle device notches and status bars, and leverage the useSafeAreaInsets hook for custom safe area layouts in any component.

Why Safe Areas Matter

Modern devices have notches, rounded corners, and status bars that can overlap your app content. Safe areas ensure your UI renders within the visible, unobstructed portion of the screen. Without proper safe area handling, content may be hidden behind the notch or status bar.

SafeAreaProvider

SafeAreaProvider should wrap your entire app (similar to NavigationContainer). It provides safe area insets to all child components via context:

import { SafeAreaProvider } from 'react-native-safe-area-context';

export default function App() {
  return (
    <SafeAreaProvider>
      {/* Your app content, NavigationContainer, etc. */}
    </SafeAreaProvider>
  );
}

SafeAreaView

SafeAreaView is a drop-in replacement for View that adds padding automatically based on device insets:

import { SafeAreaView, Text, StyleSheet } from 'react-native';

function HomeScreen() {
  return (
    <SafeAreaView style={styles.container}>
      <Text style={styles.title}>My App</Text>
      <Text>This content is safe from notches and status bars.</Text>
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1 },
  title: { fontSize: 24, fontWeight: 'bold' },
});

SafeAreaView automatically applies padding to the top, bottom, left, and right based on the device's safe area insets.

useSafeAreaInsets Hook

For more precise control, use the useSafeAreaInsets hook to get individual inset values and apply them manually:

import { useSafeAreaInsets } from 'react-native-safe-area-context';

function CustomHeader() {
  const insets = useSafeAreaInsets();

  return (
    <View style={{
      paddingTop: insets.top,
      paddingLeft: insets.left,
      paddingRight: insets.right,
      backgroundColor: '#2196F3',
    }}>
      <Text style={{ color: 'white', fontSize: 18 }}>
        Custom Header
      </Text>
    </View>
  );
}

The hook returns an object with top, bottom, left, and right values in pixels.

Safe Areas in Scroll Views

When using ScrollView or FlatList, combine safe areas with content container styling:

import { SafeAreaView, FlatList, Text } from 'react-native';
import { useSafeAreaInsets } from 'react-native-safe-area-context';

function SafeScrollList({ data }) {
  const insets = useSafeAreaInsets();

  return (
    <SafeAreaView style={{ flex: 1 }}>
      <FlatList
        data={data}
        contentContainerStyle={{
          paddingTop: insets.top,
          paddingBottom: insets.bottom,
        }}
        renderItem={({ item }) => (
          <Text style={{ padding: 16 }}>{item.title}</Text>
        )}
        keyExtractor={(item) => item.id}
      />
    </SafeAreaView>
  );
}

Handling Orientation Changes

Safe area insets update dynamically when the device orientation changes. The useSafeAreaInsets hook automatically re-renders with new values, so your layout adjusts without extra work.

Mini-Project: Screen with Safe Area Headers and Scroll Content

Build a screen with a custom header that respects the top safe area, a scrollable content area with proper bottom padding, and a floating bottom bar that sits above the home indicator.

import React from 'react';
import { View, Text, ScrollView, StyleSheet } from 'react-native';
import { SafeAreaProvider, SafeAreaView, useSafeAreaInsets } from 'react-native-safe-area-context';

function AppContent() {
  const insets = useSafeAreaInsets();

  return (
    <View style={styles.root}>
      {/* Custom header respecting top safe area */}
      <View style={[styles.header, { paddingTop: insets.top }]}>
        <Text style={styles.headerTitle}>My Safe App</Text>
      </View>

      {/* Scrollable content */}
      <ScrollView
        style={styles.content}
        contentContainerStyle={{
          paddingTop: 20,
          paddingBottom: insets.bottom + 80,
        }}
      >
        {Array.from({ length: 20 }, (_, i) => (
          <View key={i} style={styles.card}>
            <Text style={styles.cardTitle}>Item {i + 1}</Text>
            <Text style={styles.cardBody}>
              This is scrollable content that respects safe areas.
            </Text>
          </View>
        ))}
      </ScrollView>

      {/* Bottom bar above home indicator */}
      <View style={[styles.bottomBar, { paddingBottom: insets.bottom }]}>
        <Text style={styles.bottomText}>Bottom Navigation Bar</Text>
      </View>
    </View>
  );
}

export default function App() {
  return (
    <SafeAreaProvider>
      <AppContent />
    </SafeAreaProvider>
  );
}

const styles = StyleSheet.create({
  root: { flex: 1, backgroundColor: '#f5f5f5' },
  header: {
    backgroundColor: '#2196F3',
    paddingBottom: 16,
    paddingHorizontal: 20,
  },
  headerTitle: { fontSize: 22, fontWeight: 'bold', color: 'white' },
  content: { flex: 1 },
  card: {
    backgroundColor: 'white',
    marginHorizontal: 16,
    marginVertical: 6,
    padding: 16,
    borderRadius: 8,
    elevation: 2,
  },
  cardTitle: { fontSize: 16, fontWeight: '600' },
  cardBody: { marginTop: 4, color: '#666' },
  bottomBar: {
    backgroundColor: 'white',
    paddingTop: 12,
    paddingHorizontal: 20,
    borderTopWidth: 1,
    borderTopColor: '#e0e0e0',
  },
  bottomText: { textAlign: 'center', fontSize: 14, color: '#333' },
});

Summary

  • SafeAreaProvider wraps your app to provide safe area context to all child components
  • SafeAreaView is a drop-in View replacement that adds automatic safe area padding
  • useSafeAreaInsets hook gives you individual inset values for custom layouts
  • Safe areas handle notches, status bars, rounded corners, and home indicators
  • Insets update dynamically on orientation changes without extra code
