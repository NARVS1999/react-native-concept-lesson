Lesson 0018: Motion and Graphics

Phase 6 — Design Concepts

Lesson Goal Create smooth animations with Reanimated, render vector graphics with SVG, and embed web content with WebView.

React Native Reanimated

Reanimated runs animations on the native UI thread for smooth 60fps performance — no JavaScript thread blocking:

import Animated, { useSharedValue, useAnimatedStyle, withSpring } from 'react-native-reanimated';

function AnimatedBox() {
  const offset = useSharedValue(0);

  const animatedStyle = useAnimatedStyle(() => ({
    transform: [{ translateX: offset.value }],
  }));

  return (
    <View>
      <Animated.View style={[styles.box, animatedStyle]} />
      <Pressable onPress={() => { offset.value = withSpring(offset.value === 0 ? 200 : 0); }}>
        <Text>Animate</Text>
      </Pressable>
    </View>
  );
}
Key Insight useSharedValue creates values that can be read on both JS and native threads. The withSpring function adds spring physics to the animation.

SVG Graphics

React Native SVG renders scalable vector graphics for custom shapes, icons, and illustrations:

import Svg, { Circle, Rect, Path } from 'react-native-svg';

function CustomIcon() {
  return (
    <Svg width="100" height="100" viewBox="0 0 100 100">
      <Circle cx="50" cy="50" r="40" fill="#4263eb" />
      <Rect x="25" y="40" width="50" height="20" rx="4" fill="#fff" />
    </Svg>
  );
}

SVGs are ideal for: custom icons, logos, charts, loading animations, and any graphic that needs to scale without pixelation.

WebView

Embed web content directly in your app using WebView:

import { WebView } from 'react-native-webview';

function EmbeddedWeb() {
  return (
    <WebView
      source={{ uri: 'https://reactnative.dev' }}
      style={{ flex: 1 }}
      javaScriptEnabled={true}
    />
  );
}
Security Note WebView runs JavaScript from the loaded page. Only load trusted URLs. Disable javaScriptEnabled if you don't need JS execution.
