Lesson 69: Re-render Optimization

Phase 9 — Optimization Concepts

Lesson Goal Learn to identify unnecessary re-renders, use React DevTools Profiler to measure them, and apply React.memo, useMemo, and useCallback to optimize component performance.

Why Re-renders Matter

Every time a component's state or props change, React re-renders that component and all its children. In React Native, unnecessary re-renders cause visible lag, dropped frames, and wasted CPU cycles — especially in lists and complex screens.

Identifying Unnecessary Re-renders

The fastest way to spot unnecessary re-renders is using the React DevTools Profiler. Enable "Highlight updates when components render" in React DevTools settings. Components that flash on screen during an unrelated state change are re-rendering unnecessarily.

React.memo — Shallow Comparison

React.memo wraps a component so it only re-renders when its props change (shallow comparison). This is the simplest optimization.

// Without React.memo — re-renders on every parent render
function UserCard({ name, email }) {
  console.log('UserCard rendered');
  return (
    <View>
      <Text>{name}</Text>
      <Text>{email}</Text>
    </View>
  );
}

// With React.memo — only re-renders when props change
const UserCard = React.memo(function UserCard({ name, email }) {
  console.log('UserCard rendered');
  return (
    <View>
      <Text>{name}</Text>
      <Text>{email}</Text>
    </View>
  );
});

// Usage
function ParentScreen() {
  const [count, setCount] = useState(0);

  return (
    <View>
      <UserCard name="John" email="john@example.com" />
      <Button title={`Count: ${count}`} onPress={() => setCount(c => c + 1)} />
    </View>
  );
}
// UserCard will NOT re-render when count changes

useMemo — Memoizing Expensive Values

useMemo caches the result of a computation so it only recalculates when dependencies change. Useful for expensive filtering, sorting, or derived data.

import { useMemo } from 'react';

function FilteredList({ items, searchTerm }) {
  // Without useMemo — recalculates on every render
  // const filtered = items.filter(i => i.name.includes(searchTerm));

  // With useMemo — only recalculates when items or searchTerm change
  const filtered = useMemo(() => {
    console.log('Filtering...');
    return items.filter(i => i.name.toLowerCase().includes(searchTerm.toLowerCase()));
  }, [items, searchTerm]);

  return (
    <FlatList
      data={filtered}
      keyExtractor={item => item.id}
      renderItem={({ item }) => <Text>{item.name}</Text>}
    />
  );
}

useCallback — Memoizing Functions

Every render creates a new function reference. useCallback preserves the same function between renders unless dependencies change. This prevents child components from re-rendering due to new function props.

import { useCallback, useState } from 'react';

function TodoList() {
  const [todos, setTodos] = useState([]);
  const [input, setInput] = useState('');

  // Without useCallback — new function every render, child re-renders
  // const addTodo = () => { setTodos([...todos, input]); setInput(''); };

  // With useCallback — stable reference
  const addTodo = useCallback(() => {
    setTodos(prev => [...prev, input]);
    setInput('');
  }, [input]);

  const removeTodo = useCallback((id) => {
    setTodos(prev => prev.filter(t => t.id !== id));
  }, []);

  return (
    <View>
      <TextInput value={input} onChangeText={setInput} />
      <Button title="Add" onPress={addTodo} />
      {todos.map(todo => (
        <TodoItem key={todo.id} todo={todo} onRemove={removeTodo} />
      ))}
    </View>
  );
}

const TodoItem = React.memo(function TodoItem({ todo, onRemove }) {
  console.log('TodoItem rendered', todo.id);
  return (
    <TouchableOpacity onPress={() => onRemove(todo.id)}>
      <Text>{todo.text}</Text>
    </TouchableOpacity>
  );
});

Avoiding Inline Objects and Arrays

Inline objects and arrays create new references every render, breaking React.memo and useMemo. Always define styles and objects outside the render function or use useMemo.

// BAD — new object every render
function Card() {
  return <View style={{ padding: 10, margin: 5 }}>...</View>;
}

// GOOD — constant reference
const styles = StyleSheet.create({
  card: { padding: 10, margin: 5 },
});

function Card() {
  return <View style={styles.card}>...</View>;
}

// BAD — new function passed to memoized child
function Parent() {
  const config = { theme: 'dark' }; // new object every render
  return <Child config={config} />;
}

// GOOD — memoize the object
function Parent() {
  const config = useMemo(() => ({ theme: 'dark' }), []);
  return <Child config={config} />;
}

Mini-Project: Profile and Optimize a Component

Create a screen with a list of users and a counter button. The user list should NOT re-render when the counter changes.

import React, { useState, useCallback, useMemo } from 'react';
import { View, Text, Button, FlatList, StyleSheet } from 'react-native';

const USERS = Array.from({ length: 50 }, (_, i) => ({
  id: String(i),
  name: `User ${i + 1}`,
  email: `user${i + 1}@example.com`,
}));

const UserItem = React.memo(function UserItem({ user }) {
  console.log(`Rendering UserItem: ${user.id}`);
  return (
    <View style={styles.userItem}>
      <Text style={styles.name}>{user.name}</Text>
      <Text style={styles.email}>{user.email}</Text>
    </View>
  );
});

export default function OptimizationScreen() {
  const [count, setCount] = useState(0);
  const [filter, setFilter] = useState('');

  const increment = useCallback(() => {
    setCount(prev => prev + 1);
  }, []);

  const filteredUsers = useMemo(() => {
    if (!filter) return USERS;
    return USERS.filter(u => u.name.toLowerCase().includes(filter.toLowerCase()));
  }, [filter]);

  return (
    <View style={styles.container}>
      <Text style={styles.count}>Count: {count}</Text>
      <Button title="Increment" onPress={increment} />
      <FlatList
        data={filteredUsers}
        keyExtractor={item => item.id}
        renderItem={({ item }) => <UserItem user={item} />}
        style={styles.list}
      />
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 16 },
  count: { fontSize: 24, marginBottom: 12 },
  list: { marginTop: 16 },
  userItem: { padding: 12, borderBottomWidth: 1, borderBottomColor: '#eee' },
  name: { fontSize: 16, fontWeight: 'bold' },
  email: { fontSize: 14, color: '#666' },
});

Open React DevTools Profiler, record while tapping Increment, and verify UserItem components do not appear in the commit flamegraph.

Summary

  • Unnecessary re-renders waste CPU and cause frame drops in React Native
  • React.memo wraps components to skip re-renders when props haven't changed (shallow comparison)
  • useMemo caches expensive computations and recalculates only when dependencies change
  • useCallback memoizes functions to maintain stable references for child components
  • Inline objects and arrays create new references every render — define them as constants or memoize them
  • Use React DevTools Profiler with "Highlight updates" to visually identify unnecessary re-renders
  • Profile first, optimize second — not every component needs memoization
