What is React Query?

TanStack React Query (formerly React Query) is a powerful data-fetching and caching library for React. It manages server state, handles loading/error states, provides automatic re-fetching, and optimizes your app's network usage.

Why React Query?

  • Automatic caching — Data is cached and re-used across components
  • Background re-fetching — Stale data is updated silently
  • Request deduplication — Multiple components share one network request
  • Built-in loading/error states — No more manual state management
  • Optimistic updates — Update UI before server responds

Installation

npm install @tanstack/react-query

Setting Up QueryClient

The QueryClient manages the cache and configuration for all queries in your app.

// App.js
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
import HomeScreen from './screens/HomeScreen';

const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 1000 * 60 * 5,  // 5 minutes
      cacheTime: 1000 * 60 * 30, // 30 minutes
      retry: 2,
      refetchOnWindowFocus: false,
    },
  },
});

export default function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <HomeScreen />
    </QueryClientProvider>
  );
}

useQuery for Fetching Data

useQuery fetches and caches data. It returns data, isLoading, error, and more.

// hooks/usePosts.js
import { useQuery } from '@tanstack/react-query';

const fetchPosts = async () => {
  const response = await fetch('https://jsonplaceholder.typicode.com/posts');
  if (!response.ok) throw new Error('Failed to fetch posts');
  return response.json();
};

export function usePosts() {
  return useQuery({
    queryKey: ['posts'],
    queryFn: fetchPosts,
    staleTime: 1000 * 60 * 2, // 2 minutes
  });
}

Using useQuery in Components

// screens/PostsScreen.js
import { usePosts } from '../hooks/usePosts';
import { View, Text, FlatList, ActivityIndicator, StyleSheet } from 'react-native';

export default function PostsScreen() {
  const { data: posts, isLoading, error, refetch } = usePosts();

  if (isLoading) return <ActivityIndicator size="large" style={styles.center} />;
  if (error) return (
    <View style={styles.center}>
      <Text>Error: {error.message}</Text>
      <Button title="Retry" onPress={refetch} />
    </View>
  );

  return (
    <FlatList
      data={posts}
      keyExtractor={(item) => item.id.toString()}
      onRefresh={refetch}
      refreshing={isLoading}
      renderItem={({ item }) => (
        <View style={styles.item}>
          <Text style={styles.title}>{item.title}</Text>
          <Text>{item.body}</Text>
        </View>
      )}
    />
  );
}

const styles = StyleSheet.create({
  center: { flex: 1, justifyContent: 'center', alignItems: 'center' },
  item: { padding: 16, borderBottomWidth: 1 },
  title: { fontWeight: 'bold', marginBottom: 4 },
});

Query Options: staleTime and cacheTime

  • staleTime — How long data is considered "fresh". During this time, no re-fetch occurs.
  • cacheTime — How long unused data stays in memory. After this, it's garbage collected.
  • refetchOnMount — Whether to re-fetch when component mounts (default: true)
  • refetchOnWindowFocus — Whether to re-fetch when app regains focus
  • retry — Number of retry attempts on failure

useMutation for Creating/Updating Data

useMutation handles POST, PUT, DELETE operations. It provides mutate, isLoading, and error.

// hooks/useCreatePost.js
import { useMutation, useQueryClient } from '@tanstack/react-query';

const createPost = async (newPost) => {
  const response = await fetch('https://jsonplaceholder.typicode.com/posts', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(newPost),
  });
  if (!response.ok) throw new Error('Failed to create post');
  return response.json();
};

export function useCreatePost() {
  const queryClient = useQueryClient();

  return useMutation({
    mutationFn: createPost,
    onSuccess: () => {
      // Invalidate the posts query to refetch fresh data
      queryClient.invalidateQueries({ queryKey: ['posts'] });
    },
    onError: (error) => {
      console.error('Error creating post:', error);
    },
  });
}

Using Mutation in Components

// screens/CreatePostScreen.js
import { useState } from 'react';
import { View, TextInput, Button, Alert } from 'react-native';
import { useCreatePost } from '../hooks/useCreatePost';

export default function CreatePostScreen() {
  const [title, setTitle] = useState('');
  const [body, setBody] = useState('');
  const createPost = useCreatePost();

  const handleSubmit = () => {
    if (!title || !body) {
      Alert.alert('Error', 'Please fill in all fields');
      return;
    }
    createPost.mutate(
      { title, body, userId: 1 },
      {
        onSuccess: () => {
          Alert.alert('Success', 'Post created!');
          setTitle('');
          setBody('');
        },
      }
    );
  };

  return (
    <View style={{ padding: 16 }}>
      <TextInput placeholder="Title" value={title} onChangeText={setTitle} />
      <TextInput placeholder="Body" value={body} onChangeText={setBody} multiline />
      <Button
        title={createPost.isLoading ? 'Creating...' : 'Create Post'}
        onPress={handleSubmit}
        disabled={createPost.isLoading}
      />
    </View>
  );
}

Query Invalidation

Invalidating a query forces a re-fetch. This is essential after mutations to keep the cache in sync.

// Invalidate a specific query
queryClient.invalidateQueries({ queryKey: ['posts'] });

// Invalidate multiple queries
queryClient.invalidateQueries({ queryKey: ['posts', 'comments'] });

// Invalidate all queries
queryClient.invalidateQueries();

Optimistic Updates

Update the cache before the server responds. If the mutation fails, roll back to the previous state.

// Optimistic mutation example
export function useToggleTodo() {
  const queryClient = useQueryClient();

  return useMutation({
    mutationFn: async (todo) => {
      const response = await fetch(`/api/todos/${todo.id}`, {
        method: 'PATCH',
        body: JSON.stringify({ done: !todo.done }),
      });
      return response.json();
    },
    onMutate: async (todo) => {
      // Cancel outgoing refetches
      await queryClient.cancelQueries({ queryKey: ['todos'] });

      // Snapshot previous value
      const previousTodos = queryClient.getQueryData(['todos']);

      // Optimistically update
      queryClient.setQueryData(['todos'], (old) =>
        old.map((t) => (t.id === todo.id ? { ...t, done: !t.done } : t))
      );

      return { previousTodos };
    },
    onError: (err, todo, context) => {
      // Rollback on error
      queryClient.setQueryData(['todos'], context.previousTodos);
    },
    onSettled: () => {
      // Always refetch after error or success
      queryClient.invalidateQueries({ queryKey: ['todos'] });
    },
  });
}

Summary

  • QueryClient manages the cache and global query configuration
  • useQuery fetches and caches data with automatic loading/error states
  • useMutation handles create/update/delete operations
  • staleTime controls data freshness; cacheTime controls memory retention
  • Query invalidation forces re-fetching after mutations
  • Optimistic updates provide instant UI feedback with rollback on error
