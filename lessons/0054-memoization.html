Lesson 54: Memoization

Phase 7 — Advanced Concepts

Lesson Goal Understand React.memo and useMemo hooks, learn when and how to apply memoization to optimize re-renders, and profile performance before and after applying memoization techniques.

What is Memoization?

Memoization is an optimization technique where the result of a function call is cached and returned directly when the same inputs occur again. In React, memoization prevents unnecessary re-renders of components and re-computation of expensive values.

React.memo

React.memo is a higher-order component that wraps a functional component. It skips re-rendering a component when its props haven't changed (shallow comparison by default).

import React from 'react';

// Without React.memo — re-renders every time parent re-renders
const UserCard = ({ name, email }) => {
  console.log('UserCard rendered for', name);
  return (
    <View style={styles.card}>
      <Text style={styles.name}>{name}</Text>
      <Text style={styles.email}>{email}</Text>
    </View>
  );
};

// With React.memo — only re-renders when name or email changes
const MemoizedUserCard = React.memo(({ name, email }) => {
  console.log('MemoizedUserCard rendered for', name);
  return (
    <View style={styles.card}>
      {name}
      {email}
    </View>
  );
});

export default MemoizedUserCard;

Custom Comparison Function

By default, React.memo uses shallow comparison. You can provide a custom function for deeper comparisons:

const MemoizedList = React.memo(
  ({ items, onSelect }) => {
    return (
      <FlatList
        data={items}
        keyExtractor={(item) => item.id}
        renderItem={({ item }) => (
          <TouchableOpacity onPress={() => onSelect(item.id)}>
            <Text>{item.name}</Text>
          </TouchableOpacity>
        )}
      />
    );
  },
  (prevProps, nextProps) => {
    // Only re-render if items length or selectedId changed
    return (
      prevProps.items.length === nextProps.items.length &&
      prevProps.selectedId === nextProps.selectedId
    );
  }
);

useMemo Hook

useMemo caches the result of an expensive computation between renders. It takes a function and a dependency array — the computation only re-runs when dependencies change.

import React, { useMemo, useState } from 'react';

const FilteredList = ({ items }) => {
  const [search, setSearch] = useState('');
  const [sortBy, setSortBy] = useState('name');

  // Without useMemo — recalculates on every render
  // const filteredItems = items
  //   .filter(item => item.name.toLowerCase().includes(search.toLowerCase()))
  //   .sort((a, b) => a[sortBy].localeCompare(b[sortBy]));

  // With useMemo — only recalculates when items, search, or sortBy changes
  const filteredItems = useMemo(() => {
    console.log('Computing filtered items...');
    return items
      .filter(item => item.name.toLowerCase().includes(search.toLowerCase()))
      .sort((a, b) => a[sortBy].localeCompare(b[sortBy]));
  }, [items, search, sortBy]);

  return (
    <View>
      <TextInput
        placeholder="Search..."
        value={search}
        onChangeText={setSearch}
      />
      <FlatList
        data={filteredItems}
        keyExtractor={(item) => item.id}
        renderItem={({ item }) => <Text>{item.name}</Text>}
      />
    </View>
  );
};

Avoiding Premature Optimization

Warning: Don't memoize everything. Memoization adds overhead. Only apply it when you've identified a performance problem through profiling.
  • Profile first — measure before and after
  • Memoize components that receive new object/array references on every parent render
  • Memoize expensive computations (filtering, sorting, complex math)
  • Don't wrap simple components in React.memo — the comparison cost may exceed re-render cost

Mini-Project: Optimize a List with React.memo

import React, { useState, useMemo } from 'react';
import { View, Text, FlatList, TouchableOpacity, StyleSheet } from 'react-native';

const TodoItem = React.memo(({ item, onToggle }) => (
  <TouchableOpacity style={styles.item} onPress={() => onToggle(item.id)}>
    <Text style={[styles.text, item.done && styles.done]}>
      {item.done ? '✓' : '○'} {item.title}
    </Text>
  </TouchableOpacity>
));

const App = () => {
  const [todos, setTodos] = useState([
    { id: '1', title: 'Learn React.memo', done: false },
    { id: '2', title: 'Learn useMemo', done: false },
    { id: '3', title: 'Build a todo app', done: true },
    { id: '4', title: 'Practice memoization', done: false },
  ]);
  const [filter, setFilter] = useState('all');

  const toggleTodo = (id) => {
    setTodos(prev =>
      prev.map(t => (t.id === id ? { ...t, done: !t.done } : t))
    );
  };

  const filteredTodos = useMemo(() => {
    switch (filter) {
      case 'done': return todos.filter(t => t.done);
      case 'pending': return todos.filter(t => !t.done);
      default: return todos;
    }
  }, [todos, filter]);

  const stats = useMemo(() => ({
    total: todos.length,
    done: todos.filter(t => t.done).length,
    pending: todos.filter(t => !t.done).length,
  }), [todos]);

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Optimized Todo List</Text>
      <Text style={styles.stats}>
        Total: {stats.total} | Done: {stats.done} | Pending: {stats.pending}
      </Text>
      <View style={styles.filters}>
        {['all', 'done', 'pending'].map(f => (
          <TouchableOpacity
            key={f}
            style={[styles.filterBtn, filter === f && styles.activeFilter]}
            onPress={() => setFilter(f)}
          >
            <Text style={styles.filterText}>{f.toUpperCase()}</Text>
          </TouchableOpacity>
        ))}
      </View>
      <FlatList
        data={filteredTodos}
        keyExtractor={(item) => item.id}
        renderItem={({ item }) => (
          <TodoItem item={item} onToggle={toggleTodo} />
        )}
      />
    </View>
  );
};

const styles = StyleSheet.create({
  container: { flex: 1, padding: 20, backgroundColor: '#f5f5f5' },
  title: { fontSize: 24, fontWeight: 'bold', marginBottom: 10 },
  stats: { fontSize: 14, color: '#666', marginBottom: 15 },
  filters: { flexDirection: 'row', marginBottom: 15, gap: 10 },
  filterBtn: { padding: 8, borderRadius: 6, backgroundColor: '#ddd' },
  activeFilter: { backgroundColor: '#007AFF' },
  filterText: { color: '#fff', fontWeight: '600' },
  item: { padding: 15, backgroundColor: '#fff', borderRadius: 8, marginBottom: 8 },
  text: { fontSize: 16 },
  done: { textDecorationLine: 'line-through', color: '#999' },
});

export default App;

Summary

  • React.memo prevents unnecessary re-renders by shallow-comparing props
  • useMemo caches expensive computations between renders
  • Both rely on dependency/reference stability to work effectively
  • Always profile performance before applying memoization
  • Avoid premature optimization — memoization adds its own overhead
  • Custom comparison functions can be passed to React.memo for deeper checks
