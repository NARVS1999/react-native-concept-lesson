Lesson 0005: Styling and Flexbox

Phase 2 — Core Concepts

Lesson Goal Use StyleSheet and Flexbox to create responsive, well-structured layouts in React Native.

Stylesheet: Declarative Styling

React Native uses JavaScript objects for styles. The StyleSheet.create API optimizes these objects for performance:

import { StyleSheet, View, Text } from 'react-native';

function StyledBox() {
  return (
    <View style={styles.container}>
      <Text style={styles.title}>Hello</Text>
      <Text style={styles.subtitle}>World</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: { padding: 20, backgroundColor: '#f5f5f5', borderRadius: 8 },
  title: { fontSize: 24, fontWeight: 'bold', color: '#333' },
  subtitle: { fontSize: 16, color: '#666', marginTop: 8 },
});
Why StyleSheet.create? It validates styles at build time and sends them to the native layer as IDs instead of plain objects — more efficient than inline styles.

Flexbox: The Layout System

React Native uses Flexbox for layout. By default, Flexbox in RN is column-based (not row-based like web CSS).

PropertyValuesWhat it does
flexDirectionrow, column (default)Direction of the main axis
justifyContentflex-start, center, space-between, space-around, space-evenlyAlignment along the main axis
alignItemsflex-start, center, stretch (default), flex-endAlignment along the cross axis
flexNumber (e.g., 1, 2)How much space an item should take relative to siblings
gapNumberSpacing between items
// Center content both horizontally and vertically
<View style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}>
  <Text>Centered!</Text>
</View>

// Side-by-side layout
<View style={{ flexDirection: 'row', gap: 8 }}>
  <View style={{ flex: 1, backgroundColor: '#e3f2fd' }}>
    <Text>Left</Text>
  </View>
  <View style={{ flex: 1, backgroundColor: '#fce4ec' }}>
    <Text>Right</Text>
  </View>
</View>

Dimensions: Screen Size

Use the Dimensions API to get the screen width and height for responsive layouts:

import { Dimensions } from 'react-native';

const { width, height } = Dimensions.get('window');

// Use width to calculate responsive sizes
const cardWidth = width * 0.9;

You can also use useWindowDimensions() hook which updates when the screen rotates:

import { useWindowDimensions } from 'react-native';

function ResponsiveLayout() {
  const { width, height } = useWindowDimensions();
  return (
    <View style={{ width: width * 0.9, padding: 16 }}>
      <Text>Screen: {width} x {height}</Text>
    </View>
  );
}

Mini-Project: Price Tag Row

Create a horizontal row with a product name on the left and a price on the right, using flexDirection: 'row' and justifyContent: 'space-between'.

function PriceTag({ name, price }) {
  return (
    <View style={styles.row}>
      <Text style={styles.name}>{name}</Text>
      <Text style={styles.price}>{price}</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  row: { flexDirection: 'row', justifyContent: 'space-between', padding: 16, borderBottomWidth: 1, borderBottomColor: '#eee' },
  name: { fontSize: 16 },
  price: { fontSize: 16, fontWeight: 'bold', color: '#2b8a3e' },
});

Summary

  • Use StyleSheet.create for optimized, validated styles
  • Flexbox defaults to column direction (not row like web CSS)
  • justifyContent = main axis, alignItems = cross axis
  • Use useWindowDimensions() for responsive layouts that update on rotation
