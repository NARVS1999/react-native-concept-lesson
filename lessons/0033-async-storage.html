Lesson 0033: Async Storage

Phase 4 — Integration Concepts

Lesson Goal Use @react-native-async-storage/async-storage to persist key-value data locally, handle JSON serialization, understand storage limits, and build a custom useAsyncStorage hook.

What is AsyncStorage?

AsyncStorage is a simple, unencrypted, asynchronous key-value storage system for React Native. It's the React Native equivalent of localStorage in web browsers. Common uses include persisting user preferences, caching API responses, and storing tokens.

@react-native-async-storage/async-storage is the community-maintained version that works on iOS, Android, and Web.

Installation

npm install @react-native-async-storage/async-storage

Basic Operations

AsyncStorage provides three core methods: setItem, getItem, and removeItem. All operations are asynchronous:

import AsyncStorage from '@react-native-async-storage/async-storage';

// Save a value
await AsyncStorage.setItem('user_token', 'abc123');

// Read a value
const token = await AsyncStorage.getItem('user_token');
console.log(token); // 'abc123'

// Delete a value
await AsyncStorage.removeItem('user_token');

// Check if key exists
const exists = await AsyncStorage.getItem('user_token');
if (exists !== null) {
  // Key exists
}

JSON Stringify and Parse

AsyncStorage only stores strings. To persist objects and arrays, serialize with JSON:

// Save an object
const settings = { notifications: true, darkMode: false, fontSize: 16 };
await AsyncStorage.setItem('app_settings', JSON.stringify(settings));

// Read an object
const raw = await AsyncStorage.getItem('app_settings');
const settings = raw ? JSON.parse(raw) : null;

// Save an array
const favorites = [1, 2, 3, 4, 5];
await AsyncStorage.setItem('favorites', JSON.stringify(favorites));

// Read an array
const rawFavorites = await AsyncStorage.getItem('favorites');
const favorites = rawFavorites ? JSON.parse(rawFavorites) : [];

Batch Operations

For multiple operations, use multiGet and multiSet for better performance:

// Get multiple keys at once
const keys = ['user_token', 'app_settings', 'favorites'];
const result = await AsyncStorage.multiGet(keys);
// result is an array of [key, value] pairs

// Set multiple key-value pairs
const pairs = [
  ['user_token', 'abc123'],
  ['app_settings', JSON.stringify({ darkMode: true })],
];
await AsyncStorage.multiSet(pairs);

// Remove multiple keys
await AsyncStorage.multiRemove(['user_token', 'app_settings']);

Storage Limits

AsyncStorage has platform-specific limits:

  • iOS: Approximately 6MB total storage
  • Android: No hard limit, but performance degrades with large amounts
  • Best practice: Keep data under 6MB total. Use files for large data

useAsyncStorage Hook

Create a reusable hook that wraps AsyncStorage with React state management:

import { useState, useEffect, useCallback } from 'react';
import AsyncStorage from '@react-native-async-storage/async-storage';

function useAsyncStorage(key, initialValue) {
  const [value, setValue] = useState(initialValue);
  const [loading, setLoading] = useState(true);

  // Load stored value on mount
  useEffect(() => {
    async function load() {
      try {
        const stored = await AsyncStorage.getItem(key);
        if (stored !== null) {
          setValue(JSON.parse(stored));
        }
      } catch (error) {
        console.error('Error loading from storage:', error);
      } finally {
        setLoading(false);
      }
    }
    load();
  }, [key]);

  // Update value and persist
  const setStoredValue = useCallback(async (newValue) => {
    try {
      const valueToStore = newValue instanceof Function ? newValue(value) : newValue;
      setValue(valueToStore);
      await AsyncStorage.setItem(key, JSON.stringify(valueToStore));
    } catch (error) {
      console.error('Error saving to storage:', error);
    }
  }, [key, value]);

  return [value, setStoredValue, loading];
}

// Usage
function SettingsScreen() {
  const [darkMode, setDarkMode] = useAsyncStorage('darkMode', false);

  return (
    <View>
      <Switch
        value={darkMode}
        onValueChange={setDarkMode}
      />
      <Text>Dark Mode: {darkMode ? 'On' : 'Off'}</Text>
    </View>
  );
}

Mini-Project: Settings Screen with Persistent Preferences

Build a settings screen that persists user preferences (notifications, dark mode, font size) using AsyncStorage and a custom useAsyncStorage hook.

import React from 'react';
import { View, Text, Switch, Slider, StyleSheet, SafeAreaView } from 'react-native';
import { useAsyncStorage } from './useAsyncStorage'; // Custom hook from above

function SettingsScreen() {
  const [notifications, setNotifications] = useAsyncStorage('notifications', true);
  const [darkMode, setDarkMode] = useAsyncStorage('darkMode', false);
  const [fontSize, setFontSize] = useAsyncStorage('fontSize', 16);

  return (
    <SafeAreaView style={styles.container}>
      <Text style={styles.title}>Settings</Text>

      <View style={styles.row}>
        <Text style={styles.label}>Notifications</Text>
        <Switch value={notifications} onValueChange={setNotifications} />
      </View>

      <View style={styles.row}>
        <Text style={styles.label}>Dark Mode</Text>
        <Switch value={darkMode} onValueChange={setDarkMode} />
      </View>

      <View style={styles.row}>
        <Text style={styles.label}>Font Size: {fontSize}</Text>
        <Slider
          style={styles.slider}
          minimumValue={12}
          maximumValue={24}
          step={1}
          value={fontSize}
          onValueChange={setFontSize}
        />
      </View>

      <View style={styles.preview}>
        <Text style={[styles.previewText, { fontSize }]}>
          Preview text at {fontSize}px
        </Text>
      </View>
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 20, backgroundColor: '#f5f5f5' },
  title: { fontSize: 28, fontWeight: 'bold', marginBottom: 30 },
  row: {
    flexDirection: 'row', justifyContent: 'space-between',
    alignItems: 'center', paddingVertical: 16,
    borderBottomWidth: 1, borderBottomColor: '#ddd',
  },
  label: { fontSize: 18 },
  slider: { flex: 1, marginLeft: 20 },
  preview: { marginTop: 30, padding: 20, backgroundColor: 'white', borderRadius: 8 },
  previewText: { textAlign: 'center' },
});

export default SettingsScreen;

Your settings will persist between app launches. The useAsyncStorage hook automatically loads saved values on mount and saves when you change them.

Summary

  • AsyncStorage provides asynchronous key-value storage for React Native apps
  • Always use JSON.stringify() and JSON.parse() for objects and arrays
  • multiGet and multiSet batch operations for better performance
  • iOS has an approximate 6MB storage limit; keep data minimal
  • A custom useAsyncStorage hook combines AsyncStorage with React state management
