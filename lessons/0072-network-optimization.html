Lesson 72: Network Optimization

Phase 9 — Optimization Concepts

Lesson Goal Learn request batching, caching strategies with React Query, image compression for network transfers, prefetching data, and debouncing API calls to reduce network overhead.

Why Network Optimization Matters

Network requests are expensive — they consume battery, data, and time. Poorly optimized networking leads to slow screens, high API costs, and poor user experience on slow connections. Optimizing how and when you fetch data is critical.

Request Batching

Instead of making many small API calls, combine them into a single request. This reduces the overhead of HTTP headers, TLS handshakes, and server round trips.

// BAD — 5 separate API calls on screen load
const UserProfile = () => {
  useEffect(() => {
    fetchUser(id);           // Request 1
    fetchUserPosts(id);      // Request 2
    fetchUserFriends(id);    // Request 3
    fetchNotifications(id);  // Request 4
    fetchSettings(id);       // Request 5
  }, [id]);
};

// GOOD — single batched request
// Backend endpoint: GET /api/user-dashboard?id=123
const UserProfile = () => {
  const [data, setData] = useState(null);

  useEffect(() => {
    fetch(`/api/user-dashboard?id=${id}`)
      .then(res => res.json())
      .then(setData);
    // Single request returns: user, posts, friends, notifications, settings
  }, [id]);

  if (!data) return <LoadingSpinner />;

  return (
    <View>
      <UserHeader user={data.user} />
      <PostsList posts={data.posts} />
      <FriendsList friends={data.friends} />
    </View>
  );
};

// If you can't change the backend, batch on the client with Promise.all
const fetchAllUserData = async (userId) => {
  const [user, posts, friends, notifications] = await Promise.all([
    fetchUser(userId),
    fetchUserPosts(userId),
    fetchUserFriends(userId),
    fetchNotifications(userId),
  ]);
  return { user, posts, friends, notifications };
};

Caching Strategies with React Query

React Query (TanStack Query) provides powerful caching out of the box. The staleTime option controls how long data is considered fresh before refetching.

import { QueryClient, QueryClientProvider, useQuery } from '@tanstack/react-query';

const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 5 * 60 * 1000,    // 5 minutes — data is fresh for 5 min
      cacheTime: 30 * 60 * 1000,   // 30 minutes — unused data stays in cache
      refetchOnWindowFocus: false,  // don't refetch when app regains focus
      retry: 2,                     // retry failed requests twice
    },
  },
});

function UserList() {
  const { data, isLoading, error } = useQuery({
    queryKey: ['users'],
    queryFn: fetchUsers,
    staleTime: 10 * 60 * 1000, // override: 10 minutes for this query
  });

  if (isLoading) return <ActivityIndicator />;
  if (error) return <Text>Error loading users</Text>;

  return (
    <FlatList
      data={data}
      keyExtractor={item => item.id}
      renderItem={({ item }) => <UserCard user={item} />}
    />
  );
}

// Prefetch data before the user navigates to a screen
const prefetchUser = async (userId) => {
  await queryClient.prefetchQuery({
    queryKey: ['user', userId],
    queryFn: () => fetchUser(userId),
    staleTime: 5 * 60 * 1000,
  });
};

// Usage: prefetch when user hovers or focuses on a list item
<TouchableOpacity
  onPress={() => prefetchUser(item.id)}
  onPress={() => navigation.navigate('UserProfile', { id: item.id })}
>
  <UserCard user={item} />
</TouchableOpacity>

Image Compression for Network

Images often account for 60-80% of network data. Compress and resize them before sending or loading.

import ImageResizer from 'react-native-image-resizer';

const compressImage = async (uri) => {
  const result = await ImageResizer.createResizedImage(
    uri,
    800,    // width
    600,    // height
    'JPEG', // format
    80,     // quality (0-100)
    0,      // rotation
  );
  return result.uri;
};

// Use compressed images in uploads
const uploadProfilePhoto = async (imageUri) => {
  const compressedUri = await compressImage(imageUri);

  const formData = new FormData();
  formData.append('photo', {
    uri: compressedUri,
    type: 'image/jpeg',
    name: 'profile.jpg',
  });

  await fetch('/api/upload-photo', {
    method: 'POST',
    body: formData,
    headers: { 'Content-Type': 'multipart/form-data' },
  });
};

Prefetching Data

Predict what the user will need next and fetch it before they ask. This makes navigation feel instant.

import { useQueryClient } from '@tanstack/react-query';

function ProductList({ products }) {
  const queryClient = useQueryClient();

  // Prefetch product details when user scrolls near them
  const handleViewableItemsChanged = useCallback(({ viewableItems }) => {
    viewableItems.forEach(({ item }) => {
      queryClient.prefetchQuery({
        queryKey: ['product', item.id],
        queryFn: () => fetchProduct(item.id),
        staleTime: 60 * 1000,
      });
    });
  }, [queryClient]);

  return (
    <FlatList
      data={products}
      renderItem={({ item }) => (
        <TouchableOpacity onPress={() => navigate('ProductDetail', { id: item.id })}>
          <ProductCard product={item} />
        </TouchableOpacity>
      )}
      onViewableItemsChanged={handleViewableItemsChanged}
      viewabilityConfig={{ itemVisiblePercentThreshold: 50 }}
    />
  );
}

// Prefetch the next page of a paginated list
const useInfiniteProducts = () => {
  return useInfiniteQuery({
    queryKey: ['products'],
    queryFn: ({ pageParam = 1 }) => fetchProducts(pageParam),
    getNextPageParam: (lastPage) => lastPage.nextPage,
  });
};

// Trigger prefetch of next page when nearing the end
const prefetchNextPage = (.hasNextPage, fetchNextPage) => {
  if (hasNextPage) {
    fetchNextPage();
  }
};

Debouncing API Calls

Debouncing prevents rapid-fire API calls when users type in a search box or adjust sliders. It waits until the user stops interacting before sending the request.

import { useState, useEffect, useCallback } from 'react';
import debounce from 'lodash/debounce';

function SearchScreen() {
  const [query, setQuery] = useState('');
  const [results, setResults] = useState([]);

  // Debounced search — waits 500ms after user stops typing
  const debouncedSearch = useCallback(
    debounce(async (searchTerm) => {
      if (searchTerm.length < 2) {
        setResults([]);
        return;
      }
      const response = await fetch(`/api/search?q=${encodeURIComponent(searchTerm)}`);
      const data = await response.json();
      setResults(data.results);
    }, 500),
    []
  );

  useEffect(() => {
    debouncedSearch(query);
    // Cleanup: cancel pending debounce on unmount
    return () => debouncedSearch.cancel();
  }, [query, debouncedSearch]);

  return (
    <View>
      <TextInput
        value={query}
        onChangeText={setQuery}
        placeholder="Search..."
      />
      <FlatList
        data={results}
        keyExtractor={item => item.id}
        renderItem={({ item }) => <Text>{item.name}</Text>}
      />
    </View>
  );
}

// Simple debounce utility without lodash
function useDebounce(value, delay) {
  const [debouncedValue, setDebouncedValue] = useState(value);

  useEffect(() => {
    const timer = setTimeout(() => setDebouncedValue(value), delay);
    return () => clearTimeout(timer);
  }, [value, delay]);

  return debouncedValue;
}

Mini-Project: Implement Request Batching

Refactor a screen that makes multiple API calls to use batched requests and prefetching.

// BEFORE: Multiple separate API calls

  const [user, setUser] = useState(null);
  const [orders, setOrders] = useState([]);
  const [notifications, setNotifications] = useState([]);

// AFTER: Single batched endpoint + React Query caching
import { useQuery, QueryClient, QueryClientProvider } from '@tanstack/react-query';

const queryClient = new QueryClient({
  defaultOptions: {
    queries: { staleTime: 5 * 60 * 1000 },
  },
});

function useDashboard(userId) {
  return useQuery({
    queryKey: ['dashboard', userId],
    queryFn: async () => {
      const response = await fetch(`/api/dashboard?userId=${userId}`);
      return response.json();
    },
    staleTime: 2 * 60 * 1000, // fresh for 2 minutes
  });
}

function DashboardScreen({ userId }) {

    <View>
      <UserHeader user={data.user} />
      <OrdersList orders={data.orders} />
      <NotificationsList notifications={data.notifications} />
    </View>
  );
}

  };

}

Summary

  • Request batching reduces HTTP overhead by combining multiple API calls into one
  • React Query's staleTime controls how long data is considered fresh before refetching
  • Image compression reduces network payload size — compress before uploading or displaying
  • Prefetching loads data before the user navigates to a screen, making transitions feel instant
  • Debouncing delays API calls until the user stops interacting, preventing rapid-fire requests
  • Use Promise.all for parallel independent requests instead of sequential awaits
  • Cache data aggressively and invalidate only when necessary to minimize redundant network calls
