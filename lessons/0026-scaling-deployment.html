Micro-Frontends for Mobile

Micro-frontends decompose a large app into smaller, independently deployable modules. In React Native, this translates to:

  • Module Federation — Load code from remote bundles at runtime
  • Package-based splitting — Separate npm packages for each feature
  • React Native Config — Share configuration across micro-apps
// Feature flags for module loading
const FEATURES = {
  chat: true,
  payments: true,
  analytics: false,
};

// Dynamic screen loading
const ChatScreen = FEATURES.chat
  ? require('./features/chat').default
  : require('./features/placeholder').default;
When to use micro-frontends Only for large apps with multiple teams. For solo developers or small teams, a well-structured monolith is simpler and faster.

Code Push (Instant Updates)

Code Push (via App Center or EAS Update) lets you deploy hotfixes without waiting for app store review:

# With EAS Update
eas update --branch hotfix --message "Fix crash on login screen"

# Users get the update on next app launch

Code Push strategies:

StrategyWhen to use
Immediate updateCritical bug fixes, security patches
Soft updateNew features, prompt user to restart
Mandatory updateBreaking API changes, compliance requirements

A/B Testing

A/B testing validates feature changes with real users before full rollout:

// Simple A/B test with feature flags
function useExperiment(experimentName) {
  const [variant, setVariant] = useState('control');

  useEffect(() => {
    // Fetch variant from your experimentation platform
    fetchExperiment(experimentName).then(setVariant);
  }, [experimentName]);

  return variant;
}

// Usage
function CheckoutButton() {
  const variant = useExperiment('checkout-button-color');
  const color = variant === 'blue' ? '#2196f3' : '#4caf50';
  return <Pressable style={{ backgroundColor: color }}>...</Pressable>;
}

Popular A/B testing tools for React Native:

  • LaunchDarkly — Feature flags and experimentation
  • Firebase Remote Config — Free, integrates with Google Analytics
  • Statsig — Feature gates and experiments
