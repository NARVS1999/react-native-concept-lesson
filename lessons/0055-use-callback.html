Lesson 55: useCallback

Phase 7 — Advanced Concepts

Lesson Goal Learn how useCallback stabilizes function references between renders, understand the dependency array, and see how passing stable callbacks to memoized children improves performance.

The Problem: Unstable References

Every time a component re-renders, all functions defined inside it are recreated with a new reference. This breaks optimizations in memoized children because they see "new" props every render.

import React, { useState } from 'react';

const TodoItem = React.memo(({ todo, onToggle }) => {
  console.log('TodoItem rendered:', todo.id);
  return (
    <TouchableOpacity onPress={() => onToggle(todo.id)}>
      <Text>{todo.title}</Text>
    </TouchableOpacity>
  );
});

const App = () => {
  const [todos, setTodos] = useState([]);
  const [count, setCount] = useState(0);

  // This function is recreated every render
  const handleToggle = (id) => {
    setTodos(prev => prev.map(t =>
      t.id === id ? { ...t, done: !t.done } : t
    ));
  };

  return (
    <View>
      <Button title="Count" onPress={() => setCount(c => c + 1)} />
      {todos.map(todo => (
        <TodoItem key={todo.id} todo={todo} onToggle={handleToggle} />
      ))}
    </View>
  );
};

useCallback Solution

useCallback returns a memoized version of the callback that only changes when specified dependencies change.

import React, { useState, useCallback } from 'react';

const App = () => {
  const [todos, setTodos] = useState([
    { id: '1', title: 'Learn useCallback', done: false },
    { id: '2', title: 'Build a todo app', done: true },
  ]);
  const [count, setCount] = useState(0);

  // useCallback ensures the same function reference is returned
  const handleToggle = useCallback((id) => {
    setTodos(prev => prev.map(t =>
      t.id === id ? { ...t, done: !t.done } : t
    ));
  }, []); // Empty deps: function never changes

  return (
    <View>
      <Button title="Increment" onPress={() => setCount(c => c + 1)} />
      {todos.map(todo => (
        <TodoItem key={todo.id} todo={todo} onToggle={handleToggle} />
      ))}
    </View>
  );
};

Dependency Array Rules

The dependency array tells React when to update the memoized callback. Include all values the callback uses.

const SearchScreen = () => {
  const [query, setQuery] = useState('');
  const [results, setResults] = useState([]);

  // Missing query dependency — stale closure problem
  const handleSearch = useCallback(async () => {
    const res = await fetch('/api/search?q=' + query);
    const data = await res.json();
    setResults(data);
  }, []); // query is always stale!

  // Correct — includes all used external values
  const handleSearchFixed = useCallback(async () => {
    const res = await fetch('/api/search?q=' + query);
    const data = await res.json();
    setResults(data);
  }, [query]); // Recreates only when query changes
};
Warning: Empty dependency arrays are only correct when the callback doesn't reference any props or state. Use the React hooks linting plugin to catch missing dependencies.

Passing Callbacks to Memoized Children

The key use case: pass a stable callback to a React.memo-wrapped child to prevent it from re-rendering unnecessarily.

const ListItem = React.memo(({ item, onPress }) => (
  <TouchableOpacity onPress={onPress}>
    <Text>{item.name}</Text>
  </TouchableOpacity>
));

const Parent = () => {
  const [selected, setSelected] = useState(null);

  // Stable reference — child won't re-render when parent re-renders
  const handlePress = useCallback((id) => {
    setSelected(id);
  }, []);

      data={items}
      renderItem={({ item }) => (
        <ListItem item={item} onPress={handlePress} />
      )}
      keyExtractor={(item) => item.id}
    />
  );
};

Mini-Project: Stabilize Callbacks in a Todo List

import React, { useState, useCallback, useMemo } from 'react';
import { View, Text, TextInput, Button, FlatList, TouchableOpacity, StyleSheet } from 'react-native';

const TodoItem = React.memo(({ item, onToggle, onDelete }) => (
  <View style={styles.item}>
    <TouchableOpacity onPress={() => onToggle(item.id)}>
      <Text style={styles.check}>{item.done ? '\u2713' : '\u25CB'}</Text>
    </TouchableOpacity>
    <Text style={[styles.text, item.done && styles.done]}>{item.title}</Text>
    <TouchableOpacity onPress={() => onDelete(item.id)}>
      <Text style={styles.delete}>\u2715</Text>
    </TouchableOpacity>
  </View>
));

const App = () => {
  const [todos, setTodos] = useState([
    { id: '1', title: 'Learn useCallback', done: false },
    { id: '2', title: 'Learn React.memo', done: true },
  ]);
  const [input, setInput] = useState('');

  const toggleTodo = useCallback((id) => {
    setTodos(prev => prev.map(t =>
      t.id === id ? { ...t, done: !t.done } : t
    ));
  }, []);

  const deleteTodo = useCallback((id) => {
    setTodos(prev => prev.filter(t => t.id !== id));
  }, []);

  const addTodo = useCallback(() => {
    if (!input.trim()) return;
    setTodos(prev => [...prev, { id: Date.now().toString(), title: input.trim(), done: false }]);
    setInput('');
  }, [input]);

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Stable Callbacks Todo</Text>
      <View style={styles.inputRow}>
        <TextInput style={styles.input} placeholder="Add a todo..." value={input} onChangeText={setInput} />
        <Button title="Add" onPress={addTodo} />
      </View>
      <FlatList
        data={todos}
        keyExtractor={(item) => item.id}
        renderItem={({ item }) => (
          <TodoItem item={item} onToggle={toggleTodo} onDelete={deleteTodo} />
        )}
      />
    </View>
  );
};

const styles = StyleSheet.create({
  container: { flex: 1, padding: 20, backgroundColor: '#f5f5f5' },
  title: { fontSize: 24, fontWeight: 'bold', marginBottom: 15 },
  inputRow: { flexDirection: 'row', gap: 10, marginBottom: 15 },
  input: { flex: 1, borderWidth: 1, borderColor: '#ccc', borderRadius: 8, padding: 10 },
  item: { flexDirection: 'row', alignItems: 'center', padding: 12, backgroundColor: '#fff', borderRadius: 8, marginBottom: 8 },
  check: { fontSize: 18, marginRight: 10 },
  text: { flex: 1, fontSize: 16 },
  done: { textDecorationLine: 'line-through', color: '#999' },
  delete: { color: 'red', fontSize: 18, padding: 5 },
});

export default App;

Summary

  • useCallback returns a memoized function that only changes when dependencies change
  • Include all values the callback references in the dependency array
  • Use useCallback when passing callbacks to React.memo-wrapped children
  • Functional updaters in setState let you use empty dependency arrays safely
  • Missing dependencies cause stale closures — use the linting plugin to catch them
  • useCallback + React.memo together prevent cascading re-renders
